## 如何使用

在本项目当前会话或新建的统筹会话中，完整复制下面“正式启动指令”代码块并发送一次。该会话成为A，负责建立B/C及后续接续会话；不要再把同一完整指令分别发给B/C。先核对现有执行状态，避免重复启动。
