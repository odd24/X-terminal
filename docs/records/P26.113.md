# P26.113 修复交互 ADB Shell 的显示和输入

按 [CR-063](../changes/CR-063.md) 及 [ADR-111](../decisions/ADR-111.md)，在本地命令组向末步裸 ADB Shell 交接时保存同标签的启动记录，并将当前视口交给原 ConPTY。原生绝对坐标只影响 Shell 视口。普通本地命令和 BAT 仍沿用已有停止路径。

交互阶段的键盘 Ctrl+C 送到原 Console，不作为本地取消。多行粘贴冻结原路由、任务及阶段，LF 和 CRLF 按一个分隔发送，末尾不添换行。确认区显示原文分行及末尾状态。正常 exit 与意外断开按原进程结果区分，异常保留退出码和诊断输出。Step-ID: P26.113。

同一 Windows x64 Release 程序验证四种 LF/CRLF 和末尾组合，各有原始 IPC 和原生 Win32 输入记录。模拟绝对重绘只更新当前视口，滚动历史保留启动记录。空提示符、半行和模拟长程序均接收 Ctrl+C，原 shell PID 和身份探针一致。新结果拒绝原任务输入。开启自动关闭后，明确 exit 关闭标签，异常 255 保留标签及原因。回环 SSH 路由、普通命令组及 BAT 停止、PowerShell 粘贴和 159 项前端测试均通过。证据位于 artifacts/P26.112-adb-console 的 exact-adb.json、exact-routes.json、exact-stop.json、exact-paste.json。
