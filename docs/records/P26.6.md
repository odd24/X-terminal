# P26.6 桌面发布版性能优化

依据 [CR-029](../changes/CR-029.md)，比较 0.1.17、0.1.18 和带优化的 0.1.19。0.1.18 是直接实现对照，包含上轮标签拖动和复制功能。

ConPTY 在空缓冲变为有数据或进程实际退出时唤醒。每个任务一个有界等待读取者，等待不持有会话或进程输出锁。浏览器仍按原有节奏处理持续输出，空闲无需持续取空页。响应使用小块 JSON 元数据加原二进制输出，保留溢出提示、退出码、末段、输入任务身份和原编号回读。切换可见性仅调整视口，主题设置变化才重应用外观。

每次主界面刷新用单次桌面调用取服务状态和窗口可见的连接列表。原 Ping、列表请求、窗口过滤和失联处理继续执行。服务的记录、授权、协议及队列容量保持原有行为。
