## 风险与未完成项

- 不把合成 echo 当成真实 shell 或 Linux 实机验收，P03 不记 DONE。已异步询问真实设备/端点；缺失信息只阻塞相关验证。
- 多算法、RSA/ECDSA、证书、旧 UNIX、保活丢失未验。默认库能力和实测覆盖分开列。
- 原型在 channel 成功应答前收到其他事件会保守失败；未做真实端点的事件顺序覆盖。P09 需保留早到输出并完整映射状态。
- exec 超时不能证明远端未执行；断线后不自动重放。5 秒限制仅用于原型，不能代替 P15 长任务语义。
- 依赖链有预发布密码学组件，最终采用与分发需审计；不将它包装成已完成安全验收。
