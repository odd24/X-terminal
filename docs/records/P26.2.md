# P26.2 本地 PowerShell、ADB 枚举与直接运行交付

依据 [CR-025](../changes/CR-025.md)，接续 Windows x64 0.1.14。使用同机 Windows PowerShell 5.1.22621.6133 和 ADB 1.0.41（Platform Tools 36.0.0-13206524）对照。PATH 上工具与普通 PowerShell 解析一致。当前会话未设置 ANDROID_SERIAL、ADB_SERVER_SOCKET、ANDROID_ADB_SERVER_ADDRESS 或 ANDROID_ADB_SERVER_PORT。实际设备行在序列号和状态间使用七个空格，旧 split_once(Tab) 无法识别。设备标识省略。

枚举采集有界 stdout 和 stderr，并在侧栏展示实际路径和结果。轻量入口在 xterm 中编辑和提交，原生直接执行路径沿用。默认 Shell 使用 Windows 系统目录内的 Windows PowerShell，以常规配置加载启动；应用不往原 Shell 注入探测命令，ADB 独立结果标签从原标签的初始 Windows 工作目录开始。

首轮 ConPTY 从 PowerShell 7 进程继承模块路径，启动停在 PSReadLine 发布者提示。仅让 Windows PowerShell 子进程重新生成模块搜索路径，原执行策略、用户配置和 ADB 环境仍由系统及进程原入口处理。没有确认或修改发布者信任。[Microsoft PowerShell 模块路径说明](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_psmodulepath?view=powershell-5.1)

## 软件与指定设备

- 实际 Windows PowerShell 的版本、当前宿主的 $PROFILE 路径是否存在和 PATH 上的 adb 与外部 PowerShell 对照一致。实际按 Tab 补全含中文的文件名并读取正文，核对管道筛选和重定向文件。Ctrl+C 停止受控长命令，随后的中文输入成功写出 UTF-8 样本。原 PowerShell 草稿在独立结果标签运行模拟 ADB 后仍可提交。
- 空格、Tab、空枚举及异常格式单测通过。模拟枚举的非零退出和 stderr 在按钮旁可查看。显式及环境目标仍按原目标运行，合成目标掉线未改投。镜像图标实际尺寸为 16 px、热区 28 px，使用 Space 展开，宽窗、窄窗及分屏仍沿用右栏布局。
- 最终 Release 使用自建数据根，核实设备枚举只有一台且状态为 device。点击一次按钮进入授权 Android 设备 Shell，只输入 pwd 和 exit。得到实际目录输出及退出码 0。诊断显示与外部 PowerShell 相同的 adb，并观察到原设备被绑定。没有写入设备、触碰业务节点或重启 ADB server。设备标识和原始交互正文不进入仓库。

## 直接运行目录

Windows x64 0.1.15 位于 artifacts/SharedTerminal-0.1.15-windows-x64。双击其中的 shared-terminal-desktop.exe，保留同目录服务和 MCP。三个未签名 EXE、README、逐文件大小和 SHA-256 可从 manifest.json 核对。按用户要求交付目录，未生成本版压缩包，也未替换现有安装。

从候选直接运行目录通过普通启动、0.1.14 配置锁和显式复查、受管理退出、MCP 29 工具发现及普通/保护读取、本地轻量终端、ADB 快捷指令和 PowerShell 专项。交付目录再测右侧栏布局与镜像图标。

Windows 11 22631 下，首个 PowerShell 提示符在约 382 ms 出现。后续三次为 330、387、391 ms。外部同版本 PowerShell 进程从启动到返回配置对照 JSON 约 554 ms，终点不同，单列作环境参考。ADB 设备回显性能、其他设备和 Windows 输入法候选矩阵本轮未测。

证据位于 artifacts/SharedTerminal-0.1.15-windows-x64-verification.json、artifacts/local-powershell-device-result.json 和 artifacts/windows-0.1.15-adb-sidebar-layout.json。实际窗口截图为 windows-0.1.15-powershell.png、windows-0.1.15-adb-diagnostic.png 和 windows-0.1.15-adb-sidebar-wide.png。诊断截图使用模拟故障。
