# P26.27 Windows x64 0.1.36 当前用户正式部署

2026-11-24 部署 Windows x64 0.1.36 已验收 Release。清单源码 `8f59f22795823ace83147cba5f4bc84f197f492b`，版本号与该提交一致。四个清单文件由原目录复制到 `%LOCALAPPDATA%\Programs\SharedTerminal\0.1.36`，安装文件与发布清单、三份程序与快捷指令实测二进制的 SHA-256 相符。

原开始菜单「共享终端」和已有 Codex `shared-terminal` 启动首选均为 0.1.22。主快捷方式改为 0.1.36，原快捷方式保留为「共享终端 0.1.22」。Codex 保留原 stdio 启动脚本，只修改该注册的参数，首选已安装 0.1.36，回退已安装 0.1.22。启动脚本按运行中的桌面实例选择其同目录的桥。更新后回读实际注册，与验证使用的命令及参数一致。已有运行中的旧桥仍在，部署未启动默认数据根。

证据为 `artifacts/SharedTerminal-0.1.36-formal-install-verification.json`、`artifacts/SharedTerminal-0.1.36-installed-smoke.json` 和 `artifacts/SharedTerminal-0.1.36-installed-stdio.json`。新版入口生效后，只有在 0.1.36 桌面运行且 Codex 重新建立 MCP 连接时才会使用 v13。回退启动保留原二进制入口，无默认数据根的迁移或还原操作。
