## 实现

Rust 外壳从自身 exe 相邻路径启动 session-service.exe，bootstrap 经匿名 stdin 传递，PID 核对后建立客户端，token 不进入 renderer/argv/env/文件。外壳持有 Child 与匿名、不可继承、KILL_ON_JOB_CLOSE Job。服务启动前分配到 Job；分配失败不提供服务。服务在收到 bootstrap 前不能建立 Pipe；极窄的 spawn/Job 分配窗口中若父进程死亡，bootstrap EOF/5 秒超时让子进程自行失败退出。

默认退出策略 stop_on_desktop_exit：关闭最后窗口请求 shutdown，等待最多 2 秒后 kill；强杀外壳由 Windows 关闭 Job 回收服务。后台保留/托盘选择留待 P12，当前 UI 明确说明退出会停止。每个外壳启动独立随机 instance/服务，不通过磁盘发现或复用未知服务；同 instance 排他由 P07.2 覆盖。原生客户端每 10 秒心跳，独立于 React/页面暂停；任何 IPC 错误锁定失败，不重新启动服务或重发输入。

renderer 只注册 status/list/read 与显式 fixture_create/fixture_append，没有 generic root RPC 或签发票据入口；根凭据不返回 JS。默认 fixture 禁用；只有外壳/服务同时显式 --test-fixture 才可新建合成连接。合成键盘回显、高输出和屏幕数据均经过服务，页面按各自 cursor 读取，覆盖报告缺口，渲染保留 P02 有界队列。键盘合成请求最多 16 个在途；真实设备写授权/去重仍待 P14，不将 fixture 当作设备写入口。
