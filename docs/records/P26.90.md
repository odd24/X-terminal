# P26.90 实现并验证会话树标签落位与焦点

按 [CR-057](../changes/CR-057.md) 和 [ADR-107](../decisions/ADR-107.md) 固定发起窗格实例、服务身份和启动回执。新标签显式追加，认证绑定原连接代次。主动切走后保留当前输入路径。有焦点交接的场景须等待准确终端已显示且可写。复制、分组、混排和工作区沿用各自现有入口。

隔离 Windows 原生桌面用回环 SSH 验证树三个入口、手动重排和分组、混排、复制相邻。以 WebView2 键盘输入及原始服务字节核对选中、渲染和真实目的地。延迟启动回执覆盖快照先到、切换窗格、原窗格关闭和 Escape；丢失回执覆盖同窗格切换、查询原编号和继续原认证。

内存 UART 验证旧配置修订拒绝、固定启动丢失回执后仅查询原目标，以及追加、显示、聚焦和命中设备的输入字节。桌面固定串口回执按原身份查询。Windows IPC 的既有 MCP 单操作授权与原身份测试通过。普通和测试服务分别构建和运行。

运行 TypeScript、159 项前端测试、Rust 格式和 Windows x64 Release 构建。回归包含 SSH2 首次登录及凭据保存、会话树删除、串口配置和现有双 SSH 工作区恢复。证据保存在 artifacts/P26.89-tree-tabs。SSH1 预览路径接入原窗格标识并通过静态检查。原版 SSH1 对端、物理 UART、真实服务器和实体键盘待验。Step-ID: P26.90。
