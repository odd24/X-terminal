# P26.34 窗口会话快照订阅重构

依据 [P26.33 执行方案](P26.33.md)，本轮处理每个桌面窗口的会话快照。方案提交为 `a23711d`，代码对照为 `3e7b03d`。第二轮快捷指令执行协调的启动条件为新增执行目标、结果标签复用、取消／重试或自动关闭规则等业务变更。

## 代码与归属

- [窗口订阅](../../apps/desktop/src/session-snapshot.ts)负责立即发起首次读取、捕获路由版本、串行等待并在处理完上一帧后约 100 ms 再读。卸载取消计时器，并丢弃该订阅已经发出的迟到应答。读取或应用失败时只调用一次失联处理。
- [桌面窗口](../../apps/desktop/src/main.tsx)仍负责撰写历史、可见连接列表、输出通知、触发器校验、窗格保留和焦点。列表相等时复用可见列表引用，最新游标仍会通知相应控制器。每个窗口各挂载一个订阅，分屏复用所在窗口的订阅。
- 移交会话可能先从本窗可见列表移除首项。设原始快照顺序为 A、B，游标分别为 20、60，移交 A 后，按可见下标 0 取值会把 20 当作 B 的提示。现在通过同一快照的服务标识、连接 ID、代次与协议取得 60。服务或代次不匹配时交由原读页机制处理。这一边界由确定性测试覆盖。
- [回归测试](../../tests/session-snapshot.test.mjs)已接入 `npm test`。可控时钟与 Promise 分别验证慢读串行、请求时的路由版本、定时器取消、重新挂载后忽略旧应答及错误终止。原生 IPC、存储格式和 MCP 工具均沿用现行契约。

## 功能验收

- 148 项前端测试全部通过，类型检查、前端生产构建和 Tauri Windows x64 Release 构建成功。
- 实际 WebView 中压住快照时仍能读到 SSH 新输出；在途时从 A 切到 B，释放旧快照后 B 仍被选中。刻意延迟 A 的正文页并切换到 B，B 中只出现自己的标记，切回 A 可以读到原文。B 的最后一帧在断开后仍可见。定向回执为 `P26.34-route.json`。
- 复制后的普通桌面单独启动，核对服务映像、PID 和父进程后仅终止该测试窗口的服务。桌面继续存活并显示服务不可用，快照及后续状态请求均返回 `SERVICE_UNAVAILABLE`。回执为 `P26.34-loss.json`。
- PowerShell 普通标签双击只开一个独立副本，现有交互子进程保留在原标签。实际 Windows 指针拖动完成重排、拆分、合并与取消。混合本地与 SSH 标签的复制及输入归属、Alt 加数字和小键盘切换均通过。回执为 `P26.34-local-tabs.json`、`P26.34-mixed-tabs.json`、`P26.34-shortcuts.json`。
- `P26.34-tabs.json` 中每种规模各有 150 次标签切换。4 标签 P50／P95 为 9.2／23.5 ms，20 标签为 10.0／14.1 ms。每次独立启动都核对了两个输出进程各 480 个连续编号。
- `P26.34-flow.json` 中八路合成连接共 245,760 字节逐源一致；录制一路的 120 条、30,720 字节已持久化。120 个可见标记 P95 为 47.4 ms。重连代次刷新约 73 ms，断开、移除与受管理退出均通过。以上为本机软件验收，设备实测与长稳边界仍见 [P22](P22.md)。

## 同机对照

下表每行分别观察单窗与双窗空闲各 30 秒。单窗停在 PowerShell；双窗包括独立 SSH 窗口。两个回显栏单位为 ms，每栏每批各 30 次，按最近秩计算 P50／P95。每个完成批次还核对独立窗完整收到 75,010 字节，并比对两窗可见会话归属。原始 JSON 在 artifacts 目录，文件名以 `P26.34-` 开头。

| 批次 | 单窗快照／空读 | 双窗合计快照／空读 | 单窗格回显 P50／P95 | 双窗格回显 P50／P95 |

| base3-repeat | 270／0 | 543／28 | 21.4／37.1 | 26.9／37.6 |

**失败与复测。** 候选 trial2、基线 base3 各有一次在「完成管理」后的快捷指令悬停预览等待超时，均发生在采样之前。保留两个失败报告；同一二进制、同一断言分别重跑通过。原因尚未定位。完整批次各三次，输出完整性或归属断言失败数为零。

**延迟判读。** 前两组候选双窗格回显 P95 超出前两批基线区间；第三组反转执行顺序。第三次候选降到 42.1 ms，第三次基线也降到 37.6 ms。三组配对候选均较慢，差值为 4.0、7.4、4.5 ms。核对了窗口只有一个订阅入口、相等列表跳过状态更新、每轮游标通知仍走原控制器，以及实际双窗空读六批均为 28 次。现有测量无法将几毫秒差距归因于订阅或其他调度环节；记录为待跟踪的回显差异。这个工作包的收益是游标归属正确和订阅可独立验证。后续若优化键入延迟，应单独测量输入派发、远端回显到达、读页及 WebView 绘制各段。

**交付与回退。** 复制目录的三个 exe 已逐一与 Release 构建核对 SHA-256，可直接运行桌面程序。本次交付独立候选目录，正式安装仍指向原版本。需要回退时通过含 `Step-ID: P26.34` 的本地提交定位变更，以新的 revert 提交撤回该包并更新台账，再复跑触发回退的场景；本机亦可直接启动留存的 P26.32 对照目录。后续快捷指令工作包沿用 [P26.33 的启动条件](P26.33.md)。
