# P26.52 Windows x64 0.1.37 当前用户部署

2026-11-24 将 [P26.51 正式发行](P26.51.md)安装到 `%LOCALAPPDATA%\Programs\SharedTerminal\0.1.37`。先在同一上级目录创建独立暂存目录，复制正式包四个清单文件及清单，校验字节数和 SHA-256，再移入版本目录。实际回读桌面 PE 文件和产品版本，服务及桥均报告 0.1.37。

切换入口前，从安装目录使用新建隔离数据根运行 `node scripts/Test-Windows-Portable.mjs INSTALLED_DIRECTORY REPORT`。通过 0.1.36 的隔离配置锁和显式复查，普通服务拒绝测试入口，同目录桥提供 v13 的 33 项工具，未批准的会话枚举被拒绝。桌面与服务均以退出码 0 结束，关停回执为 `ACKNOWLEDGED`，无强制终止，隔离根已清理。
