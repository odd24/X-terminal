# P26.99 修复本地粘贴确认及 PowerShell 多行编辑

按 [CR-060](../changes/CR-060.md) 调整本地确认焦点。Enter 松开后只激活焦点按钮，按住时重复的按键不提交草稿。Esc 或取消回到原终端。轻量终端的单行草稿可在确认后继续编辑，剪贴板末尾换行不触发提交。

按 [ADR-109](../decisions/ADR-109.md) 区分 PowerShell 编辑代次和前台进程输入。PSReadLine 在原位置一次插入文本，换行统一为 LF，保留段落顺序、缩进和原光标两侧的文字。正在运行的应用经原输入队列收取其粘贴字节。原编辑代次或前台状态变化时拒绝迟到的粘贴。

隔离 Windows PowerShell 5.1 实窗核对 LF、CRLF、50 列下的软折行、原始两行草稿、光标、前后缀及继续输入。原始 ADB 文字只读回草稿后清除。仅执行本地输出样本并核对结果文件只写入一次。确认、取消、旧编辑代次及已退出前台读取均核对。另复验本地右键复制与粘贴、模拟 ADB 和 CMD 的原始输入、切换与关闭后的迟到读取，以及 159 项前端测试。证据在 artifacts/P26.98-local-paste/implementation-editor.json 和 implementation-local-clipboard-result.json。Step-ID: P26.99。

既有快捷指令停止关闭通过 9 项复验。拖入事件回归通过，原生 OLE 的第二轮通过前 12 项，含长路径、精确折行边界、路径按光标插入和迟到回执。后续拖放由窗口所有权及鼠标按钮保护取消，各轮原始报告保留在同一证据目录。
