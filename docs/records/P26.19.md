# P26.19 本地标签拖动与双击

按 [CR-042](../changes/CR-042.md) 修正。标签名称区域将指针手势直接交给本地与 SSH 共用的标签按钮。连接服务的编号只用于远端标签手势的校验，本地标签在首个服务快照到达时继续拖动。松手前复核源身份和存续。

移除本地双击的复制动作。右键或 Shift+F10 的显式复制沿用原目录和独立终端流程。脚本标签和 ADB 结果的双击只选中原终端。实现不读取终端命令和输出判断是否在刷机。

隔离 Windows 实窗验证实体鼠标重排、连接服务首帧到达时完成拖动、Escape 取消、边缘分屏和跨栏合并，原 xterm 节点及草稿保留。普通 PowerShell、轻量命令行、合成 ADB 和自建 BAT/CMD 双击无新增本地会话，显式菜单复制正常。回环 SSH 的分屏、混排、双击复制和输入隔离通过。

实体鼠标排序通过的是调试构建。Release 的鼠标助手检测到起点属于另一窗口，在发送事件之前退出。Release 使用隔离 WebView 指针验证上述窗口内手势和原会话状态。

证据见 `artifacts/local-tabs-software-result.json`、`artifacts/local-scripts-software-result.json` 和 `artifacts/windows-0.1.29-session-copy-ssh.json`。此修复随 0.1.29 Windows x64 直接运行目录交付。
