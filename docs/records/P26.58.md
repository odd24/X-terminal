# P26.58 实现右栏编辑导航及发布验证入口

按 [CR-051](../changes/CR-051.md) 改造右栏快捷指令表单。比较进入表单时的名称、命令、描述与开关，复原字段后直接返回。顶部返回与底部取消共用共享模态的草稿确认。现有指令以 UUID 恢复管理入口，记录列表滚动位置。新增取消将焦点放回发起入口，保存成功定位新条目。失败保留输入，键盘可直接重试。列表收到并发更新导致刚恢复焦点的行消失时，焦点回落到当前可用的管理入口，已有用户焦点优先。

保留原配置入口、修订检查和描述契约。发布脚本在解压目录上运行新增导航专项，继续验证描述预览，并使用真实 v12、v13 桥验证 v14。与此前一样，三程序要求未嵌入签名。本机信任查询停滞后，对普通产物改用确定的 PE32+ 证书表检查，解包门再次校验。

通过前端类型检查、158 项测试、脚本解析和签名字段正负向验证。真实 Windows 桌面专项验证顶部返回、底部取消、Tab 约束、Esc、保存失败和重试、已有条目与新增路径，以及并发删除后的焦点回落。第一次运行缺少 Enter 的 WebView 字符事件，按既有测试方法补齐。第二次发现临近返回的并发删除会丢失焦点，已修正并复验。最终候选的描述预览、导入和旧桌面编辑回读也通过。证据位于 `artifacts/P26.58-navigation`。
