`scripts/Prepare-Windows-Portable.ps1` 打包后重新解压，在解压副本和自建中文数据根完成实际验证。三件 PE 均为 x64，Desktop 使用 GUI 子系统，运行时加载同目录服务和 MCP。普通启动拒绝 fixture 功能，串口测试专用参数在创建数据前被拒。隔离旧预览持锁时正式版获得 `LOCKED`。旧预览正常退出后，同一正式版服务通过显式复查读取旧合成配置及字号和亮度偏好。正式版重启后审计恢复健康。官方 Codex 客户端实际发现 v11 的 29 项工具，未配对读取被拒。回环 SSH 上独立通过普通与保护读取的字节边界和时间窗回归。Desktop、服务和桥退出，自建数据根释放。前端测试 136 项通过。

首轮 ZIP 验证中夹具拒绝正常发生，测试误将 CDP 包装后的 Error 与原拒绝文本直接比较。修正断言后用同一批二进制重打包并通过。最终验收见 `artifacts/SharedTerminal-0.1.0-windows-x64-verification.json`。本包交付本机日常使用的未签名便携版。实际 MSI、干净系统安装、签名及真实设备验收仍按 T21 和对应实机计划处理。用户运行中的旧预览和用户数据根未参与。

## 安装数据保留策略与 T21 验收准备（2026-11-19）

按当前源码核对，Desktop 默认调用 Tauri 的 `app_local_data_dir()`，应用标识为 `local.shared-terminal.desktop`。显式 `--data-dir` 接受独立的绝对目录，并交给所属服务。服务在数据根打开 `config.sqlite` 与 `credentials.sqlite`，同根还有日志、配置备份及恢复诊断。用户经系统选择器另存的文件可在数据根之外。现有 Tauri bundle 关闭，安装和卸载行为须待候选安装包实测。

候选采用**卸载程序、保留数据**。卸载界面明确告知此结果。安装器负责本包安装的文件及注册项，保留稳定的应用标识。普通卸载保留默认数据、用户指定的数据根、另存文件及外部 Codex 配置。需要清理数据的用户应先退出应用并备份所需内容，再独立处理明确识别的应用数据根。自定义根可能含其他文件，清理前逐项核对。Codex 接入由用户单独移除对应条目，保留其他 MCP 配置。WebView2 作为共享运行时保留。

在干净 Win10 与 Win11 的固定候选上逐项留证：

| 场景 | 核对结果 |
| --- | --- |
| 新装 | 记录 Windows build、WebView2 版本、安装包 SHA-256、安装范围和应用实际数据根。在中文路径和目标 DPI 启动，核对 Desktop 及同目录所属服务实际运行。 |
| 升级 | 在旧候选建立合成配置、凭据、日志和独立另存标记。通过安装器进行升级，核对原数据根、配置、已保存密码实际认证、日志字节及原另存标记。同一用户运行，服务身份重新生成，会话及授权为空。 |
| 活跃时发起升级 | 通过旧版确认退出前，核对旧连接和文件身份。确认退出后核对所属服务实际退出，再检查安装器完成替换。取消安装保全旧版及原数据。 |
| 失败与回退 | 分列安装文件回退和数据回退。旧程序遇较新 schema 时原库保持完好。同用户仅从版本匹配的配对快照在独立目录恢复，核对原库、备份和新增数据的归属。 |
| 卸载、重装和可选清理 | 实际查看卸载提示，核对安装文件及注册项移除，自建默认及显式数据根、外部另存文件和合成 Codex 配置逐项保留。重装后同用户重新打开数据并核对凭据与日志。独立清理步骤只处理明确选择的测试数据，其他文件保持。 |

执行时保存安装前后文件身份与哈希，凭据以成功认证和受保护文件校验留证。此工作包是候选策略及验收准备。正式包仍需在完整 P24 前置、最终安装形式及目标环境落实后验证，P25/T21 保持待验。
