## 桌面编辑器阶段（前置 efb0f95）

Rust 外壳现在默认通过 Tauri app_local_data_dir 选择应用本地用户数据目录，支持显式 --data-dir 绝对路径。启动将目录交给统一服务；renderer 无数据库/文件读写入口。配置与终端各用一个原生 Pipe 客户端/互斥锁，各有独立于页面的心跳，配置保存不持有终端通道锁。

桌面已提供目录创建/重命名/父目录编辑/删除、按目录/名称筛选，SSH2/显式 SSH1/SERIAL 的新建/修改/移动/复制/删除和编码/认证/控制线参数表单。保存只持久化配置，不建立连接或打开 COM。复制不携带凭据引用；Keep/Clear/Replace 文案明确，保存/切换/关闭清空新输入，不回填已存秘密。处理中的状态与完成状态分开，修正初次界面测试暴露的旧成功提示问题。

私钥通过专门 SaveProfileKeyFile 导入：页面只输入文件路径/口令，服务限额读取本地盘普通文件，检查 PEM 头并加密关联；Tauri 通用配置入口拒绝原始 private_key 字段有值。拒绝设备/UNC/ADS 路径、保留 DOS 名称、超限文件和叶级符号链接；使用 OPEN_REPARSE_POINT，不修改源文件。凭据总序列化限额仍为 64 KiB，私钥结构/算法/口令能否认证由 P09 实际解析验证，不把 PEM 头检查当作 SSH 验收。测试只用无效的合成 PEM 标记，不使用真实私钥。
