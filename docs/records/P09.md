## 实际证据

隔离服务器只绑定 127.0.0.1 随机端口；每轮随机密钥/合成秘密，无设备凭据。原 4 项 P03 回归保留，新增 5 项真实 SSH2 包场景及 2 项 KDF 头部单元测试。

- 密钥挑战待决定时 auth_attempts=0；拒绝/决定超时不发送密码；连接取消后待确认回执关闭。
- 错误密码明确拒绝后正确密码成功；加密私钥与口令可认证、错口令拒绝；异步交互提示等待回答，17 提示超限不交给 UI；Debug 不含密钥/口令标记。
- PTY/shell 早到输出、流控通知和正常 banner 不丢；同一 transport shell 写入/resize 与独立 exec 并行存在；保活后仍可读写，取消后不再排入新字节。
- exec 非零 code=7、stderr/早到 stdout、信号 TERM、无退出码、断线、超时/取消部分结果、未收到批准但已有输出、64 字节总限额均有断言；失败 exec 后正常 exec 仍可运行，无自动重放。
- 所有者 Drop 后 shell 观察关闭；无 SSH banner 的实际 TCP 对端观察客户端超时后 EOF。KDF 测试构造超成本 PKCS8/OpenSSH 头部，不进行昂贵派生即拒绝。

## 有界输入与 resize 阶段（前置 298dd38）

session-core 新增通用 request_id 指纹/回执账本，实际 SSH2 写入和 resize 经同一个每连接 FIFO（16 等待槽+1 工作槽），读取与写入并发轮询；等待 SSH 窗口不占会话锁。公开请求明确 connection_id/generation/request_id；SensitiveBytes 排队容器脱敏/擦除，账本不留 payload。相同 ID/内容只返回原回执，同 ID 内容或动作变化拒绝；最多 1024 回执，满额不淘汰去重证据。每次主机评估/确认暂停新输入，未派发工作等待 writable 通知。详见 [ADR-015](../decisions/ADR-015.md)。

Pending/Dispatching/PipelineQueued/Unknown/CancelledBeforeDispatch 分开，成功只表明进入 SSH pipeline，不表明远端执行。错误后终止连接任务并结算其余队列；关闭或迟到结果不能把 Unknown 改成“没发过”或确定成功，不重放。当前仅 active Desktop 可写/查回执，Observer 拒绝；P14 Agent 授权/接管未实现，P09 尚无桌面入口/exec 任务/同 ID 重连。长会话回执容量策略仍须 P14/P22 补齐，不能把 1024 上限说成通过 8 小时压力。

领域新增 3 个实质用例：重复/冲突与一次派发、关闭前后状态/迟到成功、容量及不淘汰；协议新增有界 payload/UUID/尺寸/敏感 Debug 与序列化负向验证。独立 Windows 服务 + 实际 SSH2 回环新增 FIFO/文本及 resize 去重/旧代次/Observer 拒绝、真实背压时 16 项等待上限与 Ping/Read 可用/关闭不重放，以及 15 秒真实写入超时部分 Unknown/停止后续队列。背压 fixture 将窗口限为 32 KiB 并停在 data handler，64 KiB 写入只观察到 32 KiB，不能把部分发送报告为零或完整发送。
