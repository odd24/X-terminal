## 实际证据

隔离服务器只绑定 127.0.0.1 随机端口；每轮随机密钥/合成秘密，无设备凭据。原 4 项 P03 回归保留，新增 5 项真实 SSH2 包场景及 2 项 KDF 头部单元测试。

- 密钥挑战待决定时 auth_attempts=0；拒绝/决定超时不发送密码；连接取消后待确认回执关闭。
- 错误密码明确拒绝后正确密码成功；加密私钥与口令可认证、错口令拒绝；异步交互提示等待回答，17 提示超限不交给 UI；Debug 不含密钥/口令标记。
- PTY/shell 早到输出、流控通知和正常 banner 不丢；同一 transport shell 写入/resize 与独立 exec 并行存在；保活后仍可读写，取消后不再排入新字节。
- exec 非零 code=7、stderr/早到 stdout、信号 TERM、无退出码、断线、超时/取消部分结果、未收到批准但已有输出、64 字节总限额均有断言；失败 exec 后正常 exec 仍可运行，无自动重放。
- 所有者 Drop 后 shell 观察关闭；无 SSH banner 的实际 TCP 对端观察客户端超时后 EOF。KDF 测试构造超成本 PKCS8/OpenSSH 头部，不进行昂贵派生即拒绝。

首轮 cargo test -p transport-ssh2 --locked 11 项通过。clippy 首次报告可折叠 if，已修正；补流控通知时误用 xon_xoff 方法名被编译拒绝，已改为本地锁定 API 的 xon_xoff_request。最终命令结果在阶段提交前补充，不以失败轮次冒充通过。
