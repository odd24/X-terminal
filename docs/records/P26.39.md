# P26.39 R2 复制会话和结果归属

按[全仓重构方案](../REFACTOR_PLAN.md)实施，入口接续 [R1 窗格模型](P26.38.md)。[窗口级复制协调](../../apps/desktop/src/session-copy.ts)登记原读取、对话框、收到的子连接身份和邻接落位。React 管理 DOM 锚点、对话框和焦点，[原生独立窗](../../apps/desktop/src-tauri/src/session_windows.rs)继续校验原窗许可和原始复制编号。

| 路径 | 行为 |
|---|---|
| 普通本地标签 | 复用原本地启动、目录继承和双击条件。 |
| 主窗口远程标签 | 读取时固定服务、连接 ID、代次、协议和窗格。重复手势共享一次读取。取消后的回执无法结算新对话框。一个已接收的子连接只安排一次邻接落位。 |
| 独立窗发起 | 请求经原生许可交给主窗。主窗收到原编号时固定当时活动窗格，稍后读取完成仍使用同一窗格。主窗已有对话框时消费原编号并显示提示。 |
| 迟到连接回执 | 若对话框已取消或服务已换代，回执无权更新对话框或焦点。若同一次已启动的连接回执到达时源窗格已变化，结果仍由该复制对话框识别和呈现，禁止把它落到替代窗格或让它抢焦点。 |
