# P26.1 ADB 快捷指令右侧栏

依据 [CR-024](../changes/CR-024.md)，从 0.1.13 将快捷操作移入本地窗格右侧。独立开关放在窗格标签行末端，默认收起。沿用 WebView 的本地界面偏好保存手动开合，ADB 路径、指令、顺序和配置版本仍使用原受保护设置。全局工具栏和原生执行入口沿用原方案。

宽窗侧栏使用 300 px 布局，窄窗和分屏在当前窗格内覆盖。终端接收原有尺寸更新，折叠只隐藏侧栏。xterm 实例和输入路由继续由原标签拥有。

验收使用隔离 Windows 数据根、两条回环 SSH 用于建立实际分屏，以及模拟 adb 程序核对调用计数和参数。现有实际设备和用户数据根不参与测试。

开发版实际窗口通过宽窄布局、分屏、原位编辑和旧设置重开。模拟 adb 专项用鼠标命中指令行的命令区域，核对一次执行。新建、设置保存、取消、上移、下移和删除的额外调用数为零。折叠后原任务 PID 保持，切回原标签发送交互文本并核对回显。等待绑定原标签后，草稿分流、结果焦点和后续目标用例通过。TypeScript 检查和既有 138 项 JavaScript 测试通过。
