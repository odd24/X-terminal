# P26.26 MCP 快捷指令四类型管理

按 [CR-049](../changes/CR-049.md) 实施。MCP 契约升级到 v13，保留四个工具名及原有入参分支。显式 `version: "v2"` 选择新分支与扩展查看、扩展管理。浏览器授权预览列出本地命令、会话发送文本及各自配置操作，绑定实际桥 PID、原待批准编号、期限和原生提交门。旧查看和管理仍只投影旧式 ADB 与 BAT/CMD 引用。会话权限单独验证。

新投影包含四类目标、全区排序及适用的 `close_on_success`、`append_enter`。原文通过同一桌面输入规范校验，保持原字节，目标补丁沿用条目类型。脚本别名为空时按桌面同规则保留后缀，主文件名最多 60 个 Unicode 字符。省略补丁名称时保留当前名称。边缘移动基于操作当时的置顶／普通区，将选中块保持当前相对顺序，兼容原锚点。

原配置库、版本检查、请求摘要和原编号查询继续使用。v2 回执独立登记，每种范围最多保留 32 条回执，旧回执格式及摘要不迁移。扩展管理可查询已有旧回执。原管理只查询旧回执，跨版本复用请求号拒绝。配置和相应回执一起提交，成功后通知已打开右栏。路径登记只验证格式，管理链路不读取脚本正文、启动进程或发送会话输入。

0.1.36 Release 通过实际官方 Codex 客户端的 114 次定向 stdio 调用。捕获 33 项实际工具契约，原 29 项逐项完全一致，四项的 legacy schema 分支与 v12 一致。0.1.35 创建、删除并保存回执后，用同一份隔离数据在 0.1.36 中启动原版 0.1.35 桥，验证旧枚举、隔离、升级前回执和原编号幂等重交，再用新版桥验证独立审批、撤销和重启。

新版实测覆盖四类混排增查改删、脚本的缺省和清空别名、64 字上限、路径更新保留别名、关闭和追加 Enter 的显式 false 与省略保留。两行 `adb root`、`adb shell` 的 CRLF，以及另一条含 LF、引号和管道的本地命令保持原文。双方范围与错误版本拒绝、过期修订、跨区原子拒绝、同区批量首尾、旧锚点、丢应答只查回执、已打开右栏同步均核对。合成 SSH 输入无变化，模拟 ADB 调用文件及脚本执行哨兵均未产生，删除后原脚本的 SHA-256 保持一致。
