# P26.15 标签轮廓与快捷指令区内首末移动

按 [CR-038](../changes/CR-038.md) 实施。未选中标签共用原应用主题表面和 1 px 轮廓，保持现有 4 px 间距、单窗 31 px 与分屏 26 px 行高。选中标签沿原终端底色增加顶线。原会话身份、菜单结构、拖放、录制和关闭路由保持。

快捷指令首末移动选择所在区域的首项或末项，由原插入算法保存。边界禁用，其他项顺序不变。沿用本机快捷指令 revision 比较、失败反馈和明确重读。成功时焦点回到移动项的管理按钮。脚本、命令与执行入口保持。

实际 Windows WebView 隔离验证。0.1.25 menus 基线复现两条同地址 SSH 与两个本地标签未选中时缺少轮廓。0.1.26 对照浅色与深色、宽分屏和 720 CSS px 窄分屏，实际宿主 DPR 100%，窄分屏 150% 通过 WebView 模拟。覆盖名称、关闭按钮的尺寸与颜色、悬停、键盘焦点、只对一条回环 SSH 开关录制、滚轮与精确关闭、拖分屏、原草稿和标签加号。没有接入真实服务器或硬件。

快捷指令专项使用自建 ADB、BAT 和 CMD 文件验证置顶区单列、普通区双列和首末边界，检查原相对顺序、磁盘回读、并发版本拒绝及重启保留。以进程调用标记和脚本文件做零执行与文件保留核对。旧配置、批量与单步排序、隐藏折叠和原显式执行回归继续由同一专项检查。

初次专项通过直接保存为测试区域造数后尝试点尚未出现的冲突重读按钮，断言停在造数阶段。改由现有批量置顶操作准备两区域，再用测试服务模拟并发保存。最终版另同时核对 ADB、BAT、CMD，确认选中及未选中时，正在录制的 SSH 标签沿用同一红色状态标识。

最终 TypeScript、145 项前端测试、普通 desktop:build、Windows x64 锁定 Release 均通过。发布目录复验本地鼠标拖动、回环 SSH 双击复制和菜单样式及键盘，保留原精确路由。普通便携验证覆盖旧配置锁和复查、真实 stdio 33 工具发现和正常退出。

交付 `artifacts/SharedTerminal-0.1.26-windows-x64`，含三个 0.1.26 普通 EXE、README 和逐文件 SHA-256 清单。截图库和测量在 `windows-0.1.26-tabs-baseline.json`、`windows-0.1.26-tabs-result.json` 与 `windows-0.1.26-shortcuts-result.json`，另有 `windows-0.1.26-menus-regression-result.json` 和 `SharedTerminal-0.1.26-windows-x64-verification.json`。所有动作在独立数据根和自建会话中完成。
