按 [CR-035](../changes/CR-035.md) 实施。设置使用已有本地目录保护库的独立记录。旧记录无此项时采用默认右键行为，目录、快捷指令及通用会话偏好保持原存储格式。

## Windows x64 0.1.25 交付

普通 Release 目录为 `artifacts/SharedTerminal-0.1.25-windows-x64`，源码提交 `12df3f8`。候选目录通过普通启动、前版配置锁复查、真实 stdio 工具发现及正常退出。最终文件大小与 SHA-256 均与清单一致。前端 144 项及既有服务终端剪贴板 Windows 专项通过。

本地 Windows 专项从 0.1.24 打开的隔离数据目录升级，核对默认策略、模式切换即时生效及重启后保留。覆盖选区精确复制、复制失败后留选区、光标位置单行插入、两种右键行为、Ctrl+Shift+C/V，以及 CR、LF、CRLF 的预览、取消和确认。前台交付核对 PowerShell、模拟 ADB 和自建 CMD 的目标与输入，切走再切回、关闭原标签及任务结束后迟到回执均无写入。空闲轻量编辑器确认单行末尾换行，多个逻辑行展示说明并禁用确认。

早期试验发现浏览器默认快捷键事件与应用处理叠加，系统剪贴板单行文字进入一次隔离 PowerShell 草稿。测试立即中止，未发送 Enter，移除了相关失败截图和本地报告。最终构建阻止浏览器默认事件。回归使用受控剪贴板读写及原生剪贴板事件护栏，未读取原系统剪贴板正文。

正式报告为 `artifacts/SharedTerminal-0.1.25-windows-x64-verification.json`，配套截图为 `windows-0.1.25-local-right-click-settings.png`、`windows-0.1.25-local-right-click-menu.png` 和 `windows-0.1.25-local-paste-confirmation.png`。
