scripts/Test-Mcp.mjs 为协议/边界客户端；scripts/Test-Codex-Mcp.mjs 驱动本机实际 Codex app-server MCP 客户端。后者使用忽略目录的独立 CODEX_HOME 和临时命令行配置，不修改全局/项目配置、不复制认证、不创建用户侧栏聊天或模型任务。
