# P26.41 R4 SSH 和串口原生命令适配

按[全仓重构方案](../REFACTOR_PLAN.md)将 `ssh_request` 和 `serial_request` 从 Tauri 入口移至各自领域文件。[SSH](../../apps/desktop/src-tauri/src/ssh_commands.rs) · [串口](../../apps/desktop/src-tauri/src/serial_commands.rs)

移前移后逐字节比较命令体。注册名、State、JSON 类型和错误映射沿用原入口。每类请求继续穷举连接目标并在共享服务锁内校验窗口，再原序转发。会话服务内部的 SSH1 权限和操作级身份只覆盖特定请求，继续使用其独立规则。日志与保存命令另包处理。

## 验证

- [隔离窗口专项](../../scripts/Test-Desktop-ShortcutRoutes.mjs)用两个回环 SSH 会话运行。命令为 `node scripts/Test-Desktop-ShortcutRoutes.mjs EXE --window-commands --measure REPORT`。先用 P26.39 冻结结果。主窗只见自己连接，独立窗仅见被移交的原代次。固定连接状态查询区分窗口拒绝与服务层拒绝，独立窗口的无连接查询被拒绝。刻意压住移交前已准入的状态回复，核对实际命中一次。原回复仍绑定原连接，移交后的新主窗请求被拒绝。
- Rust 格式、26 项桌面 Rust 测试与 Windows x64 Release 构建通过。候选目录 `artifacts/SharedTerminal-0.1.36-refactor-P26.41`，桌面 SHA-256 为 `d5ff047837a61e5ab693d42a327aae1dd9285259f5522dcc414b3aa38827fb82`。普通服务和桥沿用 R0 哈希。
- P26.39 对照与本候选均通过窗口专项。固定状态在独立窗返回 `SESSION_IN_OTHER_WINDOW`，随机原编号从主窗转发后由服务返回 `PermissionDenied`。初次将该服务拒绝预期写为 `NotFound`，按对照证据更正，源码映射保持。
- 同哈希桌面配内存 UART 完成串口复制、取消及原端口独占检查。另在普通候选验证失联，按映像、PID 和父进程核对后，仅终止本次自建会话服务。桌面继续运行，两个命令适配层均返回 `SERVICE_UNAVAILABLE`。测试夹具保留在独立目录，普通候选使用普通服务。
