# P26.18 快捷指令别名和只读预览

按 [CR-041](../changes/CR-041.md) 实施，对照用户提供的 hover-preview.png 和 shortcut-alias.png。紧凑行只渲染名称，详情保留在显式展开。历史自定义名称使用原设置，无存储迁移。

命名清单冻结原设置 revision 和选择路径，一次确认提交同一个 CAS。现有 name 字段保存别名，空白用原文件名，超长时在 64 字符内保留扩展名。重命名或取消都不会打开脚本进程。原执行和 MCP 查询管理路径仍使用同一个保存记录，未增加 MCP 脚本内容入口。

原生预览只在主窗口接收严格 ID 与 revision 请求，使用已登记路径、已有本地盘/普通文件/重解析点与最终路径校验。一次只读一个有界前缀，最多 32 KiB，多读一个字节判断截断。返回前复核当前配置。UTF-8、BOM UTF-16 LE/BE 及当前 Windows ANSI 代码页支持，不支持的文本给出安全错误。前端将正文用纯文本、转义控制字符显示，配置过期、切换和后来指向其他条目均丢弃原应答。

初轮实窗验证发现长脚本正文继承全局 `pre` 高度和滚动限制。指针移入及滚轮事件正常到达卡片，卡片外层自身没有可滚动距离。修正后由卡片统一滚动，文件名、正文和编码信息同处一个滚动区。

0.1.29 Windows x64 Release 在自建数据目录通过系统多选及取消、别名提交和冲突、紧凑与展开、预览滚动和键盘进出、过期回复丢弃、缺失文件、重启及单击执行专项。长脚本卡片可视 358px、可滚动内容 16,128px。模拟 ADB、脚本启动计数和哨兵文件证实预览没有执行动作。编码专项实际覆盖 UTF-8、UTF-16 LE 和 Windows CP936。

同一便携目录通过 Windows 启动与原配置锁复查、快捷指令管理与菜单、真实 MCP stdio 查询和变更、BAT/CMD 与本地和 SSH 标签回归。TypeScript 检查、145 项前端测试和文档校验通过。未使用真实 Android、串口、用户数据或模型。

发布目录为 `artifacts/SharedTerminal-0.1.29-windows-x64`。快捷指令实窗报告为 `artifacts/windows-0.1.29-shortcuts-preview-result.json`，同前缀四张实窗图展示批量命名、仅名称列表、ADB 命令和脚本内容。便携验收为 `artifacts/SharedTerminal-0.1.29-windows-x64-verification.json`。
