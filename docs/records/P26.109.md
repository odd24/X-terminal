# P26.109 部署 Windows x64 0.1.40 到当前用户

根据 [P26.108 正式包](P26.108.md) 和 0.1.39 的 [部署流程](P26.88.md)，确认正式报告、ZIP 哈希及清单，使用同级独立暂存路径解压并核对五个文件，移入 `%LOCALAPPDATA%\Programs\SharedTerminal\0.1.40`。回读安装副本文件散列，确认桌面 PE 文件和产品版本、会话服务及 MCP 自报版本均为 0.1.40。

从安装目录以独立测试数据根实际启动。验证 0.1.39 的数据根锁与显式复查、配置回读、普通服务拒绝测试入口、同目录 MCP v14 的 33 项工具及未授权拒绝。桌面和服务以 0 退出，回执为 `ACKNOWLEDGED`。开始菜单主链接「共享终端」改指 0.1.40，回读目标、工作目录、图标和空参数。「共享终端 0.1.39」保留原链接作为回退，0.1.38 入口仍指原安装。

从发布开始到安装完成，既有桌面及服务各一个，PID、映像和启动时间逐项一致。安装复验使用独立数据根，默认用户数据沿用已有设置和锁。Codex 全局配置校验一致。证据位于 artifacts/P26.109-install，包括 deployment.json、installed-smoke.json 和 process-retention.json。Step-ID: P26.109。
