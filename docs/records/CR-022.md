# CR-022 桌面界面软件交付记录

2026-11-20 · Windows 桌面开发预览

## 实施

- A 将连接库开关、可滚动标签、新建、日志和更多放在同一行。无会话时中央提供两个入口。拖动侧栏分隔线或用方向键调宽。手动开合保存在 WebView 本地偏好，工作区按已保存布局恢复并等待用户连接。新配置库默认浅灰界面和黑底白字终端，已有配置库沿用原主题与终端配色。
- B 复用 SSH2 和串口连接状态机。主按钮原位反馈连接中，字段就地校验，进入 SSH 新建表单聚焦地址。沿用主机身份审核、认证补录、精确设备选择和原编号恢复。
- C 顶部与窗格右键共用日志菜单。有选区时右键复制该窗格的文本。菜单显示固定目标和保存范围，每个标签显示其当前代次的录制状态。保留缓冲排第一，可在起录前保存。存档沿用系统选择器和原覆盖保全。成功文件名及目录入口仅在原路由仍匹配时出现。
- D 更新[日常使用](../LOCAL_PREVIEW.md#基本使用)、[剪贴板操作](../ALPHA_USER_GUIDE.md#输入撰写与剪贴板)及[界面规则](../UI_GUIDELINES.md)。

## 2026-11-20 录制状态浮层自动收起

开始或停止记录的状态浮层每次显示 5 秒。原回执和后续状态更新使用同一个计时。自动收起和“收起日志操作”都保留原任务、正在进行的录制和顶部录制标记。“查看上次日志操作”按原服务及代次打开上次状态，重新计时。未完成任务继续按原编号查询。另存及同名覆盖仍等待明确操作。

隔离桌面中延迟真实起录回执后实测首次显示 5031 ms，再次打开 5028 ms。手动收起后核对同一记录编号、顶部和标签标记，以及实际文件后续增长。截图位于 artifacts/log-status-timeout-open.png 和 artifacts/log-status-timeout-dismissed.png。

停止录制在内存 UART 已完成同步后实测 5046 ms 收起。覆盖确认在 5200 ms 后仍可取消。实际桌面构建、136 项前端测试及完整 LogMenu 专项通过，专项结束恢复普通服务。实现 ac4359b 的独立预览实测启动、普通服务验证和退出通过，目录为 artifacts/shared-terminal-preview-a0bc9edc-7a4f-4907-869b-0a2a58032900，清单为 artifacts/log-status-timeout-preview.json。
