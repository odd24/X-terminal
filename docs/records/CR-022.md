# CR-022 桌面界面软件交付记录

2026-11-20 · Windows 桌面开发预览

## 实施

- A 将连接库开关、可滚动标签、新建、日志和更多放在同一行。无会话时中央提供两个入口。拖动侧栏分隔线或用方向键调宽。手动开合保存在 WebView 本地偏好，工作区按已保存布局恢复并等待用户连接。新配置库默认浅灰界面和黑底白字终端，已有配置库沿用原主题与终端配色。
- B 复用 SSH2 和串口连接状态机。主按钮原位反馈连接中，字段就地校验，进入 SSH 新建表单聚焦地址。沿用主机身份审核、认证补录、精确设备选择和原编号恢复。
- C 顶部与窗格右键共用日志菜单。有选区时右键复制该窗格的文本。菜单显示固定目标和保存范围，每个标签显示其当前代次的录制状态。保留缓冲排第一，可在起录前保存。存档沿用系统选择器和原覆盖保全。成功文件名及目录入口仅在原路由仍匹配时出现。
- D 更新[日常使用](../LOCAL_PREVIEW.md#基本使用)、[剪贴板操作](../ALPHA_USER_GUIDE.md#输入撰写与剪贴板)及[界面规则](../UI_GUIDELINES.md)。

## 验证范围

使用隔离的中文数据目录、回环合成 SSH 和内存串口。真实服务器和 COM 未纳入本轮。验收定义见 [CR-022](../changes/CR-022.md)。

## 软件回归

## 2026-11-20 暗色桌面反馈修订

SSH 与串口沿用同一标签轨，置于终端工作区顶边。活动标签与终端同色且共边，标签关闭、录制标记、键盘相邻切换和横滚保留。连接树使用紧凑行与更少的标题和搜索留白。xterm 预编辑使用浅蓝底、深色字及蓝色轮廓，定位样式和提交机制沿用 xterm。底栏常显目标与输入状态，异常同一行提醒，“连接与服务详情”在浮层展开，展开时终端高度不变。

同一 Windows 96 DPI 下，两条合成 SSH 会话、1100×760 WebView、深色跟随主题，逐项读取实际窗口和 xterm 行列数。

| 测量 | 上一预览 | 修订 |
|---|---:|---:|
| 标签与终端上边关系 | 活动标签在导航上方，标签底边 y=48，终端顶边 y=64 | 标签位于终端工作区，活动标签底边和终端顶边均为 y=45 |
| 连接库顶边至树列表顶边 | 140 px | 73 px |
| 连接行间距 | 47 px | 26 px |
| 底栏本体 | 47 px | 24 px |
| 终端底边到窗口底边 | 119.5 px | 40 px |
| 终端可见行数 | 94 列 × 30 行 | 94 列 × 36 行 |

比较原始数据位于 artifacts/CR-022-polish-before.json 和 artifacts/CR-022-polish-after.json。暗色实际截图为 artifacts/CR-022-polish-dark-desktop.png，亮/暗预编辑截图为 artifacts/CR-022-polish-after-light.png 和 artifacts/CR-022-polish-after-dark.png。用实际 WebView 的组合输入与提交核对预编辑在光标附近可见，拼音阶段零新增服务字节，最终恰好收到一次“中文”的 UTF-8 字节。Windows 中文输入法实际候选窗交互和 150% DPI 继续待人工验收。

实际桌面构建及 136 项前端测试通过。Navigation 在最终构建测定常规和 744×521 紧凑客户区，包含方向键、鼠标滚轮、原配置导航及详情展开。QuickSerial 首轮捕获串口连接完成与终端进入可见态的焦点竞争，随后改为等待原窗格和代次已渲染。最终 QuickSerial、Split、WorkspaceSplit 均通过，分别核对串口焦点和浮层入口、分屏输入未知时底栏提示、工作区恢复焦点。视觉构建已完成 LogMenu 全专项，覆盖录制标记、右键、系统文件与另存，无产品日志实现变化。
