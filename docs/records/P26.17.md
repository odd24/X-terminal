# P26.17 普通本地终端双击复制

按 [CR-040](../changes/CR-040.md) 实施。P26.13 为阻止刷机标签误复制关闭了所有本地标签的双击复制。0.1.27 在隔离 Windows 窗口复现双击仅选择原标签，右键菜单可创建第二个终端。

复用原有效双击判定、同步新建门及 native `open`。创建只取精确源标签的 `cwd`，模式来自源标签。native 会话重新初始化，前台任务、命令、草稿、历史和设备选择不从源继承。源关闭或移动时核对原窗格。脚本、独立 ADB 结果按创建来源区分；普通轻量标签的已知任务、等待启动和原回执待查不触发双击复制。原普通标签由 ADB 临时复用结束后可再次复制。

轻量命令行的 `cd` 更新 native 会话目录。PowerShell 的 ConPTY 进程用该目录启动，之后 PowerShell 内部的位置变更不回传给宿主。本包保留这一启动目录语义，不读取 PowerShell 命令、提示符或输出来判断目录或任意设备操作。

实际 Windows 隔离验证轻量 `cd` 后原目录、原草稿保留、双击仅一次原生打开请求，非有效点击序列不创建；PowerShell 用 `Set-Location` 实测源进程位置变化后，新进程仍从原启动目录打开，源 `Read-Host` 和输入保持独立。模拟 ADB 同时验证复用轻量标签忙时拒绝、结束后可复制及独立结果前后台均拒绝，日志中只有两次显式合成启动。BAT/CMD 专项验证双击后输入仍送到原任务。SSH、内存 UART 的双击及原右键入口通过，UART 同一占用端口仍不可复制。

初轮实体鼠标重排未观察到预期结果，测试改为用整个目标标签计算落点，并在落点停留等待事件。最终实体鼠标原栏重排、取消、分屏和跨窗格合并通过。方案 A 样式沿用，实体动作只对自有隔离窗口。普通调试及 Windows x64 Release 构建、TypeScript、145 项前端测试通过。

直接运行目录为 `artifacts/SharedTerminal-0.1.28-windows-x64`，含三件普通 EXE 与逐文件清单。正常便携验证覆盖旧配置锁复查、真实 stdio 33 工具发现及受管理退出。证据为 `windows-0.1.28-local-tabs-baseline.json`、`windows-0.1.28-local-tab-copy-result.json`、`windows-0.1.28-uart-copy-result.json` 和 `SharedTerminal-0.1.28-windows-x64-verification.json`。真实服务器、真实串口、Android 写入和用户会话未参与。
