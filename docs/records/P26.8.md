# P26.8 桌面快捷键

依据 [CR-031](../changes/CR-031.md)。桌面在 WebView 捕获阶段处理专用键，应用内标签编号取当前窗格实际渲染的标签栏。服务终端的焦点在原连接代次重新呈现后交回。本地终端沿现有独立渲染器立即恢复焦点。

本地查找使用已选标签的 xterm 保留缓冲区和原搜索器。切离该标签结束本次本地查找，关闭时清除选区、滚到现有输出底部并返回输入焦点。SSH 和串口沿用原查找，查找框 Escape 保留原工具入口焦点。

144 项前端测试通过。实际 Windows release 在明确前台验证窗口收到了 Ctrl+Tab、Ctrl+Shift+Tab、Ctrl+Shift+T/B/F、Alt+1/0 和小键盘 Alt+1。显示顺序在 10 个 SSH 与本地混合标签、拖动换序和分屏后核对。空缺编号无动作。受控本地前台进程跨切换继续运行，字节记录只含两个测试输入标记。回环 SSH 也只收到指定文本。普通编辑、模态输入和重复按键的操作阈值通过专用用例，AltGr 和 IME 状态由键分类测试覆盖。

从原生文件夹选择器保存自建中文目录，Ctrl+Shift+T 启动的 PowerShell 进程实际进入该目录，分屏中新标签也进入当前窗格。侧栏打开焦点进入列表，方向键跨项，按一次 Enter 分别触发一次模拟 ADB 和 BAT。脚本结果、轻量和 PowerShell 从已离开屏幕的原输出匹配，并回到底部和输入。使用独立内存 UART 服务验证旧串口查找、原输出字节和 Escape 焦点。

第一次实际窗口预检发现本地查找关闭后仍停在旧输出，后续执行的 ADB 结果位于可见范围之外。关闭时补齐回到底部的行为，最终实际键盘和缓冲区专项通过。旧 SSH 及串口保留原查找与焦点路径。
