# P26.85 修复 MCP 发布夹具的目标切换时序

首轮 0.1.39 解压门禁在 MCP 快捷指令专项的 v3 指令发送断言失败。夹具触发轻量命令行后只等侧栏按钮。连接中的 SSH 本来就有该按钮，因此夹具在本地标签完成前就发起了切回。故障证据显示发起发送时主窗格仍是本地命令行，回环 SSH 收到零字节。

夹具改成等待轻量终端正文就绪，切回后核对选中 SSH 标签及渲染代次。关闭授权面板，在同一原窗格点击发送，再重新打开授权面板核验撤权。保持只发送命令与请求回车的原始字节断言及所有授权断言。

在首轮 ZIP 的同一解压副本复跑完整 MCP 专项通过。原失败及复测位于 artifacts/P26.85-release。正式包重新执行全部门禁。本步以 Step-ID: P26.85 关联提交。
