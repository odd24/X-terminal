## Windows x64 0.1.23 交付

普通 Release 目录为 `artifacts/SharedTerminal-0.1.23-windows-x64`，入口 `shared-terminal-desktop.exe`。清单源提交 `0c4e2fc`。现场验收后重新核对了移动到交付位置的每个文件的大小和 SHA-256。目录验收报告为 `artifacts/SharedTerminal-0.1.23-windows-x64-verification.json`。

Windows 窗口专项验证悬停计时、移入与离开、Escape、方向键和 Enter。原生文件夹选择后，PowerShell 进程实际回报设置中的目录。分屏点击切换到指定窗格，并交回终端输入焦点。SSH2 专项覆盖保存、确认信任和登录、取消、拒绝主机、保存校验失败、重复点击和丢失保存回执。内存 UART 专项覆盖仅保存、确认指定设备后连接，以及端口占用时保留配置。专项使用独立中文数据目录和同一桌面文件，UART 服务为带 SHA-256 和库存识别的独立测试二进制。

普通目录通过 33 项真实 stdio 工具发现和旧读取边界，以及配置锁、本地输入、PowerShell、脚本、默认目录、标签拖动、人工和 MCP 快捷指令回归。前台占用造成的安全中止在同一候选目录复验，最终原生鼠标拖动与 13 次原生键盘组合均通过。前端 144 项测试通过。

专项报告为 `artifacts/windows-0.1.23-new-entries-result.json`，截图为 `artifacts/windows-0.1.23-tab-plus-menu.png` 和 `artifacts/windows-0.1.23-tree-serial-form.png`。
