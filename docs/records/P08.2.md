## 产物与实证

credential-vault Windows crate 提供 UUID 引用的 set/get/delete，独立 SQLite 只保存认证密文。当前用户 DPAPI 包裹每条记录的新随机 AES-256-GCM 密钥，完整头部作 AAD；未使用 machine scope，无密码/私钥进入配置库或参数/环境。0–64 KiB 不透明秘密、10000 条/库限额，更新事务化，get 前长度检查。Debug 脱敏、内存擦除与 native allocation RAII；详见 ADR-009。

真实测试覆盖保存/重开/更新/删除/未知引用，空密码/二进制/64 KiB/超限拒绝；读取 Debug 不显示内容；独立 Windows 进程只用测试路径/合成 UUID（不是秘密）重新读取并检查 stdout/stderr 不含标记。运行中的落盘文件及关闭后的库均扫描合成秘密明文标记，不存在。未把秘密序列化到 SQL 参数，落盘扫描是补充证据，不能证明所有操作系统分页/转储都无副本。

篡改试验最初直接 DPAPI 版本在头部第 8 字节改变时未拒绝；已据此改为 DPAPI 包裹随机密钥 + 标准 AES-GCM 认证整个记录。最终对合成记录每一字节翻转均 get 失败，截断、另一 ID/namespace 拒绝；恢复原始记录可正常读取。未知 schema、非 SQLite、空文件、非法存储 UUID、超长 blob 拒绝，文件字节不变。错误不被替换为空值。

全部数据为临时随机目录内合成内容，无真实密码/私钥。helper 在常规测试枚举中标记 ignored，仅由父测试使用 --ignored --exact child_read 显式执行；父测试成功已证明它实际运行，未把 ignored 数冒充独立通过数。清理限于本次建立并核对位于临时目录下的直属目录。
