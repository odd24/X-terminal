# P26.72 实现并验证 WebView 原生菜单过滤

按 [CR-053](../changes/CR-053.md) 和 [ADR-103](../decisions/ADR-103.md)，每个 WebView2 创建时注册原生菜单策略。普通页面请求由宿主处理，只有可编辑文本目标显示筛选后的原生命令。快捷指令区域的右键按下保持原焦点，管理按钮仍打开原菜单。应用自有菜单及快捷键保持原分派。

Windows x64 Release 构建、Rust 格式检查、前端类型检查及 158 项测试通过。实窗使用 WebView2 输入通道送入鼠标和键盘事件，并通过 Windows UI Automation 检查同进程树的原生菜单，排除网页内的业务菜单元素。原版正对照实际显示「返回」「刷新」「另存为」「打印」和「更多工具」。最终候选的快捷指令、空白处、配置弹窗普通文字和独立窗口标题上没有原生菜单。配置文本框经鼠标和上下文菜单键实际显示编辑项，并通过原生「全选」核对输入框选区。Shift+F10、上下文菜单键和 Ctrl+Shift+B 的应用相关路径通过。

实际复验会话树及主、独立窗口的终端业务菜单。运行原本地右键剪贴板专项和会话配置删除专项，覆盖两种本地右键模式、既有数据与审批边界，以及独立删除确认和不明结果的只读核对。

物理指针试跑因其他应用占据命中点被所有权防护拒绝。最终使用真实 WebView2 输入和原生菜单观察。剪贴板首次执行缺少工具链，已改用独立报告前缀，原历史通用报告从对应正式验证报告恢复。日志和结果位于 `artifacts/P26.72-context-menu`。
