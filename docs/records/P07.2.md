## 实际产物

session-service 独立普通用户进程，通过父进程匿名 stdin 帧接收 bootstrap；参数/环境/磁盘不传 bootstrap。建立带当前用户 SID 的受保护单 ACE DACL，明确 PIPE_REJECT_REMOTE_CLIENTS、首实例标记、句柄不可继承；客户端先用 GetNamedPipeServerProcessId 校验预期 PID，再发票据。

服务使用 P07.1 的同一会话领域和帧协议，支持版本握手、服务生成身份、最小配对/只读票据、共享输出和显式 fixture 生命周期。默认关闭 fixture，不打开 SSH/串口；所有未实现真实传输保持缺失，不假成功。32 个客户端与 JoinSet 任务条目上限，完成条目及时回收；启动时拒绝 elevated token。先补建监听实例再交给连接任务，避免首实例句柄断档。握手 5 秒、空闲客户端 30 秒、发送 5 秒截止；本地请求出错/超时丢弃 IPC 连接，不自动重放。

Bootstrap 只存在于进程内存，服务重启后没有连接/票据恢复。桌面客户端断开不会删除服务中的连接；原生 WebView 重载与桌面默认退出策略由 P07.3 补齐。

6 个跨进程测试覆盖：两个客户端读取同一 connection_id/generation 与字节；UI 客户端断开再连接保留输出；只读票据不可写/签发/跨连接，重连不继承、撤销/过期逐请求拒绝；版本/token/PID/先发业务帧/超限帧拒绝；默认 fixture 禁用；重复服务实例失败而原服务可继续使用；输出覆盖报告 available_from/truncated；33 个未握手连接受总 32 上限约束，已授权客户端仍响应；杀死服务后客户端失效，新服务不恢复连接或旧票据。

最终集成测试约 1.64 秒，重复实例的 stderr 错误 5 是预期负向结果，不是主服务失败。测试输出只有合成数据/类别，没有保存真实 SID、票据、设备日志。

## 风险、边界与回退

ACL 不抵御同账户恶意进程，SID owner 本身可改权限；PID 校验避免给普通假端点发送票据，不是进程完整性证明。远程拒绝由实际 CreateNamedPipe 标志与 Windows API 语义保证，未做远程网络用例，P22/P23 可补充。完整 Agent 写授权/租约/去重仍在 P14；当前只有桌面和只读观察者。

当前故障反馈为固定协议错误/客户端 I/O 类别和启动诊断；持久日志/审计在 P11/P14，不记录请求正文。服务 shutdown 会关闭所有 IPC；真实活动连接的退出提示尚待 P07.3/P12。
