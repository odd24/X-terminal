# P26.88 部署 Windows x64 0.1.39 到当前用户

核对 [P26.87 正式包](P26.87.md) 的 ZIP 校验文件、正式验证报告与发布清单。解压到当前用户程序目录内的同级独立暂存路径，回读五个文件的字节数和 SHA-256，再移入 %LOCALAPPDATA%/Programs/SharedTerminal/0.1.39。安装副本的桌面 PE 文件和产品版本、服务及 MCP 桥自报版本均为 0.1.39。

主入口切换前，以安装副本和独立数据根通过烟雾测试。核对 0.1.38 配置目录锁及显式复查、配置与偏好回读、普通程序拒绝夹具、同目录 MCP v14 的 33 项工具及未授权拒绝。桌面和服务均以 0 退出，停止回执为 ACKNOWLEDGED。

原子切换当前用户开始菜单「共享终端」至 0.1.39。回读目标文件、工作目录、图标和空参数。原快捷方式实字节保留为「共享终端 0.1.38」，旧安装清单与四个文件的散列一致。部署开始时的一个既有程序进程在收尾时保持相同 PID、映像与启动时间。全局 Codex 配置文件前后校验一致，已有 shared-terminal 注册继续采用 [P26.66](P26.66.md) 的 0.1.38 参数。

证据见 artifacts/P26.88-install。安装过程使用隔离数据根，实物和长稳覆盖见 [P26.87](P26.87.md)。Step-ID: P26.88。
