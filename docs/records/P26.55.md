# P26.55 实现右栏快捷指令描述与 MCP v14

实施 [CR-050](../changes/CR-050.md) 和 [ADR-101](../decisions/ADR-101.md)。右侧栏本地、ADB、发送和脚本指令共用描述输入，批量导入时按脚本填写。换行统一为 LF，最多 500 个 Unicode 标量值，纯空白按省略处理。紧凑列表保持原行高，描述在悬停、键盘焦点和全部展开的预览中先于正文呈现。脚本加载和失败时描述仍可读，迟到响应按原条目、配置修订和预览作用域校验。

Windows 保护存储按快捷指令 ID 单独保存描述，将配置、描述和 MCP 回执原子写入。旧版读取原记录，保存已有 ID 后新版依旧可以读取其描述。四个快捷指令工具保留原工具名，新增 `version: "v3"` 和独立的描述读取、管理授权。更新省略字段保留原值，传空字符串、纯空白或 `null` 清除。旧请求、旧回执和过去工具快照保留兼容语义；请求版本变化导致的编号复用由原回执冲突规则处理。

## 验证

- 前端 lint 和 158 项测试通过，Rust 格式检查、桥测试以及 Windows 保护存储测试通过。Release 构建包含实际桌面、会话服务和 stdio 桥。
- 最终桌面候选通过隔离数据根的快捷指令专项，包括真实文件选择、脚本逐项描述、500/501 字边界、加载及失败预览、迟到响应、重启和 0.1.37 旧桌面编辑后回读。
- 用候选桥捕获 [v14 工具快照](../../contracts/mcp/v14-tools.json)。实际 stdio 验证新旧作用域、v2 与 v3 投影、新增和更新、长度和修订检查、旧回执、丢失响应后查询及编号重放。回环 SSH 夹具核对显式发送的原命令字节。

本机证据位于 `artifacts/P26.55-descriptions`。使用隔离 Windows 会话、合成 SSH 和模拟 ADB，覆盖范围未包含物理设备或长稳。通过提交正文的 `Step-ID: P26.55` 关联。
