# P26.11 会话控件视觉修复

按 [CR-034](../changes/CR-034.md) 修复两个标题图标的对齐和会话关闭叉的可读性。关闭按钮的图形与点击区独立，悬停填色以其前景色在标签背景上合成。当前 WebView 支持自动对比色时按实际终端背景计算，其他 WebView 使用与内置配色对应的黑白值。

Windows 专项使用实际 Desktop、回环 SSH、内存 UART 和本地轻量终端。覆盖主题、缩放、对比度、焦点、菜单、刷新、精确关闭及拖动隔离。

## Windows x64 0.1.24 交付

正式 Release 目录为 `artifacts/SharedTerminal-0.1.24-windows-x64`，源码提交 `d31d4ff`。目录复验通过普通启动、前版配置锁与复查、真实 stdio 的 33 项工具发现和正常退出。最终四个文件的大小及 SHA-256 与清单一致。交付报告为 `artifacts/SharedTerminal-0.1.24-windows-x64-verification.json`。前端 144 项测试通过。
