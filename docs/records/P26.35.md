# P26.35 窗口快捷指令执行协调

用户在 P26.34 交付后要求继续执行，按 [P26.33 第二轮](P26.33.md)实施现有快捷指令的执行协调。起点为 `3b85e76`。

## 责任与回执

| 入口 | 谁负责 |
|---|---|
| 点击指令 | 主窗口从活动窗格取得本地标签，或服务标识和协议、连接 ID、代次。协调模块使用这次点击的来源、按钮 ID 与设置修订。 |
| 向当前会话发送 | 异步取回文本后复核路由版本、选中目标和可写状态，再向该窗格的控制器派发。来源关闭、切换或换代时丢弃迟到文本。 |
| Windows 命令或 ADB | 窗口级启动槽在第一个异步操作前占用。仅传统 ADB、原本地提示符空闲、无草稿且未启用成功关闭时复用。其余按原逻辑创建结果标签。设备选择、取消、终端交互与未知回执查询仍在结果标签中。 |
| 本地脚本 | 交给原有本地打开入口，以按钮 ID 和修订启动。结果标签记录最初来源。启用成功关闭时由原生任务终态触发，关闭的是本次结果；还停在结果标签且来源有效时才返回。 |
| 连续启动与诊断 | 启动结束按请求号结算。关标签仅释放该结果占用的启动槽。诊断仅接受该按钮最近请求的回执。 |

窗口协调在 [shortcut-execution.ts](../../apps/desktop/src/shortcut-execution.ts)，主窗口装配在 [main.tsx](../../apps/desktop/src/main.tsx)。本地原生调用、输入草稿与设备选择仍在 [local-terminal.tsx](../../apps/desktop/src/local-terminal.tsx)。未新增配置字段、MCP 接口或改变安装注册。

## 验证方法

- `npm test` 覆盖 152 项，其中四组新增测试覆盖 A 发起、B 运行、用户切至 C 后完成，异步读文本时来源关闭／换代，重复启动、迟到诊断与回执、草稿和任务复用边界、打开失败释放以及脚本修订。
- 按 README 构建 Windows x64 Release。在普通三程序复制目录运行 `Test-Desktop-ShortcutRoutes.mjs EXE --verify-reads`；内存串口在独立目录复制同一个桌面和经过哈希校验的测试服务，运行同一脚本加 `--uart`。两者使用隔离数据根和模拟 ADB。

## 实测与交付

| 环境 | 观察结果 |
|---|---|
| 回环 SSH | 当前会话快捷文本只收到一次；故意延迟读取后切到另一连接，两端均未收到迟到发送。模拟 ADB 两行依序执行，交互 Shell 能继续输入，Ctrl+C 能中断。脚本退出 0 按选项关闭，退出 7 保留；在 C 标签等待 B 完成，B 自动关闭后焦点仍在 C。 |
| 内存 UART | 串口只收到预期文本与一个回车。快速连点仅打开一个结果标签；取消多设备选择只记录一次枚举。随后单条 ADB 与两行管道均可从串口侧栏在 Windows 执行，源串口保持连接。 |
| Windows 本地终端 | `Test-Desktop-LocalAdb.mjs` 通过。已验证有草稿或有前台任务时新开标签、原工作目录继承、无设备／未授权／设备消失、多设备取消，以及导出文件实际字节。 |
| 异步边界 | 来源关闭、同 ID 换代、服务变化和迟到诊断由协调模块确定性测试覆盖。物理设备未参与本轮验收。 |

第一次类型检查发现旧可写判断在缺少服务时会返回空字符串，已改为返回布尔值；随后类型检查、前端生产构建、Windows x64 Release 构建、152 项前端测试及上表桌面专项通过。本机原始报告位于 artifacts 下的 `P26.35-windows-0.1.36-shortcut-routes-ssh.json`、`P26.35-windows-0.1.36-shortcut-routes-uart.json`、`P26.35-local-adb-software-result.json` 与 `P26.35-unit.txt`。

普通候选目录为 `artifacts/SharedTerminal-0.1.36-refactor-P26.35`。三个程序已与本次 Release 输出逐一核对，桌面 SHA-256 为 `ee191acaa350820695a4603ed6be346dfbce210a61e19e5c60ec03c8730aa829`。本次完成 P26.33 第二轮，保留现行安装。若出现重复派发、结果误关或来源错配，按 Step-ID 定位本包并新建 revert 提交，在 P26.34 候选上复跑同一失败用例。本轮验证针对行为兼容；性能对照与回显待跟踪项见 [P26.34](P26.34.md)。
