# P26.118 清理无引用的旧安装和重复构建

在 [P26.117](P26.117.md) 核验 0.1.41 安装后，通过 Codex CLI 回读 MCP 版本依赖，核验产品进程、开始菜单目标、实际绝对路径、正式清单及逐文件 SHA-256。移除旧的 0.1.39 用户安装目录及对应开始菜单快捷方式，共 6 个文件、40,257,734 字节。保留 0.1.39 正式便携归档。

另移除 50 个发布暂存 EXE 和 10 个试用构建 EXE。每个文件都有散列及大小一致的正式或候选副本。保留暂存报告、截图、不同内容的试用和验证证据、正式归档及依赖。首轮移除 66 个文件、814,578,886 字节。删除后复核全部路径、保留副本散列、0.1.41 ZIP、主入口和既有进程。清单及回读位于 artifacts/P26.118-cleanup。

首轮结束时，0.1.40 桌面和会话服务仍运行，0.1.38 被 Codex 全局 shared-terminal 的两个启动路径引用。等待用户确认退出及迁移后再继续。Step-ID: P26.118。

## 旧版退出与全局 MCP 切换

用户确认旧窗口已退出并授权继续清理。核对旧桌面、服务及桥进程均已退出。按 [现有注册切换方式](P26.66.md)，原子替换全局 shared-terminal 条目的首选和回退参数，Codex CLI 回读两者均指向已安装的 0.1.41。除这两个路径外，全局配置内容、启动器和注册属性保持一致。

用回读的实际启动器和参数，从独立数据根连接 0.1.41 自有窗口。核对 terminal-mcp.exe 映像与父进程、v14 的 33 项工具、未授权会话和快捷指令访问被拒绝。清理前后各通过一次，取得 ACKNOWLEDGED 退出回执，并清理本次测试数据根。未打开用户数据根。

移除 0.1.38 和 0.1.40 的两个用户安装目录及对应旧快捷方式。本次收尾移除 12 个文件、81,380,066 字节。两轮累计移除 78 个文件、895,958,952 字节。清理后复核旧路径均不存在，当前用户仅安装 0.1.41，「共享终端」仍指向新安装。用户数据、保留的正式档案、验证证据及新安装散列均通过相应核验。收尾证据位于 artifacts/P26.118-cleanup，含注册读回结果、前后桥接实测、移除清单及最终校验。Step-ID: P26.118。
