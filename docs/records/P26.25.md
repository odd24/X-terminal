# P26.25 本地命令组输出

按 [CR-048](../changes/CR-048.md) 在 0.1.34 基础上精简结果标签。解析时把原输入行与解析后的执行阶段一同保存。主进程开始执行一步时输出原文，按原来的顺序转发子进程字节。移除每步「开始」「完成」横幅。保存的引号、管道及显式设备参数留在回显里，执行时增加的参数和本机包装由原运行器处理。若前一段输出没有换行，下一条回显先插入一处行分隔，跨桌面读取也保留该边界。

保留运行环境、固定设备、必要重连和出错提示。最后一步的裸 ADB Shell 使用 P26.24 的原生交互路径，继续接受终端输入。退出结果、失败阻断后续步骤和按项成功关闭沿用原规则。

实窗验收使用合成回环 SSH 与模拟 ADB，禁止调用真机 root。对照每条回显、模拟设备的实际输出和终端输入，另查没有末尾换行时的输出、原本机筛选管道、非零退出、超时、中断及自动关闭。

Windows x64 0.1.35 Release 实窗中，`adb root`、`adbd is already running as root`、`adb shell`、模拟提示符经逐行断言连续显示。随后观察到 `pwd` 键入回显和目录输出，实际退出后两条原命令仍各一次。失败管道后的步骤未执行和回显。调整尺寸、失败保留结果、零退出按项关闭、Ctrl+C、重连等待和固定设备回执均通过。首轮回显验证已通过，但调整尺寸使旧行移出可见区，导致退出后的可见行计数失败。将调尺寸和完整回显分到两个受控运行后，原 Release 通过全部断言。
