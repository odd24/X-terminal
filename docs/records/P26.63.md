# P26.63 部署 Windows x64 0.1.38 到当前用户

2026-11-24 验证 [P26.62 正式包](P26.62.md) 的 ZIP、发布报告、清单和五个文件的散列。通过同级独立暂存目录安装到 `%LOCALAPPDATA%\Programs\SharedTerminal\0.1.38`。安装后的桌面文件和产品版本、会话服务与桥报告的版本均为 0.1.38，五个文件与发行件一致。

在切换前从安装目录运行 Windows 隔离烟雾测试。0.1.37 配置锁与显式复查、旧配置和偏好回读、同目录 v14 的 33 项工具、未授权拒绝、普通程序拒绝夹具入口及正常关停均通过。桌面和服务以 0 退出，关停回执为 `ACKNOWLEDGED`，测试数据根已清理。

原子切换开始菜单「共享终端」，实际回读目标、工作目录、图标和空启动参数。保留本步开始时既有的 0.1.12、0.1.22、0.1.36 版本快捷方式及被抽查的 20 个旧安装文件，旧桥的 PID、映像路径和启动时间一致。首次进程比对误将 JSON 时间解析为本地格式，使用原 ISO 字符串回读后核验一致。未使用默认数据根或写入全局 MCP 注册。按用户追加的卸载要求，无新增 0.1.37 开始菜单入口，旧版清理另记。

安装及烟雾证据位于 `artifacts/P26.63-install`。本步以 `Step-ID: P26.63` 关联提交。
