# P26.45 R6 SSH 输入接纳和传输边界

按[全仓重构方案](../REFACTOR_PLAN.md)把 `enqueue` 和 `enqueue_from` 迁入 [Manager 输入模块](../../crates/session-service/src/ssh/input.rs)。逐字核对两段实现。Manager 内部锁与 Store 锁的先后、身份与接管检查、协议限制、请求指纹、原回执查找、有界队列预留和发送均沿用原顺序。

评估 [Actor](../../crates/session-service/src/ssh.rs) 的认证职责后，保留 `run_as` 的现有边界。同一事件接收器从首轮网络授权经过主机密钥复核、认证挑战进入 shell，还处理重新协商和取消。现在拆开会增加多处中间状态交接。串口设备释放与 join 继续由独立串口工作线程负责。

- Windows x64 Release 服务构建与格式检查通过。服务 SHA-256 为 `0fd49faffd861ccb9310cb16c6a159e59bfd79650da7311fc1277682438f3ad0`，与同版桌面和普通桥一起交付在 `artifacts/SharedTerminal-0.1.36-refactor-P26.45`。
