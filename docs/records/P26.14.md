# P26.14 全应用自绘菜单统一

按 [CR-037](../changes/CR-037.md)。只读盘点由 ToolbarMenu、ContextMenu、会话标签原独立浮层与工具菜单内诊断构成。计入顶部更多工具和日志、标签与配置加号、配置树与会话标签右键、快捷指令加号与管理、SSH 工具中的更多会话操作、本地终端右键。原生选择器、下拉、侧栏列表、终端和表单折叠采用原控件。

共用工具栏外观和菜单行、可用动作搜索、方向键和首尾导航。鼠标悬停展开和键盘接管分别维持各自关闭行为。右键菜单按原指针位置避让，按钮型从锚点上下选择位置；超高在菜单内滚动。状态说明单独换行，既有快捷键随对应动作显示。保持会话路由、原请求编号、草稿和剪贴板确认流程。

实窗专项使用 0.1.25 标签修复版实测旧工具栏。第一轮在同一浅色主题、100% DPR 下比较原工具栏尺寸和样式，新版工具栏、标签加号、配置树右键、快捷指令管理截图成组，另采集本地复制粘贴。第二轮在同一 Windows WebView 使用 CDP 模拟 150% DPR，720×360 CSS 视口内的深色窄分屏，验证靠边、长日志菜单滚动、主操作、禁用跳过、Enter、Escape 和焦点归还。宿主真实 DPR 为 1，未更改 Windows 系统缩放。仅自建测试数据、脚本、模拟 ADB 及回环 SSH。

最终 TypeScript 检查、144 项前端测试、实际 desktop:build 和 Windows x64 Release 构建通过。菜单键盘专项还验证打开日志菜单没有新录制，并通过菜单显式启动和停止同一回环 SSH 的记录，100 行的首尾都在同一同步完成文件。实际 Windows 回归通过本地 Smart/菜单剪贴板模式、原始输入与迟到回执、实体鼠标拖动和原草稿、SSH 与本地混排和双击复制、BAT/CMD 隔离输入。标签加号和配置加号的专项另用独立内存 UART 服务验证原生表单、合成 SSH、已保存配置及固定模拟端口，发布目录仍用普通服务。

Windows x64 直接运行目录为 `artifacts/SharedTerminal-0.1.25-windows-x64-menus`。本版沿用 0.1.25 版本号并使用独立目录。同目录普通服务和 MCP 沿用已验证的 0.1.25 文件。发布烟测通过配置锁复查、真实 stdio 33 工具发现和正常退出。逐文件校验以同目录 manifest.json 为准。

主报告 `artifacts/windows-0.1.25-menus-result.json` 包含 13 处实测菜单表面、同版二进制 SHA、截图名和验收项。第一轮截图前缀 `windows-0.1.25-menus-01` 至 `05`，第二轮 `06` 至 `08`。配套报告为 `SharedTerminal-0.1.25-windows-x64-menus-verification.json` 和 `windows-0.1.25-menus-regression-new-entries-result.json`。
