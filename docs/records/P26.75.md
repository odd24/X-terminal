# P26.75 实现本地终端文件拖入

实现 [CR-054](../changes/CR-054.md) 和 [ADR-104](../decisions/ADR-104.md)。主窗口按 Windows 原生坐标定位本地正文，高亮、取消和过期均按同一窗格与编辑目标处理。轻量命令行使用原草稿和光标，PowerShell 使用当前 PSReadLine 缓冲区及原输入队列。拖拽数据全程有界，拒绝控制字符及无法形成独立参数的位置。

158 项原前端单测及 2 项新增路径单测通过。Windows x64 Release 专项使用自建 OLE CF_HDROP 文件来源和受限合成指针，验证目录、多项文件顺序、实际路径字面量、手动回车前的草稿、取消、前台 Read-Host、标签栏、双窗格未聚焦落点和收起后的旧目标。另用独立 Tauri 事件注入复验同一输入边界。原生来源为本地测试窗体，Explorer 人工操作、真实 SSH/串口和其他 DPI 或系统环境另待覆盖。

证据见忽略目录 artifacts/P26.75-file-drop。候选与最终程序散列在 P26.76 登记。本步以 Step-ID: P26.75 关联提交。
