# P26.38 R1 标签拖放和窗格状态

按[方案 R1](../REFACTOR_PLAN.md)推进，以 [R0](P26.37.md) 的 P26.35 候选为对照。主要入口为[手势](../../apps/desktop/src/session-drag.tsx)、[窗口](../../apps/desktop/src/main.tsx)和[窗格模型](../../apps/desktop/src/pane-layout.ts)。

| 操作 | 执行顺序和归属 |
|---|---|
| 同窗排序、相邻插入 | 窗口先计算可用锚点下的候选顺序，再提交分组及顺序，沿用原标签选择规则。 |
| 合并和移出最后一项 | 模型在本地标签移入目标后判断是否关闭空源窗格。远程标签继续走原连接归属及替代选中规则。 |
| 本地与远程分屏 | 模型校验目标窗格与容量。单独占用的窗格允许复用原窗格键，远程分屏还验证当前服务、协议和代次。四窗格满额且无法复用时保持原状态。 |
| 原生移交和焦点 | 手势提交时带回指针按下时的服务标识。窗口校验当时和目前的服务后，沿用原生分离／停靠；本地移动和远程分屏沿用各自焦点处理。 |
