# P26.22 脚本快捷指令菜单

按 [CR-045](../changes/CR-045.md) 调整首项可见名称和菜单项可访问名称。编辑复用原表单和配置修订检查。「打开文件所在位置」调用主窗口专用原生入口，复用已登记脚本的本地路径校验和配置版本。选中优先使用 Windows Shell 的项目标识，失败时只打开父目录。

验证范围为实际 Windows 菜单键盘操作、名称和自动关闭保存及重启、真实资源管理器选中自建中文文件、失效引导、脚本完整性、普通便携启动和关闭。使用自建数据根和脚本。

Windows x64 0.1.32 Release 上，真实 Explorer 选中带中文、空格和逗号的已登记脚本，编辑及定位期间原文件与设置保持，快捷执行计数为零。过期版本、非脚本编号及附带路径参数均被拒绝。移动后的原路径提示「重新定位」，后续重新定位保留原入口。结果页「打开工作目录」通过原 Explorer 验证。

同一桌面校验值通过菜单键盘专项、脚本保存和只读预览专项。重启保留更改后的名称及自动关闭设置，显式运行成功后只关闭本次结果。菜单专项的拆窗落点更新为现行窗格几何，缺失预览用键盘焦点验证以隔离桌面指针移动。普通便携启动、同目录 MCP 33 项发现和受管理退出通过，TypeScript 和 145 项前端用例通过。
