# P26.5 本地标签与双击复制

依据 [CR-028](../changes/CR-028.md)，本地会话使用现有窗口内标签拖动手势。移动复用同一个渲染器及其原生会话。双击新建独立本地终端。服务会话从原有复制路径读取精确来源及连接设置。

139 项前端测试通过。实际 Windows x64 构建通过本地终端专项和合成 SSH 专项。原复制整套脚本带有旧版工具栏位置断言，运行到该断言停止，保存配置的后台 SSH 复制步骤已通过。本轮的标签专项使用同一真实窗口和回环 SSH 测试设施，验证同窗分屏中的双击复制、独立输入、临时 SSH 正常认证，以及本地和 SSH 标签同栏排序、跨窗格移动和混合分屏。

打包候选目录复验 0.1.17 配置锁、受管理退出、MCP 官方客户端读取、轻量模式、模拟 ADB、PowerShell、批处理入口和本地默认目录。实际拖动和双击专项在候选目录通过，同一 xterm 节点和草稿在分屏及合并后保留。交付只含直接运行目录，未生成 ZIP。没有使用真实串口或远程主机。

入口为 artifacts/SharedTerminal-0.1.18-windows-x64/shared-terminal-desktop.exe，构建源提交 4eb8d99。证据见 artifacts/SharedTerminal-0.1.18-windows-x64-verification.json 和 artifacts/windows-0.1.18-session-copy-ssh.json。

## 2026-11-22 本地标签与脚本会话回归修复

0.1.21 用自建 CMD 脚本复现双击脚本标签额外打开空白终端；同一机器上的普通本地标签原生鼠标拖动复验通过，现场拖动失败未复现。修复将本地和 SSH 的拖动入口统一到共享指针手势，要求同一标签的两次有效点击才允许双击复制，脚本标签双击只选中原会话。

144 项前端测试、前端构建与 Windows x64 Release 构建通过。修复目录通过 Windows 原生鼠标排序、分屏、跨窗格合并、取消及保留原本地草稿专项；自建 BAT/CMD 验证脚本重排与双击后的原标签、标签总数和前台输入；合成回环 SSH 验证本地混排、双击复制和独立输入。证据见 artifacts/local-tabs-software-result.json、artifacts/local-scripts-software-result.json 和 artifacts/windows-unpacked-session-copy-ssh.json。

修复入口为 artifacts/SharedTerminal-0.1.21-windows-x64-tab-fix/shared-terminal-desktop.exe，同目录服务和 MCP 来自已验证的 0.1.21 交付目录。桌面基于既有 0.1.21 原生源码构建并嵌入本次前端修复，排除了工作区尚在开发的 MCP 快捷指令变更。验证使用自建脚本、模拟 ADB 和回环 SSH。
