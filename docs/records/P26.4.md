# P26.4 本地终端默认目录

按 [CR-027](../changes/CR-027.md) 从 0.1.16 更新。设置入口为「更多工具 → 软件设置 → 本地终端」。原生选择器保存绝对路径，恢复桌面保存跟随 Windows 的选择。缺少设置的已有数据目录自动使用当前用户的桌面。已保存路径不可用时保留选项，在设置和新标签显示回退提示。桌面也不可用时再检查 Windows 当前用户的主目录。

默认目录只用于普通新建。已开标签不重新定位，ADB 结果沿用来源标签原有目录规则，BAT 和 CMD 使用脚本所在目录。

## Windows 实测

实际 Windows x64 release 构建和 138 项前端测试通过。专项用隔离数据目录运行普通桌面。当前用户的桌面实际重定向到 E 盘。空态和加号入口的 Windows PowerShell 用实际 Get-Location 核对，轻量命令行用实际标签目录核对。原生选择器选中带空格的中文目录后即时保存，取消保留原选择。两个已开标签继续使用原目录，两个新建模式使用所选目录，重启仍能读取。删除自建空文件夹后，设置与两个新标签均提示并回退到桌面。恢复桌面并再重启后，两个模式回到桌面且无回退提示。

构建时修正了 Windows UTF-16 转换的错误类型。桌面验证先后定位到文件夹选择器编辑控件与文件选择器不同、中文长路径提示符折行和退出确认的渲染时序。更新测试驱动后，验证了原生按钮和真实 PowerShell 目录。未改变对应的产品断言。

交付候选目录复验启动、0.1.16 配置锁与复查、受管理退出、MCP 官方客户端读取、轻量模式、模拟 ADB、PowerShell 和本地脚本。模拟 ADB 核对实际导出目录和结果标签，批处理专项核对脚本进程的实际工作目录。OneDrive 重定向、实际 ACL 拒绝与桌面不可用时的主目录回退未在本机单独模拟。本轮未使用真实设备。
