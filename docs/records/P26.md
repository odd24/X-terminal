# P26 Windows 本地命令行与 ADB 快捷操作

基线 Windows x64 0.1.12。范围由 [CR-023](../changes/CR-023.md) 确定。原生设计见 [ADR-099](../decisions/ADR-099.md)。

## 两阶段实现

- 本地标签独立 Windows 目录、草稿与历史，直接启动单条本机程序。ConPTY 按标签管理前台输入、输出、尺寸与释放。界面在现有「＋」增加入口，顶部工具栏沿用原布局。
- ADB 按钮按数据根持久化，复用本地执行器。有草稿或前台任务时新建结果标签。设备选择按点击冻结的命令和明确序列号进行。

Windows 11 Pro 22631 隔离普通开发构建通过本地及 ADB 两项 WebView 专项。前端既有 138 项单测通过。软件报告分别为 artifacts/local-terminal-software-result.json 和 artifacts/local-adb-software-result.json。

首轮测试中，Desktop 的重定向标准句柄被 Windows 复制到子进程，ConPTY 有标题但没有实际命令输出。显式指定空标准句柄后由 ConPTY 建立自己的流，Git、Fastboot 和可控程序实际输出通过。另保留回车进件、目录短路径归一化和测试等待边界的失败记录。[Microsoft Terminal 维护者对标准句柄的说明](https://github.com/microsoft/terminal/discussions/15814)

受控开发构建的首次本地输入为 59.83 ms，后 10 次中位数 77.46 ms、最大 86.56 ms。同宿主 PowerShell 首次 585.99 ms，后 10 次中位数 619.26 ms、最大 667.69 ms。可控进程回显 10 次中位数 66.05 ms、最大 125.55 ms。包含测试驱动和观察间隔，原始数据见 artifacts/local-terminal-performance-result.json。主机 ADB 为 1.0.41，Platform Tools 36.0.0-13206524。设备场景使用可控替身。
