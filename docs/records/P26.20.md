# P26.20 本地标签双击及发布门

按 [CR-043](../changes/CR-043.md) 恢复普通本地终端标签双击，沿用已登记的目录继承、新终端实例与明确的右键复制。轻量会话实时状态和快捷指令在途编号用于阻止任务占用时的复制。

共享标签手势判定要求两个可信鼠标按下和释放各自对应标签点击。拖动跨过阈值、离开按钮后释放、取消、窗口失焦、键盘或其他控件打断时清除点击序列。原来已纳入发布脚本的本地标签专项判定补上普通实体双击，再将 SSH 混合分屏和受控快捷指令预览纳入同一候选文件的 SHA-256 核对。

Windows x64 Release 预检确认普通 PowerShell 的原生点击序列为两次 click 与一次 dblclick，恰好新增一个原生打开请求。轻量命令行复制继承跟踪目录，拖动后即使 WebView 生成可信双击事件也不新增打开请求。原生排序、取消、跨服务首帧拖动、跨窗格合并、模拟 ADB 在途与结果标签、单次右键复制通过。鼠标助手最初的逐步发送受到系统指针移动干扰，改为先核对命中窗口，再成组送入 Win32 鼠标事件。调试者与用户窗口未参与。TypeScript、145 项前端用例和实际 Release 构建通过。

正式门使用 `Prepare-Windows-Portable.ps1 -DirectoryOnly`。成品目录为 `artifacts/SharedTerminal-0.1.30-windows-x64`，校验和测试明细由相邻的 `SharedTerminal-0.1.30-windows-x64-verification.json` 记录。验证限自建终端、合成 ADB 和回环 SSH。
