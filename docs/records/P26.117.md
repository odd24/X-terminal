# P26.117 部署 Windows x64 0.1.41 到当前用户

根据 [P26.116](P26.116.md) 的正式报告、ZIP 散列和清单，在安装根下用临时目录解压并校验五个文件，移入 %LOCALAPPDATA%\Programs\SharedTerminal\0.1.41。从安装目录回读散列、桌面 PE 版本、服务和 MCP 自报版本。

从实际安装目录以隔离数据根启动，验证旧版锁及显式复查、正常配置读取、普通服务拒绝测试入口、MCP v14 的 33 项工具及未批准拒绝。桌面和服务均以 0 退出，受管回执为 ACKNOWLEDGED。原子更换开始菜单「共享终端」主入口，回读目标、工作目录、图标和空参数，新增指向原安装的「共享终端 0.1.40」回退入口。

发布前已运行的 0.1.40 桌面和会话服务在安装后保持相同 PID、映像和启动时间。安装全过程使用独立测试数据根。本机 Codex 全局配置散列一致。证据位于 artifacts/P26.117-install，包括 deployment.json、installed-smoke.json 和 process-retention.json。Step-ID: P26.117。
