# P26.13 本地终端标签拖动与意外复制

按 [CR-036](../changes/CR-036.md) 合并本地和服务会话标签的渲染和指针拖动。关闭按钮继续独立。禁用浏览器原生拖放，主窗口继续使用原排序、移动、分屏及源会话身份。所有本地标签双击只选择原标签，普通本地标签通过右键或 Shift+F10 的「复制会话」显式复制，SSH2 和串口保留现有复制流程。

0.1.25 在隔离窗口复验中能拖动普通本地标签，双击普通本地标签会新建。本次无法复现用户现场的拖动失败，因此用共享控件消除本地与 SSH 标签的分支，并验证物理鼠标手势。未使用真实刷机命令、设备或用户会话。

TypeScript 检查、144 项前端测试及实际 Windows 调试构建通过。调试版在隔离 Windows 窗口核对原生鼠标排序、浏览器无原生拖放事件、取消、分屏和跨窗格移动，确认保留原 xterm 节点、草稿和 PowerShell 前台输入。自建 BAT/CMD 验证脚本排序、双击不创建标签及原脚本接收输入。

首次 Release 构建缺少现有正式配置覆盖，窗口仍为开发标题。原生助手按预期在发送鼠标事件前拒绝，发布烟测也拒绝该标题。已按现有 Release 配置重新构建。

正式发布修复目录为 `artifacts/SharedTerminal-0.1.25-windows-x64-tab-fix`。同目录服务和 MCP 沿用 0.1.25 的已验证文件，并按逐文件清单核对。最终目录通过普通本地、BAT/CMD、混合 SSH 标签的 Windows 专项及便携版启动、前版配置锁复查、真实 stdio 工具发现、受管理退出。调试版另通过原生 SSH 跨窗口移出与移回、四方向分屏及两个分隔条拖动回归。

验证结果见 `artifacts/SharedTerminal-0.1.25-windows-x64-tab-fix-verification.json`、`artifacts/local-tabs-software-result.json`、`artifacts/local-scripts-software-result.json`、`artifacts/windows-unpacked-session-copy-ssh.json` 和 `artifacts/desktop-window-interactions-result.json`。
