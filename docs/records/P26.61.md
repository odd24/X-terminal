# P26.61 修正跨版本 MCP 发布专项

0.1.38 打包的首轮解压运行通过前 15 项门禁，MCP 末项在旧版启动阶段超时。兼容脚本先用 0.1.35 桌面与真实 v12 桥产生旧回执，然后换到新版桌面与 v12、v13、v14 各桥。第一阶段的旧桌面在取消时直接回列表，脚本曾误等 0.1.38 的确认弹窗。按启动的桌面选择断言，以 WebView 键盘输入和冲突前后回读核对原草稿。

授权到期后，旧桌面的无模态面板一度关闭，导致填写期限时测试找不到输入控件。脚本现在按当前可见状态打开面板和详情，显式刷新后再操作界面。到期拒绝、审批内容、同意动作和原回执的断言保持。

用首轮 ZIP 的同一解压副本和真实 0.1.35 重新运行完整 MCP 专项，结果通过。保留历次失败和最终结果，见 `artifacts/P26.61-release`。本步以 `Step-ID: P26.61` 关联提交。
