# P26.16 会话标签方案 A

按 [CR-039](../changes/CR-039.md) 实施，来源是统筹转达的 A.png 与 A.html。单窗标签条 42 px，含 34 px 标签及顶部留白。分屏保留 26 px 标签操作行并对齐下沿。未选中在主题底色上显示 1×14 px 分隔，保留 2 px 标签间隔。选中 8 px 上角、直下角、无装饰顶线和框线，实际终端背景无缝相接。标题和关闭叉按终端背景取对比文字，关闭命中宽度仍为 26 px。录制和拖动指示保留原信号。

Windows 专项用两条回环 SSH 和两个本地标签复现 0.1.26 原轮廓，按相同窗口布局和终端内容对照新样式。选中标签背景、标题与叉对比、短线、终端接缝和高度均由实际 WebView 测量，截图另看同地址名称和关闭归属。深色和宽窄分屏仍使用现有分屏边框；150% 为 CDP WebView 模拟，宿主缩放为 100%。

最终 TypeScript、145 项前端测试、普通桌面调试构建及 Windows x64 Release 通过。发布目录复验浅色主题下的黑底与白底终端、深色宽窄分屏、标签和按钮焦点、同地址两 SSH 的独立录制与关闭、本地终端草稿、轮滚、加号直开和菜单。实体键盘快捷键、本地实体鼠标拖动及回环 SSH 复制专项通过。调试版另验证四方向分屏、实体鼠标拖出独立窗口及移回。所有操作在隔离数据根和合成回环会话完成。

发布目录 `artifacts/SharedTerminal-0.1.27-windows-x64` 包含普通 Desktop、服务和 MCP 可执行程序，逐文件大小与 SHA-256 见清单。便携烟测通过旧配置锁复查、真实 stdio 33 工具发现与正常退出。验收记录为 `windows-0.1.27-tabs-baseline.json`、`windows-0.1.27-tabs-result.json` 和 `SharedTerminal-0.1.27-windows-x64-verification.json`。截图包含 0.1.26 对照、A 版浅色、白底、键盘焦点、深色录制及宽窄分屏。
