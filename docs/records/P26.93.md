# P26.93 实现并验证 PowerShell 长路径拖入修复

按 [CR-058](../changes/CR-058.md) 和 [ADR-108](../decisions/ADR-108.md) 将缓冲长度判断回移到 PSReadLine 2.0 自身输入循环。Windows PowerShell 的系统 2.0.0 由进程内兼容模块处理，无终端唤醒键。沿用原 IPC 并在插入前复核编辑代次、时限和路径语法。调用操作符无法把拖入路径变成调用目标。

隔离 Windows x64 Release 的 16 组原生 OLE 检查通过。65 列 249 字符草稿呈 4 行，96 列呈 3 行。65 列恰到第 3 行行尾和行中双路径也通过。各用例分别核对一份 VT 输出、一份可见草稿、准确缓冲及光标、一次 OLE 落点和一次插入回执。覆盖正常续输、执行目标拒绝、迟到旧代次、丢失回执、前台输入、取消和原窗格边界。

7 组 Tauri 事件复验与 7 组现有回环 SSH 会话树回归通过。159 项前端测试、TypeScript、Rust 格式和 Windows x64 Release 构建通过。PowerShell 专项从启动禁用普通历史，使用合成 APK 与无害 ADB 替身。证据保存在 artifacts/P26.92-file-drop-wrap。替换旧版二进制时无需迁移。专用配置脚本、其他 PSReadLine 发行版、Explorer 人工操作和 DPI 矩阵待验。Step-ID: P26.93。
