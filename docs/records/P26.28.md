# P26.28 桌面维护文档基线

以 [0.1.36 当前用户正式部署](P26.27.md) 和 [v13 契约验收](P26.26.md) 为现行产品依据。监督只读审核无阻塞，要求保留现行界面锚点、同一候选的实体双击与拖动零复制、原目标的异步边界及可复建的视觉证据。

[README](../../README.md)提供使用、开发和交付入口。[AGENTS](../../AGENTS.md)维护仓库规则。[界面与交互规范](../UI_GUIDELINES.md#现行桌面交互基线)维护视觉、操作边界、源码和最小回归。包内用户手册与历史记录继续由原文件维护。
