## 差分调查产物与结论

新增15项连续操作夹具terminal-reflow.json，涵盖缩窄/放宽/往返、硬换行、宽字补位、组合字、显式空格、颜色、历史/512行容量、同时改变宽高、替代屏、后台普通屏、保存光标以及resize后继续输出。screen_probe可执行有序write/resize；新增physical_contents仅供物理视口探测，服务生产contents本次未改变。

Compare-Screens把xterm行读取限制在term.cols，避免替代屏保留的较宽存储行被误当可见内容；输入按夹具边界入队、最终callback后才采样，避免600行逐次等待计时器。原有P02样本继续运行，新增矩阵在npm run test:screen内执行。修复前[xterm/vt100完整基线](../evidence/P11.7-reflow-before.json)被逐字段断言，基线漂移会失败；这是缺陷证据，不是将差异豁免成产品通过。

实测新增矩阵2项匹配、13项KNOWN_DIFFERENCE：活动光标所在整个软换行组默认不重排，替代屏仅裁切视口，二者与xterm相符。普通屏已离开的行缩窄丢中段、放宽不拼回、历史/保存光标偏移仍不同。原P02矩阵6项匹配/1项差异。需要修复有界单元格重排，并在服务screen使用物理行以避免软换行被拼成一行。
