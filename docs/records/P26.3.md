# P26.3 本地脚本与入口简化

依据 [CR-026](../changes/CR-026.md)，新建菜单与空态共用一个 PowerShell 入口。更多工具保留轻量模式。右栏区分 ADB 和本地脚本，设置共用列表与版本校验。

受保护设置首次读取原 ADB 记录。新版本第一次保存时使用同库中的独立记录，0.1.15 仍可读取升级前快照。脚本保留绝对本机路径，目录取该文件父目录。启动通过系统 cmd.exe 和现有 ConPTY，固定命令行引用子进程环境变量内的路径。延迟展开及 AutoRun 关闭。脚本正文按文件现状由 cmd 读取，排序及删除仅操作保存的入口。

Windows 验证使用隔离数据根，测试脚本由验证程序新建。初次版本同步误改同版本第三方锁定项，恢复原项后继续锁定构建，未升级依赖。

Release 实测通过原生取消、多选两个批处理文件、原 ADB 路径和指令保留、配置重开及旧版本读取升级前快照。实测含中文、空格、&、!、^ 和括号的脚本路径，核对进程的当前目录、资源管理器打开的目录、回答输入、pause、退出码 7 和 Ctrl+C。再次点击执行修改后的正文，移动后重新定位成功，改名、排序和移除保留文件。原 PowerShell 草稿及模拟 ADB Shell 切回后都继续接收输入。另以单独的 cmd.exe 对照验证带字面百分号变量样式的路径。实际验证进程的管理员角色为 False。
