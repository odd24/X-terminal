# P26.92 登记 PowerShell 长路径拖入重绘修复

按 [CR-058](../changes/CR-058.md) 将原生拖入、PSReadLine 编辑状态和 ConPTY 显示分别验收。正式 0.1.39 在 65 及 96 列复现。65 列时仅一次 OLE drop 和一次插入回执，编辑缓冲含一份 253 字符草稿，输入 xterm 前的 VT 输出写出两份。Windows PowerShell 5.1 使用的编辑器为 PSReadLine 2.0.0。

无拖放的独立定时器对照复现长行。短行、直接编辑器按键插入、限速逐字输入和粘贴仅显示一份。已验证同版本 PSReadLine 的空闲重绘补丁在隔离 65 列对照中的结果。原实现见 [ADR-104](../decisions/ADR-104.md)。配套候选在后续步骤验证。

文档检查通过。Step-ID: P26.92。
