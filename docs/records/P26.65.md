# P26.65 卸载无占用和引用的历史安装

按用户的旧版卸载要求清点 `%LOCALAPPDATA%\Programs\SharedTerminal`。按清单确认 15 个有版本号的旧安装和根级 0.1.0 的五个发行文件，检查文件散列、路径、重解析点和进程占用。Windows 卸载列表和 App Paths 均无该产品条目。当前用户开始菜单、桌面和固定快捷方式目录的核对发现三个旧开始菜单快捷方式。

将 0.1.1 至 0.1.12、0.1.37 共 13 个版本目录移入回收站，并将无版本号的 0.1.0 五个核对文件按组移入回收站。同时移除 0.1.12 的开始菜单入口。0.1.22 和 0.1.36 当时仍在全局 MCP 注册参数中，0.1.36 另有既有 Codex 桥进程，因此在此步骤保留两版及其快捷方式。复核 0.1.38 五个文件、主入口及已有旧桥的 PID、路径和启动时间。

清点和阶段核验见 `artifacts/P26.65-uninstall`。工作区发行包、默认应用数据、配置及日志保留。本步以 `Step-ID: P26.65` 关联提交。
