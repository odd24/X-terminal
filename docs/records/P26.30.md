# P26.30 当前版本性能基线

执行 [P26.29](P26.29.md)。0.1.36 原发布三程序来自已安装目录，仅另开自建数据根。模拟 ADB、两个合成 SSH、独立 WebView；每批单条及两行 ADB 交替各 15 次，SSH 单／双窗格各 30 次。设备已处于 root，保留每次设备枚举。单窗口实测主窗 PowerShell 空闲，双窗口增加已移交的 SSH 标签。

| 原版，P50／P95，毫秒 | 基线一 | 基线二 |
|---|---|---|
| 单条点击到 Shell 提示符且输入已聚焦 | 140／178 | 151／177 |
| 两行点击到 Shell 提示符且输入已聚焦 | 195／264 | 184／240 |
| 两行点击到标签出现 | 16／19 | 18／22 |
| SSH 单窗格键入到绘制 | 33／48 | 29／45 |
| SSH 双窗格键入到绘制 | 29／45 | 32／52 |

基线一在独立窗口等待条件返回 DOM 对象时 CDP 序列化失败，仅采用此前完成的样本。改为判断布尔值后的基线二完整通过，含快捷路由错误、交互、中断、脚本返回等断言。单窗口 30 秒 272 次快照；双窗口各 270／269 次，独立 SSH 另有 269 次读页。原快照对应 Ping 和 List 两次服务请求。单条 root 组的第一行能很快显示，调试的主要等待出现在能够输入前。普通 PowerShell 测量冒烟同时核对两路各 480 个连续序号。

## 复现

在仓库 PowerShell 点载 `scripts/Enter-Toolchain.ps1`，构建 `gui_ssh_fixture` 后，以发布版桌面 exe 作为第一参数运行 [Test-Desktop-ShortcutRoutes.mjs](../../scripts/Test-Desktop-ShortcutRoutes.mjs)。增加 `--measure artifacts/<本轮报告>.json` 启用计时、窗口交接与输出核对，`--uart` 使用脚本指定的隔离内存服务。普通功能回归继续复用原入口。原版 `artifacts/P26.30-base2.json` 和 `P26.30-base3.json` 含逐次结果及二进制哈希。

[本地性能脚本](../../scripts/Measure-Desktop-Performance.mjs)接受 exe、报告路径、启动次数，可加 `--tabs` 在本地顺序和尾段检查后分别对 4／20 个标签各切换 30 次。原始输出保存在忽略的 artifacts 下。

快捷计时在 WebView 内使用单调时钟。从行点击开始，分别记下结果视图出现、首段可见内容、run_adb 回执、设备提示符且已聚焦、探针得到正确内容的时间。回执包含准备和 IPC；探针提交还含测试控制器轮询时间。SSH 从输入派发前到字符实际出现在 DOM 计时。空闲调用样本包含 IPC 往返与调度，TaskDuration 是渲染器工作时间。后续 CPU 对照取同一自建进程树累计 CPU 时间差；快照往返只给原生锁等待的上界。
