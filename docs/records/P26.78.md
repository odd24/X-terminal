# P26.78 实现串口设备选择与刷新

按 [CR-055](../changes/CR-055.md) 与 [ADR-105](../decisions/ADR-105.md) 共用设备清单与端口控件。新建可预选首次唯一设备，刷新保留同一 PnP 设备编号和其他草稿，识别不到或原号替换后要求重新选择。离线旧项仍可保存，保存并连接经原快速连接再次核对原设备。

Windows Release 桌面类型检查和构建通过。158 项前端单测、57 项协议与 31 项串口传输单测通过。隔离 WebView2 串口专项通过 7 组场景。真实服务 IPC 使用内存串口，空清单、多端口、失答与同号替换使用限定在清单读取的响应夹具。保存、连接、关闭走真实 IPC。专项还验证延迟清单关闭后废弃、离线原端口与参数持久化、同号替换无法预选、普通快速连接显式选择及临时连接。

结束后重建普通服务和 MCP，校验普通服务与内存服务散列不同并拒绝测试开关。证据在 artifacts/P26.78-serial-config/serial-ui.json。宿主真实端口枚举、实物拔插及驱动友好名称实机未执行。本步以 Step-ID: P26.78 关联提交。
