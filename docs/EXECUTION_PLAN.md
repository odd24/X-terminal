## 执行单位与完成定义

每个 Pxx 是一个可验收工作包，至少对应一个本地 Git 提交。包内可拆 Pxx.1、Pxx.2，每个实际执行的子步骤也必须提交；拆分前更新本计划和台账。命令、读文件等过程动作不要求逐命令提交；有独立产物/结论的执行步骤必须提交，不能等阶段结束才一次提交全部工作。

每步必须具备：前置依赖 → 实现/试验 → 验证证据 → 更新 docs/records/Pxx.md 和台账 → 检查暂存内容 → 本地提交 → 核对历史与工作区。失败/阻塞也记录证据并提交可保留的成果，不伪造完成状态。

2026-11-05续行：用户最新要求持续执行整个方案，取代第一批结束即停止的执行上限；第一批已完成，B/C保持冻结、不重复启动。当前剩余R01–R16、P12–P25前置及具体证据缺口见[完整方案剩余要求与准入盘点](REMAINING_EXECUTION.md)，原依赖、CR-001及阶段门不变，不将完整目标缩成第一批或有限测试。

状态及提交关联规则见 [变更管理](CHANGE_CONTROL.md)。完整版本所有 R01–R16（含 CR-002 补充）通过才可交付；阶段原型不替代完整需求。
