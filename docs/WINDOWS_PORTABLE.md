# 共享终端 0.1.28 · Windows x64 便携目录

1. 保留交付目录内的三个相邻 EXE，可直接从该目录启动。
2. 先在旧预览中正常退出桌面，再双击 `shared-terminal-desktop.exe`。应用需要 Microsoft Edge WebView2 运行时。
3. 默认继续使用 `%LOCALAPPDATA%\local.shared-terminal.desktop`，原来的连接配置和偏好会从这个目录读取。旧预览如果通过 `--data-dir` 指定了自定义路径，请用同一个参数启动正式版。便携包只包含程序及说明，用户数据保存在原数据目录。

同一数据目录只能由一个运行中的服务持有。若提示配置目录被占用，请确认旧预览或另一个实例已经正常退出，然后重启正式版。界面的「重新检查配置目录」也能恢复配置读取。遇到持久审计不可用时，使用 Codex 授权前需要重启。保存的会话可重新连接，正在运行的会话需先在旧窗口中妥善结束。

如需与旧预览同时试用，给正式版指定一个独立的绝对路径。

```powershell
.\shared-terminal-desktop.exe --data-dir 'C:\共享终端试用'
```

使用「更多工具 → 退出桌面」结束应用及其会话服务。接入 Codex 时，在 Desktop 的「MCP 初版连接」读取本次桥接启动参数并核对进程和授权。MCP 桥位于应用同目录。正式版包含 SSH2 和串口功能。

工具栏始终独立占一行，主窗口的侧栏开关、日志、日志目录和更多工具随时可见。标签栏在下方独立一行并紧贴终端，宽窗、窄窗和独立窗口都采用同一顺序。未选中的标签用短竖线分隔，选中标签上方圆角，下沿与终端同底色。拖动顶部名称或空白处可移动窗口，使用右上角的窗口按钮最大化或还原。分屏后每个窗格各自保留贴着终端的标签栏。标签拖到另一栏或正文中央会并入该窗格，拖到正文外围的方向区会分屏，预览会提示落点。最多四个窗格。按 F6 在窗格间切换输入焦点。已有工作区的双窗格布局可继续恢复，三、四窗格的嵌套排列用于当前窗口。

右击已连接的 SSH2 或串口标签，选择「复制会话」可在原窗格的相邻位置新建独立连接。保存的 SSH 使用原配置并按正常流程验证身份，临时 SSH 需要填写本次凭据。串口复制预填通信参数，并要求选择其他设备。右击独立窗口的标签可以将副本开到主窗口。

连接库开关位于左上角标题旁。右侧依次为「日志」、日志目录图标和「更多工具」的三个点。「更多工具」按任务分组，窄窗内可滚动。用方向键移动焦点，Home 和 End 跳到首尾，Escape 关闭菜单并返回触发按钮。

在「更多工具 → SSH2 连接」可以使用已保存的配置，或查看当前会话的地址、端口和状态。「断开连接」与「重新连接」随会话状态显示。右上角 × 仅关闭面板。已结束会话的记录可在「更多会话操作」中确认移除。接收不到操作回执时，可在面板中查询原请求编号。分屏后的每个标签栏末尾都有「收起此窗格，保留连接」按钮，收起后仍可切回这些连接。

每个 SSH2 和串口标签都有录制开关。空心圆开始记录，红色方块停止并同步记录。可直接操作后台标签，原终端继续接收键盘输入。「日志」可查看对应文件和日志目录。查找终端用 Ctrl+Shift+F，复制和粘贴用 Ctrl+Shift+C/V 或终端右键。

「日志」旁的文件夹按钮直接打开当前数据目录的 `logs`。录制停止并确认同步后，服务关闭文件，右下角短暂显示会话、文件名和已同步字节数。可以从通知打开该次日志或日志目录，也可以在资源管理器重命名或删除已停止的日志。右下角通知可用 × 收起，点击操作会立即收起当前通知。无操作时五秒后消失，鼠标停留或键盘焦点在通知内时暂停计时。打开失败会另外显示可关闭的提示。

在「更多工具 → 软件设置 → 日志」选择 Windows 系统默认或登记的应用，也可通过「选择其他应用…」浏览本地 `.exe`。程序选择会立即保存，并应用到通知和日志菜单。Windows 未关联 `.log` 时使用记事本。日志目录仍由资源管理器打开。

## 本地命令行与 ADB

「更多工具 → 键盘快捷键」可查看快捷键。Ctrl+Tab 和 Ctrl+Shift+Tab 在当前窗格循环切换。Alt+1 到 Alt+9、Alt+0 直达标签栏第 1 到 10 项。Ctrl+Shift+T 在当前窗格按默认目录新建 PowerShell。Ctrl+Shift+B 开合本地快捷指令栏，打开后用方向键选择，按 Enter 单次运行。Ctrl+Shift+F 查找保留的终端输出，本地查找关闭后回到输入。

拖动本地标签可在主窗口排序、切换窗格或拖到终端边缘分屏。双击普通本地标签会打开同模式的独立终端。轻量命令行使用原标签当前工作目录，PowerShell 使用原启动目录。脚本、独立 ADB 结果以及正在执行已知任务的轻量标签双击只选中原会话。原标签右键菜单的显式复制仍可使用。双击已连接的 SSH2 或串口标签也可进入复制连接流程。

新建 PowerShell 和轻量命令行时默认打开当前 Windows 用户的桌面。「更多工具 → 软件设置 → 本地终端」显示默认目录，可用「选择文件夹」修改，或用「恢复桌面」跟随 Windows 的桌面位置。两项操作立即保存，只影响之后新建的终端。自定义目录不可用时，设置和新标签会显示提示并改用桌面。桌面不可用时改用当前用户的主目录。

单击窗格标签旁的「＋」直接打开 Windows PowerShell。悬停约 350 毫秒或按向下方向键显示「本地终端」「SSH 连接」「串口连接」。「更多工具 → 轻量命令行」可直接提交单条命令。关闭标签会结束该标签的前台任务，独立运行的 ADB 服务由 adb 自身管理。

在本地标签栏末端点「快捷指令」图标打开右侧栏。使用「单列」「双列」调整排列，点「全部展开」可在当前窗格阅读完整命令和脚本路径，点「收起总览」回到侧栏。选择「管理」进入多选，可用拖柄或方向键调整排序，并可批量置顶、移动或移除入口。布局和排序重启后保留。点击指令行运行，右侧「⋯」可编辑、排序、删除或查看最近诊断。选择「移到最前」或「移到最后」会在当前置顶区或普通区内移动并保存顺序。失败后的「!」可查看具体提示、使用的 adb 路径和枚举输出。底部「ADB 设置」可指定 adb.exe。

轻量标签空闲且没有草稿时就地运行，已有任务或草稿时从原 Windows 目录新开结果标签。从 PowerShell 点击时，总是在独立结果标签执行，结果标签采用 PowerShell 标签启动时的 Windows 目录。ADB Shell 进入后，可直接在结果终端输入。对已识别的设备命令，多设备时先选择目标。可以用 adb pull 导出文件。

右栏「＋ → 本地脚本」可多选本机 .bat 或 .cmd。点击脚本行后在独立标签执行，默认从脚本所在目录启动。结果栏有「打开工作目录」。脚本移动后用「⋯ → 重新定位」，删除入口保留原文件。

此便携版未作 Authenticode 签名。`manifest.json` 列出文件版本、大小和 SHA-256。

会话配置标题旁的「＋」可在所选目录或根目录新建 SSH 或串口配置。「保存」写入配置库；「保存并连接」先保存，再进入对应的连接窗口。

「更多工具 → 软件设置 → 本地终端 → 终端右键行为」会立即保存。默认右键复制当前选区，未选中文本时粘贴，也可选择显示复制与粘贴菜单。带换行或可能执行命令的内容先预览。空闲轻量终端使用单行编辑器，多行粘贴请在前台进程中进行。

## MCP 快捷指令

打开「更多工具 → Agent 授权 → MCP 初版连接」，读取本次启动参数并用 Codex 启动相邻的 `terminal-mcp.exe`。进程连接后刷新「MCP 快捷指令授权」，按需预览并批准「查看」或「管理」。每种权限单独限时，也可在同一面板撤销。

查看可列出和筛选名称、完整 ADB 命令或 BAT/CMD 路径。管理可登记、修改、排序或移除右栏入口，并查询原写入回执。保存后打开的右栏自动刷新。应答不明时用原 `request_id` 查询回执。脚本和 ADB 仍通过桌面原入口运行。
