## 布局与操作

- 采用现代桌面工具的清晰层级、克制配色和统一留白；终端是主要工作区。推荐左侧会话导航、顶部连接标签、中央终端、按需展开的辅助区域与底部状态栏；P12 按实际窗口尺寸落地，不增加新的功能承诺。
- 默认显示高频操作和当前任务所需信息。高级参数、诊断、独立 exec 任务及低频维护按需展开，不能同时堆叠挤占终端。连接与配置管理入口分工清楚，文案统一使用用户能理解的动作。
- 查找配置、连接、切换、输入、断开形成连续主流程；常用动作直接可达，避免同一动作多处含义不同或重复确认。身份/主机密钥/危险操作的必要确认保留。
- 当前连接名称、协议和状态清楚可见；发送前明确目标，切换/重连不把草稿或排队输入偷偷转给其他连接。SSH exec 与交互终端执行环境明确区分。
- 空状态给出下一操作；连接中、认证、失败、断开、输出缺口、日志故障和权限状态有文字说明及可用恢复入口。状态不只靠颜色区分，不用动画掩盖失败。
- 关闭辅助面板不隐式断开连接；关闭连接与退出应用遵守既有确认和后台策略。Agent 接管/撤销、广播范围等继续遵守统一服务约束，简洁交互不削减安全语义。

## 全局样式与字体

- P12 建立单一共享设计变量入口：语义颜色、字体族、字号/字重/行高层级、间距、圆角、边框、阴影、控件高度、焦点和动效。页面引用共享定义，禁止随意散落新的颜色值、字体和尺寸。
- 统一按钮、输入框、选择框、标签、列表、菜单、对话框及提示的外观和行为；同类控件各页面一致，主次操作和禁用/悬停/聚焦/选中/错误状态一致。
- UI 使用同一套全局字体族与中文回退链，候选为 Segoe UI、Microsoft YaHei UI / Microsoft YaHei、sans-serif；终端及需要等宽对齐的内容使用同一套等宽配置，候选为 Cascadia Mono、Consolas、中文回退、monospace。最终选择由 P12 的实际字形、宽字符和回退验证确定，不依赖用户额外安装字体。
- “字体统一”指有规则的全局字体体系：界面正文、标题、辅助信息各有固定层级；终端等宽字体独立于界面字体，所有终端实例一致。不得因页面不同任意换字体、字号或字重。
- 主题与字体设置统一作用于所属全局范围；深浅主题共享语义变量并覆盖所有面板/弹窗，终端 ANSI 色板保留可读性。避免仅换背景却遗漏文字、控件或焦点色。
- 采用统一间距尺度（建议以 4px 为基础）和有限字号层级；圆角、阴影和动效克制使用。实现时在共享定义内固定数值，不能让每个页面各自解释“现代”。不强制使用模糊、透明或玻璃效果，不以装饰降低终端可读性或输入性能。

## 可用性与执行证据

原生文件选择器使用Windows公共系统组件，由系统管理主题、字体和平台交互，不为单个窗口增加自定义配色或字体；此例外用于保持系统路径导航与可访问性。选择前后及覆盖确认、任务状态、错误/恢复路径仍使用应用共享控件与变量。P11.4原生另存见ADR-033；P12/T22/T23仍须记录系统组件与宿主在系统主题、DPI及字体设置下的实际表现，不能从默认系统选择器存在推断全局矩阵通过。

- 键盘焦点始终可见，Tab 顺序符合布局，图标按钮具有可访问名称，主要动作有可理解的文字或提示。长文本可换行、截断后可查看全文或滚动，不能盖住主要操作。
- 中文/英文/数字、中文输入法及等宽终端对齐必须实测；100%/150%/200% DPI、深浅主题与紧凑窗口下不裁切、不重叠。支持系统减少动效偏好。
- P12 先盘点既有页面并建立共享样式/字体基线，再迁移并按 T22/T23 留下真实 WebView 操作及截图证据。后续 UI 步骤引用本规范并回归受影响部分；已有组件优先复用。
- 确有协议/状态语义需要特殊样式时，以共享语义变量或组件变体实现，记录用途与规范变化。不得通过隐藏错误、权限或目标信息来简化布局。
- 本轮仅归档规则，未实施主题/字体设置、页面重构或桌面验收；P12 原依赖、R01–R14 和阶段门保持有效。
