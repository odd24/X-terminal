# ADR-040 终端优先桌面壳与连接视图生命周期

- 日期：2026-11-05（Asia/Shanghai）；状态：ACCEPTED（P12软件子步）。
- 关联：P12、R06/R15/R16、T08/T22/T23、ADR-039、UI_GUIDELINES。

## 选择

保留原服务、受限IPC、连接状态与所有维护面板；将纵向开发页面改为窗口内的会话导航、标签/终端工作区和独立滚动辅助区。候选为新增布局库、每个标签另建服务连接、复用单个终端视图读取服务保留输出。选择第三项，不新增依赖，不将视图隐藏当成连接删除。树使用既有带revision分页配置读取；Profile选中、活动ConnectionRef分离，单击只显示配置摘要，双击/显式连接新建独立SSH2实例，串口仍由已有面板核对设备和控制线。SSH1明确未完成，不降级。

标签排序只调整本窗口视图；切换沿用旧输入队列关闭/代次检查和保留输出读取，不重放输入。隐藏连接可从完整会话列表重新显示，后台输出由服务有界保留，超出窗口按已有缺口协议报告。默认标签显示协议/状态/代次，完整ID在提示和活动状态栏；可水平滚动、完整列表、键盘方向/Home/End切换和左右排序。侧栏可折叠并调宽，紧凑窗口辅助区采用覆盖布局；实际DPI/全局矩阵仍独立验收。

关闭标签明确区分取消、保留连接隐藏、关闭连接后隐藏；后者固定原connection_id/generation，经原SSH2/串口close通道提交，不forget、不撤销远端已执行动作、不自动重试未知结果。代次变化拒绝对新代次关闭。普通关闭桌面沿用stop_on_desktop_exit，没有后台驻留模式；尚有设备连接时由Tauri关闭事件显示确认。确认后仍由原服务/Job退出策略收尾。

## 权限、验证与代价

本地锁定@tauri-apps/api/window.js的onCloseRequested在回调未preventDefault后调用destroy。已有core:window:allow-close不能完成该路径；真实生命周期专项发现普通无连接退出失败，保留首轮证据后，为既有main窗口补core:window:allow-destroy。未开放任意窗口、路径、传输或通用RPC。实际构建、普通退出/崩溃Job、导航专项和完整回归结果见[P12](../records/P12.md)，不能由API实现推断验收通过。

复用单终端意味着切换视图重建所保留输出，超出保留范围不会编造历史；不在本地暗存额外正文。标签顺序、隐藏集合、树查询/宽度本窗口暂态，重载不创建新服务连接，显示偏好持久化继续P12。后续P17分屏/工作区需重新验证后台视图与尺寸策略。

新增revert可回退布局、入口与主窗口关闭监听/对应权限，保留配置、所有服务连接/日志/用户保存文件，不重放输入或恢复旧授权。Step-ID: P12 / Decision-ID: ADR-040。

## 配置名称与视图元数据回收（2026-11-06）

使用现有Desktop专用SSH2/串口status中的profile_id与代次编码，关联会话树同revision读取的配置列表。名称仅显示，活动身份始终connection_id/generation；配置改名后刷新树更新所有实例，缺失配置或元数据未取得时回退协议/短ID，完整身份仍在提示/状态栏。不保存Profile选择作为发送目标，不新增服务接口/权限或数据库字段。

显示缓存只保留profile_id/encoding，不缓存认证challenge/凭据/状态正文；依据当前服务身份和权威连接清单回收，换代/协议变化撤下旧数据，迟到读取不能重建已移除条目。串行只读状态获取不占用输入队列，失败保留名称回退，后台两秒仅重查尚未取得的元数据。标签排序/隐藏集合也按当前服务清单回收，不在长期建连/移除后无限累积。所有视图信息仍窗口暂态，P17工作区另行。

实质测试验证多实例编码隔离、代次/服务变更与忘记后迟到拒绝、2000次建连/回收；真实WebView扩展导航专项验证面板创建/重载名称、配置改名/删除的纯文本与目标不变、移除和隐藏后移除。最终结果见P12，有限专项不代表完整T22/T23。回退新增revert显示关联/缓存与测试，不改服务连接/配置或重发任何动作。
