# ADR-069 常用命令准备到独立多目标文本窗口

- 日期：2026-11-08（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P19。

按R08当前/选定连接执行，复用ADR-066命令库与已具备的ADR-067显式文本批次，不展开连续键盘/触发器。常用命令新增“准备到多目标”；没有活动连接也可填写变量并准备，当前单目标撰写仍需要就绪目标且原草稿替换规则不变。变量一次字面替换、不递归，使用所有SSH2/SERIAL共同64KiB含末尾预算。准备前重读同源模板/配置revision并冻结本次服务，晚应答仅在同服务/同窗口接受；服务变化清选中项/变量/源revision并拒旧读取。

文本草稿seed仅owner/text/ending/origin，不含目标、代次、编号、lease或同意；接收方按当前owner及预算白名单拷贝，只初始化正文/末尾/来源。打开后仍默认无目标/无预览/无人工接管同意，用户在原多目标窗口独立勾选2–8个目标、预览实际范围并确认。文字来源不构成执行授权，常用命令/活动标签或上次目标集合都不继承。预览后可编辑，按批次原规则重新预览，不随模板库后续编辑改写已准备正文。

准备不派发、不接管，不将单目标草稿移除或改成广播；正文/变量值/来源不持久化，关闭多目标清seed，普通手动打开空白，重载不恢复。已有批次在途时不叠加准备，提示核对上一批次状态。无服务协议/权限/数据库变化，仍schema7，模板库保留原严格审计/备份边界。模型验证字面值/64KiB/owner及whitelist不带目标同意；真实WebView合成SSH+内存UART验证真零会话准备、源revision变化拒绝、原多目标空范围独立确认/精确字节和未选实例保持、关闭/重载不复活。产品先构建、fixture后finally实际普通恢复；原单目标命令与独立多目标按影响复验，完整R08/R09/历史节奏/实机另列。
