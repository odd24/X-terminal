# ADR-108 PowerShell 5.1 拖入沿用 2.0 编辑器并修正空闲重绘

原生 OLE 一次落点只形成一次管道请求。Windows PowerShell 5.1 搭配 PSReadLine 2.0 时，空闲事件插入文本会先渲染。跨行使控制台光标行变化，旧版输入循环随后按外部输出重新定位并渲染同一草稿。新增的缓冲长度核对使该编辑在原渲染位置结束。

将 [PSReadLine 2.4.5 的输入循环判断](https://github.com/PowerShell/PSReadLine/blob/v2.4.5/PSReadLine/ReadLine.cs#L253-L266) 回移到 [PSReadLine 2.0.0](https://github.com/PowerShell/PSReadLine/blob/v2.0.0/PSReadLine/ReadLine.cs#L217-L225)。用仓库内锁定源码和 MSBuild Roslyn 构建同版本兼容二进制，并嵌入 Desktop。只在 Windows PowerShell 正常解析到系统提供的 2.0.0 时使用。受管 PowerShell 启动时为该实例暂时插入应用目录，随后恢复该进程原模块搜索路径。应用保留常规配置入口和其他版本的模块选择。兼容模块随实例关闭清理，产品配置和用户模块无需迁移。

输入仍沿用 [ADR-104](ADR-104.md) 的当前用户管道、原任务和编辑代次。插入前再次核对期限，路径令牌要求为独立字面量，且不会成为命令调用目标。整个过程无终端唤醒键及提交动作。候选 [BSD 许可](../../vendor/psreadline/LICENSE.txt) 随程序和便携说明提供。回退可使用上一便携目录。
