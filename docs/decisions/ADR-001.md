# ADR-001 桌面和构建基线

- 日期：2026-11-03（Asia/Shanghai）
- 状态：ACCEPTED
- 关联：P01、R14

## 背景与约束

Windows 桌面需要 WebView 终端渲染，独立 Rust 会话服务承担传输和权限。首步只建立外壳，不向前端暴露连接或文件系统能力。

## 候选与证据

| 候选 | 证据 | 许可/部署 | 代价 |
|---|---|---|---|
| Tauri 2 + React + Rust | 本机已有 MSVC 14.50、SDK 26100、WebView2；前端实际构建通过 | Tauri MIT/Apache-2.0、React MIT；依赖明细见 evidence | 需要 Rust 编译和系统 WebView2 |
| Electron + React | 未做本机原型 | MIT；另带 Chromium | 安装体积与第二套运行时，不在本步引入 |
| 原生 Windows UI | 未做本机原型 | 随具体框架确定 | 与 xterm.js 集成需额外 WebView 宿主 |

## 决定与原因

采用计划中的 Tauri 2/React/Rust 骨架。锁定 Node 24.14.0、npm 11.9.0、Rust 1.99.1（MSVC）、React 19.3.1、TypeScript 7.0.2、Vite 8.3.5、Tauri crate 2.12.5、tauri-build 2.7.4、CLI 2.12.4。npm 与 Cargo 锁文件锁定传递版本；其版本号来自实际注册表而非推测。后端协议与 MCP SDK 留待 P03–P06 决策。

使用 npm workspace，避免增加包管理器。Rust 安装在 `.tools`，通过脚本设置当前进程环境，不持久修改 PATH。官方 Rust 下载慢时本机使用 rsproxy 镜像，版本由官方 channel manifest 核对，rustup 校验下载摘要。

## 影响、验证与回退

最低部署范围暂保留 Windows 10/11 x64；本机构建号 22631 仅代表 Windows 11 23H2，不能证明 Windows 10 验收。安装、升级、离线和最低版本在 P23–P25 单独测试。WebView2 采用系统 Evergreen；本步不分发运行时和安装包。

React 外壳与 Rust 只建立编译边界，不接触真实连接。许可清单是依赖元数据，不能替代 P25 的完整许可证文本和分发审计。回退为 revert P01 提交；删除本地 `.tools` 前应确认不再需要缓存，不涉及远端动作或凭据。

构建与启动结果以 [P01 记录](../records/P01.md) 为准。
