# ADR-042 按数据目录保存桌面偏好与备份

- 日期：2026-11-05（Asia/Shanghai）；状态：ACCEPTED（P12存储/服务子步，界面接入继续）。
- 关联：P12、R05/R15/R16、T07/T22/T23、ADR-010/012/039/041。

## 选择与范围

候选为共享WebView localStorage、独立JSON文件、既有配置SQLite。共享浏览器存储不能保证测试数据目录与用户设置隔离；独立文件要新增路径/版本/原子写入与备份机制。选择既有配置线程独占的SQLite单例，沿用16项有界队列和Desktop专用config_request，不引入文件路径RPC、依赖或全局配置。按实际--data-dir隔离，窗口重载/服务重启可重新读取。无数据目录或存储失败时明确失败，不偷偷回退到全局存储。

严格DesktopPreferences只含主题dark/light/system、终端字体consolas/cascadia、字号10..28和三个复制粘贴习惯开关。默认深色/Consolas/15，Ctrl+C有选区复制开启，Ctrl+V及右键粘贴关闭；显式Ctrl+Shift+C/V及按钮保持可用。Ctrl+C无选区保持中断，粘贴仍经原固定目标/多行预览/共享输入队列，开关不代表发送同意。实际界面/行为验证属于后续子步，不能由保存开关宣称已生效。

只保存以上有限字段，不存草稿、终端内容、选区、剪贴板正文、目标ConnectionRef、预览/确认、授权、租约、窗口/标签/工作区。P17工作区另行。偏好保存需匹配配置revision，成功更新revision；过期或重复旧revision拒绝。配置通道不是通用写入去重回执：应答不明时查询当前偏好，不自动重发；重启revision改变，旧写入不继承。

## 迁移与备份

schema 3新增单例desktop_preferences与迁移记录；现有v1先升v2再v3，v2直接升v3。迁移前在线备份一致旧库逻辑镜像（SQLite头部可能变化，不保证备份文件逐字节相同）到唯一config-before-vN-UUID.sqlite，事务DDL失败保留原库，未知更高schema/坏内容拒绝而不重建。新版本缺行/非法字段/越界/未知枚举不能静默恢复默认；旧版本只读兼容才给默认值。

当前配置备份与恢复镜像包含偏好，摘要覆盖全部偏好，源偏好变化使旧确认失效；恢复配置/信任/偏好为同一事务，预先保留当前完整安全副本。预览明示偏好和恢复范围。便携Profile JSON仍排除偏好、凭据引用和信任。读取schema 2旧备份时仅构造默认偏好，不修改/迁移原文件；schema 1备份沿用既有另路迁移策略，不扩大普通read_backup支持。

旧二进制面对schema 3拒绝写入。回退代码用新增revert；数据回退只在服务停止并核对目录/版本后由用户选择已验证迁移前备份或安全副本，不就地降schema、不自动替换当前库、不删除副本，不重放输入/恢复旧同意。完整崩溃/断电/磁盘耗尽及跨版本升级向导仍属P24。

## 验证与代价

真实SQLite覆盖v2只读备份/迁移前逻辑镜像与旧schema保持/只读原文件逐字节保持与迁移失败、重开/目录隔离、摘要/安全副本/恢复及更新偏好失败后全部配置事务回滚；严格协议验证未知字段/枚举、字号与revision；真实Windows Named Pipe覆盖Desktop权限、旧revision拒绝、备份预览/恢复、两个数据目录及服务重启。实际命令与结果见[P12](../records/P12.md)，尚未完成的检查不预写通过。

代价为维护schema兼容与偏好明确保存/查询界面。显示、快捷键与右键行为需要真实WebView及重启/备份专项，全部17入口最终回归在界面接入后执行；库/IPC通过不代表Alpha、实机或完整T22/T23/DPI/输入法通过。Step-ID: P12 / Decision-ID: ADR-042。
