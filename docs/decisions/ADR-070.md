# ADR-070 主动启用的本窗口撰写入队历史

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P19。

按CR-006 S3/R09补最小撰写历史，复用原ComposePanel、源/代次预览及输入队列，不做持久化历史库或额外全局编辑器。候选自动记录所有终端输入会保留密码/设备正文且扩大范围，排除；跨重启命令历史需要独立存储/迁移策略，本包不提供，不新增为当前门槛。选主动开启的窗口内历史：默认不记录，在原撰写折叠区域说明只记录用户手动确认且桌面输入队列接受的片段，不把它当服务接受/远端执行回执。认证表单、键盘/粘贴、终端输出、广播和Agent输入均不采集。

单窗口最多32条，序列化记录预算256KiB（含正文、metadata及数组余量），满后移除最早入队记录；单条过大只跳过留存，不影响已确认发送。记录仅随机ID/本次实际text/显式ending/来源协议/入队时间，不含完整未选源/目标代次/票据/编号/同意；只在同服务窗口内存保留，无local/sessionStorage/数据库/日志写入。取消勾选或“清空并停止”立即清空并停止记录，服务变化/失效、重载/关闭软件清空；关闭撰写面板保留窗口选择和历史。展示以Asia/Shanghai和安全文本/控制转义，明确入队不等执行。

历史选择只查看，不改目标/草稿/派发。准备时明确面向原撰写上方当前目标，已有草稿独立默认不勾选替换；只填正文/末尾并撤旧预览，不发送。实际发送仍原独立预览/确认/精确代次/单次consume/FIFO，未知不自动重发；恢复历史正文不恢复原目标或许可。目标切换/编辑撤原同意沿现有路径，记录/清空不修改当前草稿、连接或终端日志。回退只移除窗口模型和折叠入口，无schema/服务/权限迁移，保持schema7。

验证模型默认关闭/owner/投影副本/32条和预算退休/重复独立记录/坏Unicode/控制/单条过大无副作用；真实WebView合成SSH+内存UART验证未启用不记录、开启后全文/选区仅实际片段、查看不输入、明确替换/准备和原确认、禁用清空/重载不恢复、真实丢应答仅入队记载/不重放。产品先实际构建，finally实际恢复普通服务；原全文/选区/常用命令按影响复验。历史只是本窗口入队草稿，完整P19/R09的发送节奏、更多协议及实机验收不推导通过。
