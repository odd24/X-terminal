# ADR-018 SSH2 桌面控制与输入边界

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（P09 连接/认证/输入桌面阶段）
- 关联：P09/P11/P14、R01/R04/R11、ADR-014–ADR-017

## 决定与候选

桌面增加带类型的 ssh_request Tauri 命令，复用现有受验证的 Desktop Named Pipe 客户端和 Request::Ssh；不暴露任意根协议请求。选择此路径而非 renderer 直连设备、浏览器保存密钥或另开 shell，原因是既有服务已承担代次、挑战、凭据和去重边界。配置仍走独立配置通道。两通道均由 native 心跳保持，失败不自动重启。

SSH2 面板从保存的 Profile UUID 手动建立连接，显示当前连接 ID/代次/状态；配置选择和会话选择独立，不拿未保存表单值连接。首次/变化主机展示端点、算法、完整候选/历史指纹，勾选核对后才可批准；拒绝终止握手。挑战回答带原连接代次和 challenge_id，服务继续核对信任版本。临时密码、交互回答和保存凭据分别有明确入口，提交/挑战变化/连接切换清空表单，页面不读回保存秘密；不承诺 JavaScript 字符串物理擦除。React 文本渲染不执行远端提示。

xterm 输入明确目标 reference 和独立 UUID，通过服务 FIFO。页面最多 16 项（含正在处理项），按顺序提交并查询原 request_id 回执，只有 PipelineQueued 可继续；失败/未知停发并丢弃本页面未提交工作，不重试、不转发到新代次。队列切换/销毁关闭，选择变化时旧目标未提交动作丢弃。输入诊断仅字节数/状态，不显示真实按键；合成模式保留原诊断，但按当前会话协议分流。尺寸变化去抖 150ms、同尺寸合并并使用同队列。PipelineQueued 只说明 SSH 发送管线，不能推断远端执行。

显式关闭/重连接入既有服务；关闭不承诺撤销远端动作。每代次终端屏幕/游标和本地队列重置。读取碰到重连刚递增的 StaleGeneration 时仅重新查询会话列表，不重放输入，也不误报服务进程死亡。状态查询不自动认证、重连或输入。

## 代价、边界与验证

当前桌面入口仅启用 UTF-8 Profile；GBK/GB18030 配置保留，编码收发由 P11 接入，不把禁用入口称为满足 R04。exec 桌面任务入口、长期输入去重记录/任务容量策略、rekey 故障并发和设备验收仍开放。1024 项服务回执上限是当前限制，不宣称长稳可用；页面重载不会重连，也不能清除服务去重容量。

使用同一 SSH2 回环 wire fixture 和真实 native WebView，检查先信任后认证、拒绝/变化阻断、错误/临时密码、加密私钥文件经 DPAPI 保存后认证、隐藏交互回答、FIFO/resize、退出码与断线区别、重载保留服务。Fixture 公私钥/口令为每次随机合成，文件与配置仅在验证过范围的临时目录，协议控制经匿名 stdio；不运行真实操作系统 shell、不含用户设备日志。测试结果与截图核对见 P09 记录。

回退用新增 revert 提交撤去 GUI/typed bridge，保留服务和存储格式；已发送的网络动作不随代码回退撤销。

## exec 桌面接入补充

同一 typed bridge 现在提供现有 exec/status/read/cancel 契约的界面；不另开连接或继承 shell cwd。页面保留有界 ID/状态列表，命令提交后清空；列表不持久化，重载可用完整任务 UUID 在原 reference 查询。输出各流独立增量解码，页面显示有界来源片段，服务覆盖/页面覆盖与总捕获限额分别提示。缺应答、缺退出码、取消、断线不能解释为远端没有执行。服务和页面的长期任务容量仍待后续策略。

新增大输出后 shell 退出回归揭示测试服务器的全局 pending 阻塞，故 fixture 改为窗口信用一致的 ChannelWriteHalf 生产者，并在 channel_close 中止；应用传输/依赖不变。失败前证据和最终验证见 P09。

轮询切换终端等待 xterm 时核对原 wanted 选择，若用户已有新选择则丢弃旧结果、重新查询；新建连接未出现在较早列表快照时等待刷新，不自动选到另一连接。该读取更新保护不构成写入重试或自动重连。
