# ADR-058 完整RPC拒绝记录与独立持久审计边界

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED（核心/服务分层接入；独立持久层与GUI继续，实际见P14）。
- 关联：P14、R11/R12/R13、T13/T14/T17、ADR-044/046/057。

## 已有证据与选择

ADR-044现有Policy只含512条授权/租约/入队/派发等元数据环，Pairing部分只读校验不可变；server::connection在Hello/帧读取失败时直接结束，typed RPC按5个子通道/公共入口派发后直接写Response。现有环不能覆盖所有身份/参数/读取/跨owner拒绝、序列化/写帧错误或服务取消，也不能区分返回Ok与远端完成，不能充当完整持久审计。ADR-057的规则/正文不得进入任何新增审计。

比较把完整Request/Reply Debug或JSON写日志、扩充原Policy环、独立元数据请求尝试流。第一项会泄漏token/认证/命令/规则/输出，禁止；第二项混淆策略许可与RPC结果、破坏已有游标消费者且仍漏握手/帧读取。选择独立RPC尝试流，原Policy事件保持原语义；以后持久层可收两类独立typed事件，不轮询可能已覆盖的环来声称无损。

## 请求尝试与真实结果

服务生成每条Pipe身份及每次尝试UUID，同一wire_id/request_id重试仍是不同审计尝试，不影响原传输去重/回执。Origin包含实际认证票据ID/角色（与活跃权限不同）、服务器观察的可选OS peer PID；拒绝客户端传入role/PID作为证据。握手开始为Unauthenticated，只有实际认证成功才追加Authenticated(client_id/origin_kind)，不回写原未认证事实。非法帧和握手失败只记Transport分类及固定错误枚举，不保存帧、token片段或错误字符串。

Descriptor只包含固定Area/Verb枚举、wire_id、原request_id、请求scope声明及可选固定种类/UUID/ConnectionRef资源。分类在服务从严格typed Request逐分支穷尽生成，不能接受caller描述、任意方法字符串或格式化Request；scope是请求声明而非实际许可。任务/票据/日志等用资源ID，不把租约/认证/状态查询伪装成Control/Connect权限。所有字段只能是枚举/UUID/整数/已有纯scope结构，没有命令、认证、配置名称/参数、文件路径、正文、规则值或可枚举秘密摘要的字符串槽。

状态按Received→ReturnedOk/ReturnedError→ReplyWritten或ReplyWrite IoFailure；读Hello/帧错误可在Transport Received后终止，服务取消记Abandoned。ReturnedOk仅表示handler构造Ok回执，可能只是入队/Requested/原回执查询，绝不自动当作远端完成；ReplyWritten仅本地write_frame完成，不能当作客户端收到，write失败也不能改写先前handler结果或撤回动作。仍须查询原业务编号，不自动重试。成功握手认证身份只追加一次，不能用于普通RPC或替换已记录身份；模型强制Hello初始未认证、成功返回前已有Authenticated，未认证来源只用于Transport，不冒充普通RPC。

核心保存512事件/64活跃尝试、单页1–128、单调源seq、固定exclusive through水位及after-cursor分页；覆盖显式gap/available_from。单条终态自带原Origin/Descriptor/start_seq/attempt_id，即使Received已覆盖也可解释其原始来源/请求分类；它不重复此前Authenticated或ReturnedError内容，阶段缺失须显示unknown/缺失，绝不从ReplyWritten推导完整认证身份或handler成功。不能在容量满时逐出活跃尝试；seq耗尽明确CapacityExceeded，不wrap/伪造终态。

## 服务边界接入

服务在实际Hello读取前创建未认证尝试，记录读取/版本/身份失败、真实认证结果和写帧；成功后的每个typed RPC先用协议穷尽分类，再调原handler，保存原Result码后才做真实write_frame。无效/未知JSON、超帧、截断、空闲/读写超时及关闭只记固定Transport原因，不抄原文。32连接接入容量拒绝用独立终态AdmissionRejected，无typed请求、handler或应答，不能伪造ReturnedError/ReplyWritten；没有无界额外任务。

Guard只持独立audit Arc和有限ID，所有await/服务取消掉落时记Abandoned，不调用业务cancel/撤权，不撤回已开始动作；读写错误仍按原保留编号查询。RPC ring独立Mutex，不从记录路径反向取Store锁，不做磁盘I/O。模型记账失败计入record_failures，begin失败在handler前关闭Pipe，不静默跳过记录后执行；后续可观察失败计数，不把它当精确丢失条数。

新增Desktop专用RpcAudit Info/Page，保留原Policy Audit通道不变。回执固定service_id、through/活跃数或分页、record_failures且persistent=false；查询自身也产生事件，活跃数含查询，须先Info固定水位再分页，不能追逐不断增长的当前尾部。服务重启清空该环，不恢复任何授权。被拒的请求可能含u64最大代次/时间声明，后续WebView须精确数字文本投影或明确未知，不能静默按JS Number舍入，更不能把审计资源当实时授权/操作目标。粗Area/Verb不复原原命令、参数或未知方法正文。

## 持久层规划与准入

持久后端现选择独立JSONL，不新增SQLite/sidecar或配置迁移。terminal-log::audit提供Windows限定writer，固定terminal-audit子目录/空独占audit.lock、祖先/目录pin与plain/reparse/单硬链接叶检查；不接受IPC路径。全局有序Record封装service_id及严格RPC/Policy元数据，source seq保留原含义。1024条队列、每批最多64条后sync_all；accepted_through只入队、synced_through才同步成功，查询缓存只发布同步后的有限记录。队列/磁盘失败sticky显式，不自动重试或用无限RAM补洞。

保留最多8个固定编号分段，每段至多1MiB/1024记录，每行至多8192字节；轮转仅以独占已验证句柄退休最旧自身审计文件，保留窗口和分页gap明确，不删除终端日志/配置/用户文件。未知名字/头/硬链接拒绝，不覆盖。重启严格读取每段完整有效前缀，空/部分自有header及坏尾保留不截断、单列incomplete_segments，后续写新段；历史身份不恢复权限。页限128、固定同步水位、内部/前缀缺号都报gap。Close先禁止新入队，排完已收队列/同步并实际join；失败不能宣称同步完成。

此库层已实现并验证，不等于服务已送入或GUI已显示。服务下一步直接typed sink接两个源（不轮询环）、失败后保留原编号安全查询并阻止新Agent许可/实际派发，Desktop继续可维护；GUI只读来源/未知阶段/缺口与健康。有限收尾不增加导出、审计整理GUI或任意检索功能。

持久审计须独立于终端原始/文本日志、配置导出与用户文件，使用受管理固定子目录、Windows祖先/目录/文件句柄与非reparse检查，不接caller路径、不覆盖未知内容。候选为：有界JSONL分段（可复用已有terminal-log句柄和坏尾前缀机制，但须另实现唯一写入/断电/轮转/索引）；独立SQLite（已有config-store使用固定rusqlite版本及事务证据，但不能把审计表塞进配置备份，须另核对叶文件/sidecar安全、版本/坏库及磁盘上限）。不在本核心步骤虚构持久层验收或增加数据库/依赖；服务接入后的原型证据决定具体后端并补本ADR。

无论后端，要求独立有界writer/消息队列、单一顺序/固定服务身份、提交/同步水位、明确容量/覆盖/失败与未完整尾部，停止/实际join回收；不能把queue accepted当durable。压力/失败不得静默丢审计后仍显示完整成功，失败后是否阻止新Agent动作必须在实际派发/回执恢复语义一起设计，不能全局重做/取消原已执行动作或挡住安全的原编号只查。持久查询仅Desktop独立白名单、有限分页/固定水位，不与既有本服务512环混用，重启不恢复token/租约/同意。

全路径准入须包括：实际Windows IPC握手/无效帧、版本/身份/到期/撤销、参数/未知方法、五子通道/公共读取及业务权限失败、跨owner/旧代次、handler Ok/错误、真实不读/丢失应答、关闭/超时/服务停止。采样/聚合或保留窗口必须明确，不得声称持有无限完整历史。持久层另验磁盘/队列失败、坏尾/重启与原文件保持、受管理目录/junction、计数/同步水位和真实普通服务恢复，GUI再实际构建验证来源/缺口/状态，不由纯核心通过推断完成。

## 代价与回退

新增尝试/事件内存有固定上限；每事件复制有限元数据，原业务回执去重与许可不改。握手/每请求更多事件会更快覆盖本服务环，必须明确源游标/保留窗口；持久层不能靠无限RAM弥补压力。接口使用独立类型以保留原AuditKind/Page协议，暂不迁移配置或持久格式。出现问题用新增revert撤下新审计接口/接入，不扩大授权、不改原终端输出或删除原日志。Step-ID: P14 / Decision-ID: ADR-058。
