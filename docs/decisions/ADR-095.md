# ADR-095 已结束会话的单次保护文本导出

P15 首包仅支持 SSH2 和 SERIAL 已结束且仍保留的精确代次。源固定为当前保留输出的完整半开游标区间，格式固定为 UTF-8 文本。Desktop 读取可信范围，预览冻结服务、协议、连接 ID、代次、源、游标、编码、原 UUIDv7、保护规则和到期时间。同意默认关闭。批准时与启动时复核同一源，区间内有缺口、覆盖、源参数变化或代次退休时拒绝整批。活跃会话、录制历史、原始数据、JSONL、屏幕和时间窗留在本包范围之外。

沿 P14 的 SingleOperation 绑定重算规范参数，签发独立 Export 范围，并要求有效且非空的保护策略。Export 只授予固定操作，不能借用 Read、输入租约或 Desktop bootstrap。现有 Desktop 日志入口及账本保持隔离。原 Agent 票据、授权代次与请求编号绑定全部回执。拒绝无效或无关票据的状态查询和取消。

冻结的有界源在内存中整段解码和保护，旧截断前缀按 P14 处理。仅已保护文本可交给有界文件 worker。复用固定目录与句柄验证、暂存、同步、指纹和发布原语。准备好的磁盘副本仅在服务重新确认许可且取消尚未获胜时才登记为可用。登记与取消、撤销、代次退休在同一服务锁下排序。未登记、过期、撤销和退休产物不可交付，并由有界托管清理处理。清理失败须独立记录，崩溃遗留仅作清理，禁止从文件恢复授权。

Desktop 用户显式启动另存，沿系统选择器和原覆盖规则核验固定源。暂存复制后、首次目标改名前，需要服务同一原授权给出本次保存独占的提交确认。此确认是另存授权边界。此前发生撤销、过期、源失效或服务失联时终止并清理本次暂存。确认应答丢失时仍停止，禁止自动续存。收到确认后，由原生完成本次目标替换或原恢复流程并报告真实结果。之后撤销只撤下托管产物和后续另存，用户已保存副本保留。

stdio 新入口仅允许固定启动、原编号状态和原编号取消，原 26 项保持。仅返回请求编号、安全状态和完成时的不透明产物 ID。取消在登记前获胜时停止交付，登记后的取消返回已完成。传输失联或首答不明仅可凭仍有效的原票据查原编号，不将查询不到、过期或新授权当作重发条件。状态接口不接文件路径、正文、指纹或通用文件动作。
