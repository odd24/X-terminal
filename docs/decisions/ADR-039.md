# ADR-039 共享显示变量与基础控件

- 日期：2026-11-05（Asia/Shanghai）；状态：ACCEPTED（P12首个软件子步）。
- 关联：P12、R15/R16、T22/T23、CR-001/002、UI_GUIDELINES。

## 选择与证据

既有React/native表单与单一style.css已覆盖配置、SSH、串口、任务及日志；原色值/字体/尺寸散落，终端选项另写一套颜色。候选是新增UI组件库、逐面板独立主题、原生语义控件加共享CSS变量。前者带来依赖/许可及大范围迁移，第二种不能满足R16；选择第三种，不新增依赖，不改服务/传输或权限。

tokens.css唯一维护语义色、UI/终端字体回退、间距、字号、边框、焦点、控件高度与深浅主题及终端ANSI色板。style.css只引用共享变量；terminalAppearance读取同一变量提供xterm选项，避免JS复制色值/字体。Panel/Field为共享语义控件，外观和终端查找先使用，所有现有原生按钮/输入/选择/文本域统一基样式。后续导航、标签和面板继续复用，不逐页增主题。

UI字体Segoe UI→Microsoft YaHei UI→Microsoft YaHei，终端默认Consolas→Cascadia Mono→系统中文回退；可显式选择优先Cascadia，未安装仍回退Consolas，不安装字体。深浅/系统主题与终端字号、字体只影响显示；正常布局变化仍走原有Resize/FIFO路径，不从界面旁路传输或修改已保留字节。系统主题监听解除随组件卸载；CSS尊重减少动效。Windows系统选择器沿用既有规范例外。

本子步沿用既有字号设置生命周期，外观显示设置明确为当前窗口，重载恢复默认；未先把偏好存入共享WebView全局存储，避免测试数据目录与用户显示偏好互相覆盖。P12后续仍须决定受管理/按数据目录的偏好持久化和备份策略；此处不是把该缺口当产品完成，不持久化任何终端正文/授权/同意。

## 验证、代价与回退

真实WebView专项验证现有面板/共享控件深浅主题、Tab焦点、终端字体字号、系统主题事件、来源文本不变及重载默认，截图记录中文/ANSI。1280×720、1920×1080、720×480为明确的CSS viewport探测，不能冒充原生分辨率/真实100/150/200%DPI；实机中文输入法、所有面板弹窗完整矩阵仍按T22/T23补齐。实际命令结果见[P12](../records/P12.md)，不从构建存在推断验收。

代价是维护有限共享变量/原生组件与持续收敛旧页面；P12树/标签/辅助区域布局和习惯选项继续。新增revert可回退显示层和入口，不改数据/凭据/服务状态、不重放输入；若后续持久化引入格式，另记录迁移/回退。Step-ID: P12 / Decision-ID: ADR-039。


本轮实际SSH回归暴露已移除连接在list/status之间竞争时，主轮询经用户文案wrapper丢失NotFound/StaleGeneration码，误停为服务故障。只读轮询改用同一既有Desktop专用状态RPC保留原始错误码，不给调用者新权限，不变写入去重/输入通道；真实旧list应答延迟+实际按钮移除须命中实际NotFound并继续列表刷新。该修复是P12基础体验所需的错误恢复，实际证据见P12，不以静态推断当已验。
