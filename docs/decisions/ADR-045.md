# ADR-045 串口逐片段派发许可与客户端回执归属

- 日期：2026-11-06（Asia/Shanghai）；状态：ACCEPTED（P14软件子步，实际结果见P14）。
- 关联：P14、R03/R11/R12/R13、T04/T13/T14/T17、ADR-024/025/026/044。

## 选择与边界

串口原OS worker独占句柄，Write/Send/控制线共用16排队项及一个在途项。仅在RPC检查许可不能覆盖排队、节奏和接收等待；取消整个worker则会关闭用户的共享连接。选择在每个Work中保存可选的服务内部DispatchGuard，已有Desktop无许可回调；Agent回调捕获真实Identity、同一不可序列化Permit与Store，不接受IPC自填角色、owner、回调或路径，不引入依赖或无界映射。

每次不超过1024字节的驱动写入尝试（含短写/Interrupted重试）前，worker在全部先前等待之后调用回调。回调与撤销/接管共享Store锁，校验当前ConnectionRef、票据、grant与lease并记录派发决定；释放锁后允许这一次OS调用。正在调用/已决定的单个片段无法承诺撤回；后续片段重新检查。控制线也在实际driver调用前核对独立Control范围，不能由Write推导。

许可失效且从未尝试driver调用才返回CancelledBeforeDispatch；曾尝试但Interrupted/零成功字节也保留UNKNOWN，不把driver_accepted=0当未派发。已有成功驱动写入则保留driver_accepted已知下界、UNKNOWN/Cancelled，不伪造退出码或设备执行结果。授权取消不会结束worker；用户可继续在同一个连接发送。全连接关闭、驱动错误和真实读取失败仍沿原关闭/UNKNOWN语义，不把授权取消伪装成设备断线。Break的实际断连清理保持原策略，撤权不偷偷撤销已完成控制动作。

## 服务与归属

真实Agent仅开放Write/Send、Control和本人InputStatus；范围与当前lease在编码/连接信息读取前验证，入队再取得固定许可。用户键盘、粘贴、撰写和串口Send/控制按钮经同一服务入口接管，撤下该连接全部非Read Agent范围/租约；查询不接管。Observer在任何存在性读取前拒绝。Start/Inventory/Status/Close/Forget仍Desktop专用，本子步不代替Connect/Disconnect后续实现。

输入Record内部owner随原1024回执/UUIDv7退休一起回收，None是可信Desktop。跨客户端不能查/重用UUID，即使正文相同；Desktop可查询所有结果但不能挪用Agent编号。本人只查回执不要求新lease或新Write/Control范围，票据仍须有效且目标代次精确；撤销/到期不继续访问。原编号结果不明只查询，不自动换ID/重发。未公开客户端owner字段、通用RPC、串口任意路径或新数据库格式。Start回执归属与Connect/Disconnect范围在后续独立子步继续。

## 验证、代价与回退

实际OS线程内存端口验证排队控制/输入撤销、短写复核、已接受前缀及同连接用户继续；服务测试使用真正Pairing/Policy验证释放再取、到期、撤销和显式/自动接管。Windows IPC和原生桌面证据按实际命令记录，内存回显不等于COM驱动/设备验收。不得从该子步推断完整P14/GUI/MCP/持久审计或任何阶段门完成。

回调只持短Store锁做派发决定，不在锁内执行阻塞OS I/O；代价是每个片段一次策略检查/元数据审计，审计512环覆盖显式gap，不声称持久完整审计。回退用新增revert关闭Agent串口入口及对应回调，保留既有Desktop行为/历史记录，不重放输入、恢复已撤授权或撤销远端已执行动作。Step-ID: P14 / Decision-ID: ADR-045。
