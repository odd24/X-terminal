# ADR-034 失败日志的显式只读前缀恢复

- 日期：2026-11-05（Asia/Shanghai）
- 状态：ACCEPTED（文件库与Desktop专用服务；桌面入口继续）
- 关联：P11.4/P24、R12、T16/T20、ADR-029/030/031

## 选择与代价

现有ArchiveReader必须校验completion.json和整个保留范围，缺标志或坏尾行会拒绝完整读取。候选为原地截断并重写完成标志、忽略坏行继续扫描、独立只读前缀reader。选择新增RecoveryReader，不改ArchiveReader/导出验证语义，不写源目录、不补标志、不接回当前终端，不推断远程命令成功。代价是首个可见段缺配对/头损坏时不能恢复；跨段损坏后不寻找后续“可能有效”的内容；已退休历史与捕获前后的内容仍不可恢复。

API只接受受管理根/log_id/精确ConnectionRef。打开先枚举最多34个固定名称文件/16个段，拒绝未知项、超限、reparse、占用和非普通文件；Windows复用只读/不共享写及删除的文件句柄和祖先pin，全部观察文件保持到关闭。首对头必须证明身份、有效限额/游标，第一段号为1时必须等于捕获起点。后续头按需验证，坏头仍保留原句柄；每段合计大小受头部限额约束。缺失最早已退休段只能从最早可见段恢复，不制造已知累计丢失量。非Windows不承诺同等外部并发隔离。

completion.json/completion.partial仅记录是否存在并pin，长度仍限制1024字节，内容不用于授予完成状态。调用者必须明确选择恢复，即使标志存在也不自动降级正常历史/导出检查。开始只验证文件集合/首头，后续记录通过PairReader逐项配对，跨段严格校验身份、metadata、limits及来源/文本游标；flush之后不得续段。遇到首处错误终止并保留本页此前已经验证的记录，不扫描重同步，不返回坏记录。

## 返回与边界

每页1–128条、32–256KiB逻辑负载，不预读未交付记录；剩余页预算不足以容纳最大合法记录时提前返回，避免游标越过已交付内容。无效分页参数不移动游标。RecoveryStop含原因、段号、首个未交付文本游标，区别可见文件结尾、缺伙伴、缺段、坏头、跨段断裂、尾帧截断、记录损坏及存储错误。缺段原因的段号指最后连续段；其他后段原因指正在验证的段。终止回执稳定，后续查询返回空记录及同一结果。

EndOfAvailable只说明当前可见文件前缀已读到结尾，不表示完整、持久同步、完整连接或完成标志验证通过。无CRC/签名，成对一致篡改不保证被发现；文本不重新从raw解码。源缺口保持原样，不补字节。恢复结果不能直接供VerifiedExport/普通完成导出使用；后续恢复导出须独立标记未完整范围和停止原因。

## 证据、后续与回退

8项新增实质测试及原有测试共66项通过；真实中文临时目录覆盖缺/partial标志、两种尾截断、坏记录保留同页前缀、轮转/缺段/坏头/缺伙伴、跨段身份/游标拒绝、空日志/缺口/flush、原文件逐字节保持、活动logger占用和自建junction拒绝。严格clippy及fmt通过，见[P11.4](../records/P11.4.md)。没有IPC/GUI恢复入口、恢复导出、跨重启任务恢复、真实磁盘耗尽或实机证据，不标P11.4/P11完成。

后续服务须在有界独立文件线程执行，显式恢复模式、Desktop权限、会话范围、分页重试/租期/关闭，以及与整理/活动捕获互斥；列表必须提供可核对的身份，不从不可信调用者路径读取。桌面须保持独立目标、显示未完整范围/停止原因，不将源文本写入终端。回退新增revert并保留所有源文件，不能以“修复”名义重写完成标志或恢复已经退休的数据。

## Desktop恢复服务

在现有history有界文件线程（16消息队列）内增加独立恢复状态；不复用普通历史的读ID/回执，以免重试改变完整性语义。增加recovery_list/open/read/close显式操作，仅通过现有Desktop专用日志通道，不向公共读取票据或MCP开放。恢复最多4个reader/64回执，普通历史原8/128不变，合计最多12个reader/192回执；每份最后一页重试缓存受实际编码MAX_FRAME检查。新增ops/schema兼容现有请求，无自动恢复/降级。

RecoveryReader::inspect只检查受管理目录和首个有效配对头，供恢复列表提供精确ConnectionRef；失败条目info=null，无权猜测/拼接来源。列表最多64项，标志有无只作提示，不把头部检查当作前缀已扫描。Open绑定ConnectionRef/log_id/read_id，同ID不同scope拒绝；相同Open只返回原信息，不重开或倒退。read游标/页参数精确匹配可重试最后一页，旧页/越界参数拒绝，终止页保留已验证前缀和stop，完全没有finished字段。

120秒单调空闲租期与显式close释放文件/缓存但保留已关闭身份；关闭或过期旧ID不得重开。64回执仅退休关闭的有序UUID时间水位，不透明UUID不自动删，容量不足明确拒绝。recovery_open/list遇整理预留拒绝，实际文件句柄阻止在途整理及活动logger；请求不取会话输入锁，不重放输入。重启不恢复reader/回执，源文件重新显式打开即可读取；这不表示原任务或授权跨重启恢复。服务测试证据续见P11.4。
