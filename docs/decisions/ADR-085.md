# ADR-085 原生所有者关闭回执与上次关闭提示

- 日期：2026-11-10；状态：ACCEPTED；Step-ID: P22。

9681273曾因执行者误读重新注入的历史AGENTS条款而暂停，并非用户新要求暂停。监督核对实际授权先后后从原WIP继续；实施证据集中P22，不以本决策状态当作验证结果。

监督已选择“保持现有关闭时序、受管理安全回执、下次启动查看”。现有React活跃SSH2/SERIAL关闭确认不变；确认后原生仅在RunEvent::Exit关闭bridge和自己服务。Tauri 2.12.5将Exit定义为event loop is exiting，此处不新增同窗口反馈或确认，也不前移关闭/冻结输入规则。

子服务stderr改为私有持续drain：固定小块/单行≤2048字节，仅接受ADR-084 v1严格白名单行。原文/无关行不保留；超长、坏JSON/字段、未知版本、部分EOF、多候选/冲突及reader错误分列。多候选不挑一条宣称成功；持续drain避免管道堵塞。每reader只持本服务状态，结束/超时abort并join，不写新服务状态。关闭只发一次Shutdown，不因丢ACK重发；ACK、wait、实际kill请求/结果、最终exit、reader、审计分别记录。exit0+无诊断仅“进程正常退出/审计未知”，不是明确异常，不自动提示。

回执严格v1/固定魔数，绑定本数据根内service_id/自有PID/时间；计数精确文本，无正文/路径/异常字符串/凭据或授权。沿现有service_status仅追加固定上次回执投影，无路径参数/任意读取。上次记录绝不改当前service_id/连接故障状态或恢复票据/重连。只有非零exit、实际强退请求或可信审计关闭失败等明确异常在下次启动显示已有非模态提示；正常仅主动详情。存储不可用本身不冒称服务异常。

固定子目录desktop-close-receipts-v1，每服务一个UUID不可变文件≤8KiB，最多32份兼容受信回执。专用独占lock不等待/不夺配置锁，复用现有本地目录pin/无重解析/无硬链接句柄；跨实例不同UUID不覆盖。所有现存条目严格检查后，满额仅通过已验证独占句柄退休最旧兼容回执，不触日志/配置/未知文件；坏/未来/未知/遗留半写文件整体返回安全不可用并保留，不修复。新文件create_new、原句柄flush/sync与无替换rename，失败只清理本次新建句柄；同ID不同内容拒绝。并发/异常不能替换未知目标。

保存/读取是有界最佳努力，不阻断基本启动/退出；文件IO不可取消不承诺超时已停止OS动作。任务与文件名冻结本次service_id，结果通道超时丢弃，晚结果不改当前/新轮状态；发布结果成功/失败/未知与服务关闭结果分列，不把保存意图当持久成功。读出的是启动前“上次可用关闭记录”，带服务ID/时间；缺失或旧时间不能追认最近崩溃。未来/坏文件不可用不要求用户删文件。

备选为在ExitRequested/确认提交后等待关闭并留窗内联反馈；它改变窗口关闭时序和输入冻结边界，未选用。实现依次验证纯模型/decoder、受管理读写与多实例/满额/坏文件、生命周期接线和共享控件UI；实际Desktop构建、原退出/配置/审计影响专项及普通恢复后独立预览交付。仅新自建根，不碰用户其他进程/窗口、COM或真实会话，不启负载/T18/T19/八小时。
