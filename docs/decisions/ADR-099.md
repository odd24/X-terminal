# ADR-099 Desktop 私有 ConPTY 与 ADB 快捷按钮

Windows 本地进程由 Desktop 原生层持有。直接向 CreateProcessW 提交全路径和按 Windows CRT 规则构造的参数，保留单条命令语义并省去 Shell 初始化。ConPTY 提供双向终端交互，独立线程读输出、写输入及关闭终端，用有界数据结构保全可见结果。按原会话和任务编号收发，关闭时终止所属前台进程并关闭所属 ConPTY。Windows 脱离控制台运行的共享服务由对应工具自己的生命周期管理。

主窗口的独立本地标签复用窗格、xterm 和样式，终端正文、历史和 Windows 工作目录不写入服务或日志。应用新进程只加载按钮和 adb 路径偏好。按钮使用数据根私有的 Windows 保护存储，一次保存完整配置修订。进程、命令执行、设备选择都不进入通信服务或 MCP 契约。

普通命令和按钮复用可执行文件解析及本地参数解析。识别明确的 ADB 主机和设备操作，设备选择冻结在原点击和本次序列号上。对于带显式目标或不能可靠推断的选项，沿用 adb 原生诊断。回退到 0.1.12 可继续读取原 SSH/UART 配置库，ADB 设置存于独立文件。

参考 [Microsoft ConPTY 生命周期说明](https://learn.microsoft.com/en-us/windows/console/creating-a-pseudoconsole-session)。实施与实际测试范围见 [P26](../records/P26.md)。
