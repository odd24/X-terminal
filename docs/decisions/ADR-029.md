# ADR-029 有界原始/文本持久日志引擎

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（独立引擎；服务授权和GUI接入由P11.4实现）
- 关联：P11.3/P11.4、R12/R13、T16/T19、ADR-028

## 选择

在workspace增加terminal-log，复用现有session-core来源事件与固定serde/uuid版本，无新第三方版本；Windows发布复用已锁定windows-sys 0.61.2的MoveFileW。候选为在会话锁内写文件、单个全局磁盘线程、每个日志独立线程。选择独立线程隔离某个日志的慢写；进程最多64个工作线程，未退出的线程不释放名额。submit仅做有界校验/复制与try_send，不能等磁盘，32排队+1在途。队列满锁定失败，拒绝并计数后续记录，已接受尾部继续排空，不重试任何记录。

每个日志绑定精确connection_id/generation、协议、编码、开始时间及独立raw/text起始游标。重试/跳号/跨代次/跨连接/非法大小一律拒绝并锁定失败；引擎不替调用者授权，也不从已有保留历史重建记录。中途开始可能缺失字符前缀或ANSI上下文，后续P11.4必须明示记录窗口。原始和派生文本只按调用者提供的对应事件持久化，不将screen、输入、认证和审计混为同一流。

## 文件与限额

选择原始二进制分段和文本JSONL分段，避免JSON字节数组被误当纯原始数据或时间戳侵入原字节。严格布局、读取规则见[日志格式](../../contracts/logging/README.md)。每段两个文件合计默认100MiB、保留5段；可配置128KiB–100MiB、1–16段。头部也计入限额，额外完成标志小于1KiB。不在引擎内清理其他日志目录，跨日志持久目录总量由P11.4服务治理及P22校准。

轮转前同步当前两个文件，关闭后先退休最早一对，再建立新分段，避免额外完整段突破限额。删除或新建中途失败会锁定Storage，可能留下不完整对，不承诺旧历史仍完整。状态中的written/range只反映最后一次成功的成对写入；发生故障时必须结合failure解释，不能当作当前磁盘目录的完整清单。retired_segments与分段头游标显式说明历史退休，written_records/bytes是累计数，不等于当前保留量。

EOF单独记录text_seq，source_seq=null，不编造额外原字节；EOF引起轮转时保存实际下一原始游标。人工stop关闭提交入口、排空已接受前缀、同步临时完成文件后不覆盖地发布completion.json，natural_end=false；连接输出EOF则true。完成标志仅证明本捕获窗口保留段已成功同步，不代表整场连接、设备命令成功或退休历史仍保留。没有完成标志、错误标志、部分帧/不完整JSON都不能推断完整。

## 故障与目录

Phase区分OPENING/RECORDING/STOPPING/STOPPED/FAILED，接受/成对写入/拒绝计数分开；durable仅在双文件sync_all、completion.partial同步与不覆盖发布均成功后为true，不替代硬件断电保证。写盘部分失败不编造已写零字节；written只计成功配对，失败尾部需严格读取验证。磁盘满、普通Storage、QueueFull、InvalidRecord、CounterExhausted和WorkerPanicked分别报告；模拟注入不是实际填满用户磁盘。错误不携带路径/终端正文，Record Debug脱敏。

根目录必须预先存在，Windows只接受本地盘绝对路径，拒绝ParentDir、UNC/设备前缀；从祖先到新UUID子目录检查并持有不共享delete的目录句柄，拒绝reparse，记录期间不能替换/改名。文件create_new，不追加旧目录，不覆盖已有日志。目录继承父目录权限，服务必须选受管理的用户数据目录；这些检查不承诺抵御同账户所有恶意行为或提供日志加密。正常退出join须在事件循环外执行；异常文件驱动挂起时不假称已停止，Drop只停止提交、不等待磁盘。

## 验证与后续

真实中文临时目录/NTFS文件、字节往返、轮转/跨段EOF、严格截断拒绝、目录pin/junction和故障注入结果见[P11.3](../records/P11.3.md)。尚未捕获真实设备输出、未接服务/IPC/GUI/搜索/导出、未做30分钟或8小时压力。P11.4仍须服务端权限、当前代次、显式启停和故障提示；P11/R12/G1不因引擎测试通过而完整完成。回退使用revert并保留用户既有日志，不递归清理历史。
