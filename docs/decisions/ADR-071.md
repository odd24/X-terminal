# ADR-071 当前SSH挑战的明确补录与单次认证

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P12.1；依据CR-010。

复用原SSH Manager/挑战、配置/Windows保护存储和Start/重连编号，不新增协议/schema/Agent许可。候选取消再Start会增加连接/丢失上下文，排除；同地址借其他Profile凭据会改变身份绑定，排除。选择同窗直接补录：明示未记住/引用缺失/有关联保护记录（不等可解密）、拒绝和读取失败；等待输入与真正验证分开。表单Enter在当前credentials挑战提交，无需取消/新建；密码为空也只在明确手动提交时处理，不擅自猜空密码。

自动认证只从本次意图的精确Profile引用选一次，无引用/已知缺失不猜测；显式输入优先于旧保存材料。所有认证共用最新状态/完整ref+挑战id复核、同步authFlight和submittedChallenge门。提交后直到新挑战或终态才释放，不明只查询当前连接状态，不重复相同挑战；拒绝后的新挑战由用户补录。状态轮询原闭包可能持旧render快照，统一从latestStatus.current读取且与当前选中ref/attempt核对，不能为自动路径省略校验。结束重试建立新明确意图并重新选择本次手动/保存材料，不继承旧秘密或无限自动重试；修改目标后走新填写路径。

已保存配置也显示默认不勾的本次记住选项。先重读精确Profile安全快照（ID/设置/名称/目录/引用/缺失标志），不一致拒绝；沿已有save_profile/save_profile_key_file更新同ID保护引用，不复制其他Profile引用或读取秘密到WebView。保存后当前Actor仍持原Profile快照，因此当前挑战使用用户本次输入认证，不把新引用误当旧Actor可用保存凭据；未来Start/重连才能解析新引用。保存失败不提交认证，保存不明必须只读核对，不自动续接。明示记住不等认证成功，取消不能撤回已开始的存储或服务器动作。

回退可移除新增UI/状态助手，不迁移配置；旧数据/保护材料和服务接口不变，仍schema7。验证3项助手模型、真实WebView合成有效/未记住/缺失/不可读保护记录/拒绝、回车同Actor、明确记住后再次双击、失败同ID新代次重试、真实认证与保存应答丢失不重放；自建临时根中停自己的服务后才造故障，真实用户数据只读元数据。原导航/临时密码与密钥/配置故障/弹窗专项按影响复验，实机重登和全局矩阵另列。
