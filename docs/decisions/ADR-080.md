# ADR-080 原生版本化导入与冲突事务

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P21。

沿ADR-079/CR-017和统筹接续进入原生导入首包，仍不当完整R05/G3或Xshell兼容通过。复用format_version=1无凭据Snapshot导出、原配置线程/ConfigImage及精确批量回执方式；不采用前端循环save，也不把导入当全库恢复。完整链先parse/严格版本字段/引用校验→本次明确冲突策略和逐项前后差异→取消/独立同意→单事务revision+全库CAS/回读→原owner编号恢复；核心/服务/GUI分提交持续接续。

源只由本窗口系统打开选择器明确选一个本地普通.json文件，原生安全读取，不接受WebView任意路径或inline导入正文。固定/可移除本地盘；拒UNC、设备/ADS、相对/点段、保留设备名、重解析点/目录，打开句柄禁止共享写/删除、核对句柄最终路径和大小后有界读，再核对最终路径；不搜用户目录。最多64KiB严格UTF8（不猜编码/BOM）、64 Profile/32目录、JSON层级32/目录层级16；JSON转义后仍在512KiB IPC帧内。读取后冻结本次字节，Apply不重开文件。普通服务仅认证Desktop接受严格有限导入请求；原生通用config_request拒导入正文，只系统选择器专用命令能递交，Agent/Observer拒绝。文件中未知秘密字段整批拒绝，不回显值或任意解析器异常，Debug/审计仅白名单元数据。

缺版本/非1/未知字段/重复字段或ID/非法参数/目录环、缺父、Profile缺目录/深度或容量超限均在Apply前返回白名单问题码和有限行位置；不得静默丢字段/跳坏项。所有文件引用必须在文件内部闭合，不能猜现存同名目录；ID跨实体也必须唯一，名字重名允许。JSON对象结构由原严格Snapshot模型再次反序列化，不用Value投影默默丢键；外层Value只检查版本/预算，重复字段最终仍严格拒绝。

冲突策略默认Reject，任何现存ID冲突整批拒绝；NewIds给全部输入目录/Profile新UUID（新配置无凭据），父/所属目录统一映射，预览同时列源ID与目标ID；Replace仅同协议Profile，保留原credential_ref且不写Vault。带凭据Profile的认证端点/用户/认证方式/协议及其余参数必须原样（允许编码改变），避免把原凭据带到新端点；不满足整批拒绝，建议NewIds或由原配置编辑器另行明确处理。无凭据项不凭文件创造引用。既有目录只允许内容完全相同的复用，不替换共享目录元数据，以免影响未导入项的归属；不同则冲突并建议NewIds。未选表/项、工作区/命令/偏好/信任和活跃Actor保持。界面逐项显示目录/Profile源目标ID、创建/复用/替换、全部变化和串口初始线，默认无同意，不隐式连接。

Store从一致快照构造私有ImportPlan，冻结全库前后摘要及需要插入/更新的完整Profile（内部保留引用）；BEGIN IMMEDIATE重验schema7/前摘要，延迟文件夹FK后准确INSERT/UPDATE各1行，完整读回摘要匹配后Commit，任何ABORT/IGNORE/触发改写/未选项变化/坏版本均回滚。服务revision冲突先拒，Commit成功后才新revision；不改schema或备份引擎。单次预览最多96行，独立8回执/120秒可应用/600秒状态，取消/过期优先退休，满拒绝。真实认证ticket_id(client_id)隔离；同ID相同原revision/策略/私有文件摘要只回原结果，不重生UUID、不重做Apply，参数不同Conflict。解析失败也给原编号终态问题报告。

未知选择器/Preview/Apply/Status只查原服务/编号，不重新打开选择器或续导。关闭原未用预览可取消，Apply在途不声称撤销；重载只存service_id/preview_id，不存文件、选择、策略、路径、差异或同意，恢复PREVIEW只读/明确取消。服务重启状态未知保持，不把NotFound视为未提交；另起必须先明确读当前配置并重新选择。对文件变化/切换/旧服务迟到不得改投。原生格式交付后才另包Xshell合成映射；本包无真实样本读取/秘密解密授权。

验证严格解析/预算/引用、三策略/映射/凭据保护/外部CAS/SQL中途回滚，IPC owner/重试/取消/过期/容量/权限/重启，系统真实选择器/取消/安全读/源读后变化、明确diff/同意与真实丢应答、重载只查、活跃合成SSH/内存UART/保护库保持；前置实际desktop:build，串口finally实际普通恢复。沿影响最小复查原批改/导出备份，不机械重跑全套；完整实机/IME/DPI/长稳与全45不推导通过。回退只移入口/通道，不动用户库或降版本。
