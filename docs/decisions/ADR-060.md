# ADR-060 简洁SSH临时连接与基本文本日志

CR-008增量（2026-11-08）：Status新增只含主机文本的server_host，Entry在本次实际建连/重连快照时冻结；Desktop标签不从后来改变的Profile推导旧连接目标。该字段不含凭据、不持久化新秘密，不改变权限/管理通道或连接身份。统一Dialog通过portal/HTML showModal保证配置不挤占终端及背景不可交互；成功关闭后的终端聚焦在DOM提交后执行，普通关闭保留原焦点恢复和待连接取消语义。

- 日期：2026-11-08；状态：ACCEPTED（P12.1实现中）；依据：CR-006/CR-007，复用P09/P11/P14–P15安全边界。

问题：现有Start必须已存Profile，临时密钥不可用；日志普通出口为JSONL，不能要求初版用户理解配置/认证工具或解析内部文件。

候选：①后台偷偷保存Profile/凭据再复用旧表单，违反保存可选；②UI另开SSH/直接写任意日志路径，绕过统一服务/安全保存；③Desktop专用临时快照接入原Manager/Actor，原日志引擎增加单一文本投影。选择③，无新第三方依赖。

QuickStart只接受校验过的非秘密SSH2 Settings/原request_id/尺寸。原Start回执增加可比较的临时Settings，冲突拒绝；临时Profile无credential_ref，仅在现有有界Entry/回执保留，不写库。StartStatus只查原编号，不因缺失建连；有效Desktop独立验证。显式重连在原gate/清理/派发检查后复用临时非秘密快照，认证秘密不继承。Agent固定Profile/revision路径与权限不变，新增请求不进Agent白名单/Single Operation。

AuthenticateKey仅Desktop，对原代次/挑战作答；Actor经原config线程读取本地普通密钥，复用现有固定/可移动盘、非UNC/ADS/设备、大小/格式/重解析点限制。原导入与临时读取共享一个函数；密钥/口令为Sensitive/Zeroizing，仅本次认证，不入Vault。只有用户明确保存/记住才沿既有配置/Windows保护存储写入。RPC审计只记录操作元数据，不序列化目标参数/密钥路径/口令。

基本文本日志从ArchiveReader验证的保留记录流投影单一UTF-8 .log，不另捕获通信或认证，保留范围、缺口/解码错误/结尾说明；除CR/LF/tab外的控制与双向字符转义，正文不执行。TextExportStart/Status/Cancel和Reply::TextExport为独立固定模式，共用原8队列/64回执/8磁盘尝试/256MiB、取消、SHA256及安全暂存；跨JSONL/恢复/文本模式原编号不混用。内部发布仍用固定受管理export.jsonl文件名（内容由可信模式确定），不接受调用者路径。

原生另存新增TEXT固定来源，仅查询对应TextExportStatus/匹配TextExport完成回执获取可信指纹，再打开.log选择器；VerifiedExport/SelectedSave的句柄、复制前后指纹、同步/发布、独立覆盖确认/备份与应答不明只查询保持。前端不提供正文/指纹/任意目标路径；关闭/重载不恢复同意或自动另存。高级日志/旧JSONL/恢复模式保留。

代价：多一套封闭的文本任务模式和临时目标状态，须覆盖原编号、Agent拒绝、临时密钥不落库及格式/保存来源隔离；界面复用共享控件/tokens，不重做无关页面。迁移不改配置schema；回退用新增revert并同步记录，停止新界面入口，不删除已有日志/配置/用户文件。具体验证和未验项见P12.1记录，不以本ADR冒称新流程通过。
