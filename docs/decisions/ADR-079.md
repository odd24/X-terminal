# ADR-079 精确配置批量预览与事务应用

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P21。

按CR-017进入S4/P21首包。P08已有schema7库、配置线程独占、全库ConfigImage摘要、便携format_version=1无凭据导出与受管理SQLite备份/恢复；原导出及新目录恢复不能冒称外部格式合并导入。排除前端循环save_profile：不能保证原子、可能把旧凭据引用/不相关字段写回，且缺乏服务端冻结预览。选原配置线程中2–64个精确Profile ID、固定patch及差异预览，取消不改库，明确Apply才一次事务提交。

首包字段为共同目录（保持/精确ID/根目录）、编码，以及同协议选择下的SSH端口、串口波特率；不批改认证/秘密/凭据引用、host、协议或初始控制线。协议不适用的patch整批拒绝，不静默跳过。名字/ID保持，存在同名项仍按ID；未选择项不变。活动SSH/UART原参数已由Actor冻结，配置提交不Start/Close/Reconnect/Control或改日志。

预览经原配置线程校验服务revision，读取一致ConfigImage并计算前后摘要，生成有序PortableProfile before/after差异；凭据引用只在内部镜像用于原样保持/一致性检查，不进入批量差异或审计正文。预览由固定ID标识，服务按真实认证Desktop client_id隔离，WebView不能自填owner。最多32个保留预览/回执，预览120秒可用、原状态最多保留600秒，满则拒绝，不自动复用在途意图；取消/过期优先退休释放容量，旧编号未知不能当未提交。字段/ID/preview请求的Debug与RPC审计只白名单编号/动作，不含正文参数。

Apply只收原preview ID：先返回同owner已完成原回执，不因库后续revision变化重复执行；原预览取消/过期拒绝，当前revision变化则整批冲突。存储层BEGIN IMMEDIATE后重读全库摘要，抵抗绕过配置线程的外部SQL竞争；按原计划逐条UPDATE准确行数，读回整个预期镜像摘要，ABORT/IGNORE/触发改写/坏版本/外键失败均回滚。提交后才换服务revision并保存APPLIED回执。凭据库不打开写事务，不新建或删除保护记录，无schema迁移。

未知Preview/Apply应答仅原ID查询；窗口重载最多恢复service_id/preview_id，不恢复选择/patch/同意，查询恢复为只读，不自动Apply。关闭/编辑只取消尚未应用预览，不声称撤回已开始事务；Apply在途关闭保留原编号，迟到不能覆盖新界面/新服务。服务重启清回执，旧编号NotFound保持不明，只读核对配置，不盲目重放。

完整P21后续仍规划：复用P08 format_version=1导出，增加同版本的严格有界导入预览/冲突策略（拒绝/显式新ID或明确替换，不隐式覆盖）、引用/目录批次一致事务；不支持版本/字段给报告。Xshell只用标明合成的格式样本做字段映射，真实样本无本轮读取授权，不搜用户安装/会话/秘密，不解密密码/私有资源；真实兼容与G3留验。独立子产物分别提交并持续接续，不把批改等同迁移。

验证model/协议严格字段、数量与权限；Store测试全库CAS/外部SQL/坏版本、第二项SQL失败/IGNORE/改写回滚及凭据引用/未选项保持；真实IPC测试owner隔离、取消/应用/原编号恢复及Observer/Agent拒绝。GUI先实际desktop:build，只中文自建根/合成SSH/内存UART，精确同名选择/逐字段差异、默认无同意、取消/冲突、实际丢应答/关闭重载只查、活跃代次/字节/凭据集合保持；feature finally实际恢复普通服务。原配置/备份及受影响基本连接最小复验，实机/长稳/全局/完整迁移不推导通过。回退移除批量通道/入口，不降schema或动用户库/日志。
