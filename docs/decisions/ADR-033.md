# ADR-033 原生另存任务与保留备份的明确替换

- 日期：2026-11-05（Asia/Shanghai）
- 状态：ACCEPTED（普通本地目标；其他兼容与恢复边界见正文）
- 关联：P11.4、R12/R13/R14/R15/R16、T16/T22/T23、ADR-032

## 选择

使用Windows Common Item Dialog的IFileSaveDialog选择目标，替换确认放在应用公共面板；不让渲染器、MCP或通用RPC直接提交目标路径。windows =0.62.2已是Tauri的锁定依赖，本次仅增加同版本直接依赖和所需COM/Shell feature，terminal-log追加现有windows-sys授权feature，不另装选择器插件或修改用户全局设置。

候选为直接写用户目标、临时文件后ReplaceFile、固定目标句柄并保留旧文件备份。前者写失败可破坏原内容；第二种在错误及并发名称变化时不能承诺原样回滚。选择第三种：目标不存在时以不覆盖rename发布；存在时先固定原文件对象、向用户显示完整路径与字节数，原生位置选择器不代替覆盖确认。60秒内用户明确勾选和确认后，原文件按其句柄改名到同目录唯一backup，再将已验证/同步的新文件按句柄不覆盖发布。备份在成功后仍保留，用户可自行核对与处理，应用不自动删除用户文件备份。

## 目标与失败

用户所选父目录先解析到实际本地目录并逐级pin，拒绝未解析的reparse；应用数据根及子树按卷/文件ID拒绝，避免覆盖数据库、凭据、源日志与产物。新目标不得包含流名/分隔符/控制字符或模糊尾点/尾空格；私有partial与backup只由保存ID派生，已有同名尝试不覆盖。现有目标仅接受普通可写本地文件，目录/reparse/只读、系统/稀疏/压缩/离线/加密等特殊属性明确拒绝，用户可另选新文件名；不强行改权限/属性或扩大到网络目标。特殊目标/网络兼容性仍需后续明确实现与验收，不把本子步骤当作所有Windows路径已验证。

原文件以read+DELETE且只共享read的句柄保留，阻止常规改写/改名直到确认、取消或到期。复制使用ADR-032的可信生产指纹与VerifiedExport，写入同父目录全新私有暂存并sync；替换时复制原文件当前DACL到新文件并保护其继承，避免继承合并扩大现有访问权限，不复制原属主、SACL或其他数据流；完整原文件和原元数据保留在backup。此策略是保留当前DACL，不等于所有文件安全/属性元数据完全迁移。

备份改名成功前失败保持原文件；之后发布失败尝试按原句柄不覆盖恢复原名。若原名已被其他条目占用或恢复失败，返回RECOVERY_REQUIRED并保留准确backup路径，不删除新出现条目、不承诺已回滚。私有暂存仅按自己的句柄尝试清除，失败时返回staging路径；不递归或按用户任意路径删除。COMPLETED仅表示本次校验/sync/发布完成，不监控后来外部编辑、路径复用或断电状态。

## 本机任务与权限

桌面宿主的独立native-export-save线程、8条消息队列、最多一个活跃选择/确认/复制任务和32条回执。任务按原ConnectionRef/log_id/export request_id及独立save_id绑定；状态/取消走短内存锁，文件I/O和系统选择器不持终端或配置通道锁。开始前经既有Desktop日志通道确认源COMPLETED/大小/指纹，再固定该回执；目标来自原生选择器，Tauri请求严格拒绝path/target/role/fingerprint字段，没有服务通用保存路径RPC。

CHOOSING/AWAITING_CONFIRMATION/COPYING与COMPLETED/CANCELLED/EXPIRED/FAILED/RECOVERY_REQUIRED明确区分。确认码只在等待确认时返回，绑定目标句柄并有单调时钟期限，查询不续期；确认入队后撤下公开确认码，重复提交不再次发布。取消是请求，选择器打开时须关闭系统选择器，返回后检查取消标志；已发布优先于晚到取消。等待确认的句柄在actor约200ms空闲检查释放；阻塞OS操作期间不保证即时回收，但处理确认前核对期限。退出应用请求取消，异常退出可能留下私有暂存/备份，跨重启恢复继续P24，不保证撤销已执行文件操作。

32回执满额仅退休终态UUIDv7并推进既有RequestWindow整毫秒水位；opaque固定，活跃项不退休，旧保存编号不重开选择器。同ID换源范围拒绝；渲染器重载只恢复scope/save_id，路径、结果、nonce和同意不持久化，结果不明只查询原任务，不自动重新保存。选中历史、活动连接切换及重连不改变正在处理的源范围。

“打开保存目录”只使用已登记任务中原生选择器产生的父目录，无调用者路径/命令，调用系统Shell；只承诺请求已提交系统，不伪造Explorer已显示。原生选择器遵循Windows系统主题/字体，宿主确认/状态/路径控件复用应用公共样式，例外记录在UI_GUIDELINES。

## 证据与回退

文件库用中文临时目录实际验证新文件、锁定现有目标/备份、取消、发布名称冲突以及备份后原名被占用导致恢复失败并保留双方文件；本机回执/严格请求、前端响应/ID恢复和实际系统选择器专项见[P11.4](../records/P11.4.md)。真实设备、特殊文件系统、磁盘耗尽/长稳、异常退出恢复和完整主题/DPI/字体矩阵不能从专项推断通过。

依据Windows官方[Common Item Dialog](https://learn.microsoft.com/en-us/windows/win32/shell/common-file-dialog)、[FILE_RENAME_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_rename_info)的不覆盖名称语义及[ReplaceFileW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew)列出的不同失败状态形成选择；本实现不是ReplaceFileW的原子性保证。最终159项相关Rust、24前端、严格检查和实际系统选择器专项通过，完整回归结果在步骤记录单独列出。

回退新增revert并停止暴露依赖该任务的另存/确认入口，保留所有已发布用户文件及备份，不自动删除或恢复、不重放保存；服务产物和原指纹接口保持ADR-032语义。未来迁移原地覆盖策略必须重新评估并发身份、权限和失败恢复，不静默删除当前备份。
