# ADR-074 统一平铺实时文本与终端右键日志来源

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P11.4；依据CR-014及用户追加实时/统一目录/窗口名秒级命名要求。

复用原Logger单个有界文件worker与内部raw/JSONL证据容器，增添同worker可读文本投影，不另建读串口/SSH旁路。不移动/删除旧日志。普通记录统一写现行稳定数据根/logs，一个目录平铺不同目标/轮次文件。名称从服务真实SSH host/UART port冻结（与标签一致），北京时间起录秒；必要Windows规范化与原子create_new冲突序号，无默认协议/用户名/UUID前后缀。文件不与其他窗口混写。

候选仅停止后导出不满足实时；为每条日志造子目录不满足共同根；合并所有会话为一文件丢目标，均排除。实时文件缓冲有界，100ms目标flush/1秒目标持久sync，持续输入和空闲均检查；OS写盘阻塞不承诺硬期限。accepted为队列接收，written为内部对和文本均成功写入，flushed为文本用户态缓冲已交OS，synced为对应记录sync成功；停止同步后durable才覆盖最终保留记录。源缺口/队列满/文本容量/IO失败明确，不把前缀当完整。单份实时文件独立上限256MiB（内部轮转配额不截断用户文本），最多64份，达到上限拒绝/失败，不隐式覆盖/删除。

打开目录固定共同根，打开文件仅服务当前精确代次登记的单一平铺文本名，路径由原生推导并校验/pin，WebView无路径/命令/URI入口；活跃文件允许读、拒其他写入/删除/替换。内部清理不自动删除独立保留的用户文本，状态/说明保留这个生命周期和容量边界，不声称释放文本占用。新文本与旧raw/JSONL/历史导出分层，旧数据不迁移或自动扫盘。

右键主菜单冻结真实窗格身份与xterm实际可见viewport；全部已录导出支持活跃录制，先等待操作开始前accepted记录到达周期flush，再冻结每份文件完整已刷新字节前缀/记录水位/时间/源缺口/拒绝/失败/活动状态，不静默停止、不无限追尾，不包含起录前或快照后内容；各文件水位不是跨文件同一时刻原子快照。只流式复制可信服务登记的文件和前缀，64份/合计256MiB上限，不以预览替代全部；内部轮转不删除独立用户文本。另名有界显示缓冲导出与真实可见屏幕导出独立，保留CRLF/物理行/尾部空格，不冒充通信原始字节。

原生Desktop专用terminal_log_request只精确服务/协议/代次/受管理ID或4MiB以内显示文本，没有路径/命令/URI入口；准备任务8队列/64原编号回执，正文只在有界作业里，参数私有SHA绑定不入回执/审计。完整快照和显示产物复用ExportStore/VerifiedExport/SaveTarget，暂存于稳定内部terminal-menu根（不是用户日志目录），同256MiB/8份上限；正常另存完成/取消或明确放弃未另存的已完成准备后，仅按已登记ID及校验句柄清理自身临时副本，保存目标和实时文本不删。失败partial保留、容量/清理失败明确；不把临时清理当日志删除。系统另存保持原指纹/覆盖确认，未知原编号只查、不重新准备/自动续存。

新StartStatus是Desktop日志专用原起录编号查询，不接受名称/路径/限额，不发起新记录；服务冻结SSH真实host/UART真实port，认证数据不参与命名。活跃文本创建句柄由服务保留，允许外部读取，拒其他写/删除/替换；原生打开再校验固定头身份、普通文件/非reparse/单硬链接，目录祖先持柄，不执行内容。改动按库/服务/原生与菜单/实际专项分独立产物提交，完整包六入口及实时/同根证据未齐不标交付。回退新增revert，用户已产生文本/旧日志保留。
