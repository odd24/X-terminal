# ADR-052 Profile Connect的配置版本批准

- 日期：2026-11-06（Asia/Shanghai）；状态：ACCEPTED（P14分阶段接入，实际结果见P14）。
- 关联：R03/R11/R13/R15/R16、T04/T13/T14/T17/T22/T23、ADR-047/049/050。

## 选择

仅冻结Profile ID不能保证用户看过的配置就是实际打开配置。候选为只展示配置摘要、由WebView传入打开参数、在服务范围内绑定配置revision。选择第三项：新增profile_revision目标，含profile_id和原配置线程的全局revision UUID，只允许Connect。既有profile目标保留ID范围语义，不冒充固定配置版本；GUI只签发新目标。

配置列表的分页已有同一revision保证，GUI读取配置时保留该revision，不生成版本、不接收调用者覆盖的连接参数。Grant由配置线程核对版本与Profile存在，异步后仍复核Desktop身份；应答不明按原编号查询。Start先从该票据范围捕获唯一对应revision的Permit，再由配置线程在同一处理内比较当前revision并读取Profile。多个绑定版本不任意挑选，拒绝歧义；绑定范围不退回旧ID范围。配置修改后新Start失败，原Start回执查询优先、不重新打开或续期。

配置返回后按ADR-049/050重新核对许可，实际SSH首次poll/串口OS worker打开前仍复核同许可。该次打开使用已经读取、与批准版本匹配的不可变Profile快照；读取完成后的配置编辑不会把新参数混入在途打开，也不能撤回已经派发的动作。保存凭据仍按原Profile相等检查，Connect不授认证/主机批准。当前revision覆盖整个配置库，其他配置或偏好变更也会保守阻止后续新Start；不承诺逐Profile内容版本或跨服务恢复。

## GUI与边界

配置建连批准与当前ConnectionRef能力分开选择，默认无勾选。明确已保存Profile名称/ID、协议、配置revision、实际非秘密参数、期限，串口显示端口/速率/数据位/停止位/校验/流控/编码及初始DTR/RTS；硬件流控的RTS由驱动管理，不伪作任意手动控制。切换、刷新、编辑、关闭、重载使预览/同意失效；批准前重新读取当前配置并核对版本与Profile，过期摘要不自动换成新版批准。

只批准Connect，不创建连接、不取lease、不授新连接Read/Write/Exec/Control/Disconnect，也不授Inventory或秘密。SSH1仍未开放该Agent路径，不隐式降级。编号恢复/迟到响应/token投影沿ADR-047；WebView不保存配置快照或同意，不将GUI成功当作P15真实stdio桥交付。

## 验证、代价与回退

核心验证不同版本/ID/动作互不推导及许可撤销；协议严格字段/非nil版本；真实Windows IPC验证SSH及内存串口的新范围、修改配置后拒绝新Start、原编号查询仍保持、撤销拒绝。GUI须实际验证配置预览、默认未选、切换/编辑/删除、重载/丢应答/迟到与普通服务恢复。结果与未执行见[P14](../records/P14.md)，内存端口不等COM。

无依赖或数据库迁移；本地IPC v1同构建增加新目标。代价为全局revision较保守及旧ID目标仍有不同语义，界面和回执必须明确区分。回退新增revert撤新目标/GUI入口，保留既有Desktop/原ID路径及有界回执，不恢复同意、不重放Start、不撤销远端动作。完整P14、真实桥及P13–P25/阶段门持续开放。Step-ID: P14 / Decision-ID: ADR-052。
