# ADR-067 显式多目标文本批次与逐目标回执

- 日期：2026-11-08（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P18。

CR-006 S3下，P14统一输入和P17已有多会话/分屏软件基础可复用，先实现独立“更多工具→多目标发送”的单文本批次。完整P18同步键盘/更多目标类型、完整R07及实机范围不缩减。当前不把常用命令同意、活动窗格、标签分组或工作区自动作为广播选择，不修改基本连接/日志入口。

默认目标空、正文空/不追加换行、确认未勾选，明确选择2–8个当前SSH2/SERIAL精确代次，最多64KiB UTF-8含末尾换行。预览逐项读取原服务/连接状态、冻结实际地址/端口及编码，认证中/结束/缺失拒绝；未知编码拒绝。服务/正文/目标/末尾变化撤预览和同意，关闭/重载不恢复正文或许可。确认说明这是各目标的Desktop人工输入，沿原服务接管规则撤下对应Agent写/控制范围及未开始的Agent动作；已执行动作不撤回。不给Agent新增Broadcast许可，不走独立shell或连接旁路。

批次在窗口内最多一个，模型只保留最后8项只读结果、不保存正文/变量/同意。冻结顺序逐目标进入现有SSH/串口服务FIFO，每目标独立UUIDv7/request_id及精确connection_id/generation；再次派发前实际重验服务/同代次/状态/原编码与地址。切标签或新连接不扩大集合，目标失败不换成同地址/新代次。已知派发拒绝和预检未就绪分别显示并继续其他目标，结果不明停止所有未开始目标。SSH管线接受/串口驱动接受都不等远端执行成功，无跨目标事务或回滚承诺。

取消/关闭只停止未开始目标，当前在途动作继续原编号回执查询；取消无法撤回已发送字节。未知只查询原目标/原编号，不重放、不恢复剩余目标；只读查询失败/过期保持UNKNOWN，不能当未发送。重复确认同步锁保证一个批次；新预览后显式再次发送为新操作。重载清除窗口回执，仍可能有原在途动作，不自动补发。

选择仅窗口协调器+原native专用SSH/串口RPC，无服务协议/数据库变更；每目标服务已有FIFO/去重/认证身份负责实际执行，不另添代理广播入口。候选连续键盘同步复杂且容易扩大输入范围，保留后续。单纯同时Promise.all无法清楚停止未开始目标，采用顺序推进；互不承诺原子性。回退可移除独立入口/窗口模型，不迁移配置。验证纯模型冻结/界限/取消等待/已派发/未知不重发/原编号查询、真实合成多SSH+内存串口及原导航/撰写回归；产品先实际构建，finally实际恢复普通服务，实机另列。
