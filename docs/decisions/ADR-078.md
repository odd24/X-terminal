# ADR-078 有限跨度原生匹配与窗口触发器

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P20。

监督统筹已明确解除上个P18包不扩P20的包内限制，按S3/R10/T11启动下一独立包。P11文本视图、P14输入与P19软件前置可复用；原父步骤未全收口不自动阻塞。完整规划匹配、高亮/通知/记录/发送、冷却/限次/停用及回显防循环，核心/原生通道与GUI可分别提交，不能把首个核心产物说成完整P20。

选择锁文件/本地缓存已有的regex=1.13.1与regex-syntax=0.8.11，session-core新增直接依赖；Cargo.lock只增本包依赖边，未升级已有版本。官方[regex引擎说明](https://github.com/rust-lang/regex)与[find_at文档](https://docs.rs/regex/1.13.1/regex/struct.Regex.html#method.find_at)说明单次搜索O(mn)，不支持任意回溯构造；多次迭代搜索另需限制调用次数。排除主线程JS任意回溯正则+字符串长度上限；也不把spawn_blocking当任务可取消承诺。

核心字符串/正则模式输入最多1024字节。正则使用HIR计算有限最大匹配跨度1–1024字节，拒绝无界量词、空匹配、所有位置/锚点断言及引擎不支持的前后查找/反向引用；可用`ERR[0-9]{1,3}`，不能用任意`.*`。语法嵌套32，编译NFA预算256KiB、DFA缓存128KiB；每次新增文本16KiB，携带最多跨度减一及Unicode边界余量，最多64次搜索/32命中，超限整次失败不悄悄丢匹配继续动作。原生保留最多4个匹配器；2个工作许可在spawn前try_acquire，无无界排队；同步互斥保护状态，最坏也只有一个额外已准入任务等锁。关闭/失效不能中止已运行计算，但前端代次核对拒绝迟到结果。

匹配是服务解码文本，不等屏幕/ANSI清理文本。原生按文本事件序号严格连续推进并保留首尾来源，缺口/解码错误/文本重建撤旧激活，不跨缺口拼接。字符串有完整匹配即可命中；正则只确认其起点后已具备最大跨度的稳定前缀，避免分块不同导致短匹配提前执行。变长正则的短尾可能等待后续字节，GUI明确延迟，来源结束时本窗口规则先停，不把未确认尾部当条件；固定跨度模式/字符串适合及时触发。核心另支持最终结算供独立回放验证，不冒称本轮GUI会处理已结束来源尾页。

首包单窗口、单来源精确服务/协议/代次、一个活动规则，默认无来源/动作/同意。预览冻结四动作、冷却100–60000毫秒/上限1–100、来源地址/编码及原生编译结果；启用时仅排空保留历史以冻结新文本水位，不对起录前输出补发。单次有界轮询，编辑/换源/目标/owner/代次、gap、关闭/重载撤激活，无自动恢复。冷却被抑制的命中显式计数。多规则/持久规则/长期与实机能力保留父P20，不能因此缩减最终R10。

四动作独立选择。高亮在原生命中来源可证明的摘录上以mark显示；解码文本事件不能证明终端物理坐标，因此不按同名文本搜到的屏幕行冒充原命中，不改终端/原始字节/通信日志。通知是本窗口非模态元数据提示，不申请系统通知权限。记录是窗口内最多64条且JSON总预算64KiB、单条摘录256个Unicode标量；超限退最早，关闭规则工具/重载清空，不写盘，不用通信日志冒充命中记录。此记录语义及一次自动发送限制已由监督统筹明确接受为本首可用包边界。

发送独立勾选/预览固定1–8目标、准确固定正文/末尾和编码，最多4KiB，不将远端匹配文字/捕获组插值成命令。需单独同意本次自动发送及原Desktop人工接管，读取/高亮许可不推导发送；原租约/状态预检失败拒发，预检非原子，最终仍原服务按已明确范围处理输入。发送前先停唯一规则、退休匹配器并停止后续匹配回调，故每次激活最多一个自动批次，任何回显都不能续触发。逐目标原统一调度及独立request_id，拒绝/未知停止余项，取消不能撤回已开始动作。未知仅查原编号，不重放、不凭查询或命中历史续发；重新发送必须重新预览/明确启用。逐目标结果仅窗口内最后8项，不持久化正文或许可。

验证分层：核心跨块Unicode/所有切分点有限正则一致性、尾部稳定/拒绝与容量；原生槽位/worker严格通道；窗口协调器动作独立/冷却/容量/失效与原查询；实际desktop:build后GUI合成SSH+内存UART的四动作、真实跨块、回显一次发送/迟到/取消/错误与gap重置，finally实际恢复普通服务。匹配只用合成数据，不读用户私有日志/开真实COM或操作现有连接。安装/实机/全局DPIIME/长期及完整P20父范围留验。
