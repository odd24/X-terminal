# ADR-043 共享终端配色与配置 schema 4

- 日期：2026-11-06（Asia/Shanghai）；状态：ACCEPTED（验证结果见P12）。
- 关联：P12、R05/R15/R16、T07/T22/T23、ADR-039/042。

## 选择与边界

候选为把黑底绿字加入应用主题、只在窗口临时保存、在受管理偏好中新增终端配色。选择第三项：应用深浅/系统主题与终端配色独立，terminal_palette严格枚举follow_theme/black_green/black_white；默认跟随应用保持既有显示。默认前景/光标可绿或白，ANSI前景/背景仍区分，不能把所有输出强制着绿。所有值仅由tokens.css维护，terminalAppearance从同一入口读取，无面板或JS独立色板、额外字体/依赖。显示不改来源字节、解码文本、服务屏幕、目标或授权；正文/草稿/同意仍不持久化。

## 迁移、备份与回退

配置schema 4保留单例表并在事务内更新JSON/迁移记录；schema 1/2先沿既有路径升级至3，再升级4。已有库先校验并创建唯一config-before-vN-UUID.sqlite逻辑镜像，迁移失败回滚字段及版本，保留备份。schema 3按原六字段严格读取后补follow_theme，保留全部旧偏好；只读旧备份不改原文件。schema 2仍构造默认偏好。schema 4缺字段、未知枚举、未知字段或坏记录必须失败，不能对当前格式偷偷默认；IPC同样必填，不接受旧客户端省略字段。

配置镜像摘要/安全副本/事务恢复包含配色，配色改变使旧确认失效；旧schema 2/3备份只读构造当前镜像，摘要是当前解释的逻辑摘要，不声称与旧版本算法字符串一致。便携配置不新增偏好。旧二进制拒绝schema 4写入；新增revert可回退代码，数据仅在停止服务并核对目录后由用户选择已验证迁移前副本，不自动降版本、覆盖当前库或删除备份。P24崩溃/断电/跨版本向导仍开放。

## 验证与代价

真实SQLite验证v3旧备份逐字节保持、旧偏好/配置保留、迁移前备份仍旧版本且无新字段、失败事务回滚、当前缺字段拒绝及摘要/恢复/安全副本；原v2/目录隔离/恢复失败测试继续。协议严格字段和Windows IPC的保存/备份/重启使用非默认配色。真实WebView验证三方案/应用主题独立、来源屏幕保持、明确保存/重载/服务重启、目录隔离及备份恢复。实际结果仅见[P12](../records/P12.md)，不由源码或库通过宣称桌面通过。
