# ADR-026 串口桌面发送、编码快照与节奏

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（软件 GUI/发送；真实设备与完整接收解码待验）
- 关联：P10/P11/P14/P22/P24、ADR-023/024/025

## 发送边界

新增专用 Tauri serial_request，只转发严格 serial 枚举至同一个服务；不新增通用 RPC/路径打开入口。串口面板只读刷新 Profile 与设备目录，用户明确核对端口/实例/参数和开口控制线后才打开。显示连接 ID/代次、接收/丢失字节、清理状态及失败；关闭按钮在发送等待期间仍可用。键盘和面板写/控制均进入同一服务和 worker FIFO，操作固定 ConnectionRef，不随 UI 切换迁移。

新增 Send(connection, request_id, content, format, ending, pace)。按打开时冻结的编码处理，配置修改不改变活动句柄。UTF-8/GBK/GB18030 文本由既有 encoding_rs 编码，无法表示的字符拒绝，不发送替代字符/HTML数字实体。HEX只接受成对十六进制数字和ASCII空白，不转码；仅在末尾明确追加None/CR/LF/CRLF，不改内部换行。最终非空且最多64KiB，内容UTF-8最多196608字节。内容使用Sensitive，界面提交后清空，不在诊断中显示。

用实际字节+分段大小+间隔的独立指纹域去重；等价字节/节奏返回同回执，变更字节或节奏拒绝。不自动重发/换ID。驱动接受下界和控制调用完成不等于设备执行。面板一次等待一项操作；切换/关闭面板不取消已提交批次，返回消息明确原目标，可切回关闭。完整Agent接管/租约仍留P14。

## 节奏与接收

整个Send是一个FIFO元素，不由浏览器定时器拆成独立请求。每段1–1024字节，间隔0–1000ms，计划间隔总计最多60秒；worker通用Duration按纳秒检查，不能用亚毫秒截断绕过。间隔使用Instant，是最小间隔，不承诺实时精度；驱动/排队会增加实际时间。取消唤醒等待并阻止后续段，已接受前缀不重发，排队尾部按原语义结算。

单线程长时间park会停止接收，因此块间及等待期间查询已有可读字节并做有界接收泵，每轮最多16个4096字节块，仍走原offset/队列/缺口计数。普通大块Write也在块间接收。驱动调用仍可能阻塞，硬件缓冲/错误、取消与吞吐留实机和P22；不保证物理链路无丢失。

原始HEX接收用公共服务独立游标，显示事件序号/缺口，最多256行并说明裁剪。下方终端目前按UTF-8显示；GBK/GB18030接收增量解码和缺口后恢复留P11，不把发送编码当作完整终端编码验收。RTS硬件归属由服务冻结参数及底层共同约束，GUI禁用，直接RPC也拒绝。

## 验证构建、代价与回退

非默认Cargo特性serial-ui-fixture必须同时显式--test-fixture才启用固定COM7内存回显Factory，不枚举/打开原生设备。普通编译仍固定Native，IPC不能切换Factory。原生专项先编译测试服务，经实际WebView/Tauri/NamedPipe/worker验证，再在嵌套finally尝试构建普通服务；必须检查恢复结果。默认开发构建不启用该特性。

证据见[P10](../records/P10.md)：编码/大小、最小间隔、等待中接收、取消/去重，以及原生GUI选择、HEX/CRLF、严格GBK、键盘、节奏、关闭、重载不重发、RTS/DTR/Break和移除。内存端口不是虚拟COM或真实驱动；截图只有合成身份。

替代为UI定时分片（批次可交错、重载时易误重建）或新异步库（需重新证明驱动/取消）。当前服务整批的代价是后续写/控制排队，停止通过关闭；回执等待75秒超时后不自动重发。细粒度取消/接管留P14/P24。持久日志/接收编码留P11，旧驱动身份、真实占用/拔插/控制线与长稳未验收。

无新依赖包、驱动、系统服务、数据库/vault迁移或全局配置。回退新增revert；设备已接受的动作不能由Git撤销。
