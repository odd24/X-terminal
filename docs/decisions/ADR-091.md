# ADR-091 MCP 已保存 SSH2 配置连接与原编号查询

P15 v7 增加 `ssh_connect` 与 `ssh_connect_status`，保留 v6 二十项工具。发起仅接受 Profile ID、固定配置 revision、原编号和终端尺寸。原生桥转发显式版本的 SSH StartFixed，服务只接纳当前 Agent 票据精确的 ProfileRevision Connect，再由配置线程在同一查询中核对 revision 并读取不可变 SSH2 配置。沿 ADR-049 与 ADR-052 复核派发许可，保留 Desktop 对主机信任、凭据和交互认证的控制。

固定版本发起沿既有 SSH Start 的 Single 操作指纹，使既有固定版本批准可用。版本另由该票据的精确 Connect 许可与配置线程核验。账本指纹记录显式版本，和旧 Start、QuickStart、Reconnect 的回执分开。旧 ID 范围和请求参数覆盖均无法进入本路径。

ConnectStatus 只在原账本核对有效 owner、固定版本 Start 类别、Profile ID、revision 和原编号，返回原创建快照，不读配置或派发。两项服务回执均回传上述绑定字段。创建快照不表示在线，不授新连接的读写、任务、控线或租约。应答不明只查询原编号。
