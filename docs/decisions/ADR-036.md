# ADR-036 SSH 文本编码与原始字节边界

- 日期：2026-11-05（Asia/Shanghai）
- 状态：ACCEPTED（软件链路，实机另验）
- 关联：P11.5、R04/T06、ADR-018/026/027/028。

SSH Start与Reconnect各从本次Profile冻结Encoding，状态及exec任务返回同一快照；后续Profile编辑不改变活动代次。候选为浏览器编码、新依赖编码库、服务复用已有encoding_rs；选择服务复用锁定0.8.44，无新增依赖版本。认证用户名/密码/交互回答按SSH协议原有语义，不按终端编码转换。

新增Desktop严格WriteText，敏感正文UTF-8上限196608字节，最终字节非空且最多65536；UTF-8/GBK/GB18030范围保持。无法表示文本整批拒绝，不发替代字/HTML实体。JSON非法Unicode由严格反序列化拒绝。原Write继续保持字节原样，与WriteText等价最终字节共用原Write指纹、FIFO、回执和request_id窗口；更改实际字节拒绝，重复不重发。精确ConnectionRef在读取快照及入队时均检查，重连不能偷换目标。

Exec保留原文本指纹及选项去重，入队前严格转换并保留敏感字节；transport streaming接收AsRef<[u8]>，只把服务确定的字节交给原SSH exec通道，不另起shell，不继承交互目录。任务输出原始字节和stdout/stderr来源不变，任务元数据包含冻结编码；桌面按该元数据维护两个独立增量解码器。消费者历史覆盖时重建字符状态，终止读尽后各flush一次，替换提示不能冒充原始字节损坏数量。

代价：开发IPC严格schema增加字段/变体，绑定组件需同构建，不承诺旧客户端互通。服务增加对已锁定encoding_rs的直接依赖，锁仅登记边关系。桌面仍复用公共输出解码器/控件，不新增专用颜色字体。测试区分合成SSH协议服务器、真实Windows IPC/WebView与真实UNIX端点；前两者通过不代替后者。

回退使用新增revert，同步协议/schema/服务/桌面；无配置迁移、全局Codex修改或输入重放。不能撤销远端已执行动作。P11/G1、BUG-001、实机/长稳及全局UI矩阵不因本选择自动完成。
