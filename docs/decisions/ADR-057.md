# ADR-057 服务端有界输出脱敏投影

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED（策略引擎先行，服务/GUI尚未接入，实测见P14）。
- 关联：P14、R11/R13、T12–T14/T17、ARCHITECTURE服务端限额/脱敏、ADR-044/046/055/056。

## 选择与规则

比较仅桥端替换、每个返回页独立替换、服务按授权完整连续段先投影再分页。前两项分别可被其他读取入口绕过、或从跨事件/分页/截断处泄露片段；选择第三项。原始缓冲、终端解析、日志和用户文件保持原始事实，脱敏只产生独立的外部上下文投影，不能把时间范围过滤当脱敏。

核心Policy有明确敏感字段模式及最多32条/每条256 UTF-8字节的显式字面文本，二者至少启用一项。字面文本逐字精确匹配（含重叠/跨事件/中文），不自动修改空白、大小写或Unicode表示；不是任意正则、脚本或完整DLP。敏感字段识别固定ASCII大小写不敏感的password/passwd/passphrase/token/secret/api_key/api-key/apikey/access_token/refresh_token/authorization/private_key及冒号/等号值，支持引号/转义/未结束值。无引号值保守隐藏到行尾，PEM私钥隐藏到对应类型END整行或本段结束；END须行首开始、整行精确匹配（允许CRLF或文件末尾），行内/前缀/尾缀伪标记不能释放尾部。不声称能发现任意未知密码、混淆、Unicode同形或所有协议格式。GUI后续必须明确规则与覆盖边界，不使用“已脱敏”暗示所有敏感内容均被识别。

规则值仅进程内Zeroizing存储，不实现Serialize/Clone，Debug只显示规则数/字段模式；无效参数也擦除传入规则。后续协议须使用独立敏感包装，不把规则值、可字典枚举的规则摘要或命中正文送Agent/日志/持久审计。策略标识应使用不含值的随机不透明ID，管理视图只显示原批准的规则摘要与状态。

## 完整段与边界

输入为最多256段/合计1MiB的有效UTF-8派生文本，先合并整个获准连续段，再计算掩蔽并按原片段返回；不先切返回页。源缺口、时间排除和stdout/stderr是独立段/流，调用者不得擅自拼接。prefix_cut在字段模式隐藏整个未知段：可能处于多行引号值/PEM中部，单个换行不能证明之后安全；仅字面模式保护可能残留的前缀。suffix_cut隐藏字段末行/可能残留的字面尾部；活跃输出、调用者固定水位、时间窗切口都不能冒充自然结束。边界保护可能过度隐藏，须通过元数据解释，不提前释放潜在半个值；没有可信先前词法状态时不能擅自把prefix_cut改为false。

本纯文本引擎遇ESC、退格、裸CR、其他非普通C0控制或方向控制符时整段保守隐藏，不能把保留控制序列的字符串称为安全可见文本。正常LF/TAB/CRLF仍支持匹配。调用者若提供规范终端可见内容，必须另正确处理ANSI/光标重写/软换行及源边界；没有可证明的安全映射时整段隐藏或明确拒绝该投影，不回退原文。

结果保留片段数和UTF-8字节长度，命中字符按字节数替换为星号、保留LF结构，并返回仅供内部投影使用的掩蔽位置/匹配数/边界与不透明控制标志。这个结果不是同列宽屏幕渲染器，不能直接覆写ScreenSnapshot后宣称原列宽/软换行保持。屏幕集成须从同一获准快照按实际单元格宽度投影并防软换行绕过；标题/其他输出字段、完整和时间窗读取、exec stdout/stderr与其他可达输出都须核对，不能只保护read_text而保留raw/screen/exec旁路。

## 服务和GUI后续准入

策略须冻结在原签发票据/原回执，不从当前标签或实时可变全局设置推导，不原地放宽已批准策略；签发重试匹配原形式/范围/期限及同一策略，仍不续期。受保护票据的旧Raw/Text/Screen/Context/ExecRead等所有可达内容必须统一执行原策略，不能用另一视图或更换分页绕过；不能安全投影时明确拒绝。Read与Exec结果归属仍独立，策略本身不授Read/Write/lease或其他代次，撤销/到期/接管/退休继续按原语义。原始/派生游标、覆盖和源结束与脱敏状态分开，不将掩蔽当原始缺口或修改源文件。

GUI只在明确授权预览里显示将采用的规则/范围与限制，规则值和同意不持久化；原编号查询只恢复不含值的策略元数据。默认敏感字段与自定义字面文本的具体票据字段/原生投影，在服务接入验证后开放；本ADR不把尚不存在的服务/GUI接口写成已交付。真正stdio桥独立继续。

## 代价、验收与回退

无新依赖/数据库/全局配置。KMP逐规则线性扫描，差分数组标记重叠，固定字段/PEM头部只做有界探测，防重复不完整头形成平方扫描。1MiB源临时副本擦除，差分约4MiB，输出/位置数量受输入上限限制；后续服务必须限制并发投影，不能创建无界快照/规则或回执正文。

核心先验证全部分段/重叠/中文、引号与未结束值、正确PEM终止、活跃/截断边界、不透明控制、最大输入/规则/Debug、恶意重复头与重叠压力。服务必须另有真实Windows IPC所有输出入口与分页/时间窗/错误代次/撤销/到期/本人exec/跨流/覆盖负向用例，GUI再实际构建验证规则预览/失效与真实fetch故障。引擎通过不能当服务已保护、真实桥/COM或全局验收通过。回退用新增revert撤下新入口/策略，不扩大旧票据，不修改原始输出或用户文件。Step-ID: P14 / Decision-ID: ADR-057。
