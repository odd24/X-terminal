# ADR-106 新建 SSH2 使用已保存修订与原认证挑战

配置保存成功后按原配置 ID 重新定位会话树，展开配置所在目录并在返回时聚焦原条目。仅保存的分支没有启动连接入口。保存并连接携带保存回执中的原 ID 和修订，经现有 SSH2 固定配置启动通道提交原请求。窗格、服务所有者或回执对应目标变化时停止接纳，并关闭仍属本次的迟到结果。

正常保存配置进入连接后，主机提示使用当前挑战的服务端点与原指纹值。首次与变化两种状态各有默认停止焦点，只有明确批准动作可回答原连接代次和挑战 ID。已知相同指纹继续由服务跳过提示。信任记录沿用服务对端点、算法和原核验修订的检查，变化时更新同端点对应算法。保留手动快速连接、复制、密钥和交互认证入口。

密码补录使用服务返回的连接源参数，复用同一认证挑战、记住凭据的显式选择与 Windows 保护通道。关闭后迟到的任务回执只清理原连接。应用在原挑战状态变化后不重放已发出的信任或认证应答。此变更无需配置迁移，回退使用同目录上一候选。
