# ADR-061 简洁串口临时连接与只接收日志

- 日期：2026-11-08（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P10.1；依据CR-006/007和用户持续推进指令。

已有串口Start依赖保存配置，旧面板把设备库存、确认、发送、控制线和原始字节全部展开，不适合作为初版主入口。候选为①强制先建配置；②界面偷偷保存配置；③Desktop专用非秘密临时Settings快照复用原串口Manager/worker。选择③，不增依赖/日志引擎，不走UI直连串口或ADB。

QuickStart仅Desktop可用，严格serial Settings、库存revision/device_id和原request_id；同一有界Start回执比较完整临时快照，保存配置的Start保持原授权/去重语义。临时Profile仅内存且无credential_ref，合成ID为请求ID，不写配置库；StartStatus只查询Desktop原编号，不建连。Agent不获得临时建连/查询入口，不把临时目标当保存配置授权。原设备精确匹配、占用、库存版本、worker打开/关闭/实际join与有界队列照旧；刷新库存不会重放旧成功请求。

主入口使用共享Dialog/Panel/Field/tokens，端口/115200默认波特率可直接填写，8N1/无流控/UTF-8和初始DTR/RTS低为默认。初始控制线明文显示，用户显式“连接串口”才打开；高级参数可展开，硬件流控的RTS由驱动管理且不可手设。库存缺身份端口不可选择，刷新后重选，关闭或取消在途启动仅关闭其迟到返回的精确新范围，不关闭旧活动连接。未知应答保留原编号，重载仅恢复编号查询，不恢复连接动作或发送正文。

连接成功关闭弹窗/聚焦原终端；持续接收不发送探测命令，发送/HEX/节奏/控制线复用原服务并默认收起。基本日志使用已有LoggingPanel/TEXT可信来源/安全系统另存，不引入用户路径写盘旁路。只接收夹具仅在serial-ui-fixture编译，并拒绝任何写入，用于证明收集日志不依赖命令回显，不是Android硬件驱动验收。

代价：两个协议有各自表单但共享控件与服务边界；临时串口无永久配置名，标签取实际端口。未实现硬件重连/自动发送，真实COM目标/电平/驱动需另行验证。回退以新增revert提交及台账，不删除日志/配置/用户文件。软件/内存IPC/真实硬件分别记录，产品构建和串口finally普通服务恢复必须实际成功。
