# ADR-059 初版stdio桥采用原生Agent连接代理

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED；关联P15/P16、CR-005。

候选是向stdio进程交付bearer，或由Desktop原生桥半部持有独立Agent连接。选后者：进一步减少秘密流转，stdio只持当前用户命名管道；仍走Codex→MCP stdio→原生Agent代理→现有会话服务，不另开SSH shell，不用Desktop bootstrap执行Agent请求。

原生随机endpoint使用现有当前用户DACL/拒绝远程Pipe；OS观察client PID及实际映像，必须匹配同目录terminal-mcp.exe，不接caller身份。stdio验证实际Desktop server PID，参数仅endpoint/PID，不含token。一次只接受一个桥，断开不取消已派发远端动作。

用户先签发/查询P14原授权，再预览实际桥进程+原签发ID/完整授权元数据。默认无同意，原生30秒/一次preview ID；批准前重读原owner回执，核对服务身份/票据/原到期及完整元数据，再在原生创建Agent连接并检查Welcome角色/票据。原授权不续期、不扩大，token仅原生短暂使用并由Sensitive擦除，不进WebView/stdio/argv/env/磁盘。预览改变/过期/丢应答不自动重试，状态只查询；重载不恢复同意。

独立bridge协议只含输出Info/Text/Screen、session list、SSH2/串口精确文本发送和输入lease/原编号回执查询。发送限16KiB UTF-8，无自动换行；读取页至多64KiB，沿固定源水位/批准时间窗，受保护票据由原生强制选ProtectedContext。显式回复投影排除凭据/管理token；不开放通用RPC、配置/认证/库存/日志路径/新连接或关闭操作。本版9个工具，其他P15工具保留后续，不当全v1已完成。

服务端现有scope/lease/owner/generation/request_id及最后派发仍为权限依据。代理10秒Ping只防Pipe空闲断线，不续票据/lease；源审计的OS peer PID是原生代理，client_id仍为真实独立Agent票据，不能谎称该PID就是Codex进程。原生状态另显示实际stdio PID。MCP每次最多4调用、代理单流/1待读队列；取消/IO未知使stdio流失效，不回放或换ID重发，按原ID查询。终端内容只当数据。

验证仅必要协议负向/严格检查、实际桌面配对与真实stdio读写同一合成SSH/内存串口，取租约/去重/越权/接管/撤销/保护及清理。P16另验证实际Codex；不改全局配置，不重复无变化全套。回退新增revert撤下本桥，保留P14授权/服务与用户数据。Step-ID: P15 / Decision-ID: ADR-059。
