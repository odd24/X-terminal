# ADR-022 连接记录显式移除与建连回执窗口

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED
- 关联：P09、P12/P14/P15/P22/P24、ADR-017/020/021

## 问题、候选与决定

原服务最多保留 64 条 SSH2 连接记录，包括已断开/失败记录；Start/Reconnect 的去重表最多 1024 条且不回收。正常反复连接最终永久拒绝。提高上限仍耗尽；自动清理所有结束连接可能无声丢失用户要查看的输出/任务；删除全部请求记录可能重新建连。

增加 Desktop 专用 `ssh.forget(connection_id, generation)`，只接受 DISCONNECTED/FAILED 的当前代次。用户先关闭，再明确点击“移除连接记录”；界面说明这会丢弃保留输出/任务/输入回执。配置、主机信任和受保护凭据不变。没有批量自动清理或自动重连，不承诺撤销远端动作。连接总量仍最多 64；满额时由用户选择可移除记录。

移除与重连共用该连接的异步 gate；拿锁后重查完整代次/状态。先取消并等待后台 actor，2 秒未结束则 abort 并 join，期间不持有 manager/store 锁；之后再按原 ConnectionRef 移除领域记录和 SSH actor 条目。重连先赢则旧移除 StaleGeneration；移除先赢则新重连 NotFound。活动/认证/建连中禁止移除；Observer 没有此权限。迟到的旧 actor 不能影响新的连接/代次。

移除不立即删除 Start/Reconnect 回执。尚保留同 ID/参数请求仍返回原 Started 快照（可能对应已不存在连接），绝不新建；应另查 Status，NotFound 不等于原来没有执行。

回执仍最多 1024 条。沿用 UUIDv7 排序桶与永久单调退休水位，仅在满额时回收最旧可回收有序请求。其结果连接已移除、已进入更新代次，或对应 actor 已完成才可回收；活动当前代次的回执保留。旧 opaque UUID 不回收。全局建连水位同时用于 Start 和 Reconnect：尚保留回执先匹配完整动作/参数，否则不大于退休桶的请求返回 RequestExpired，包括未见过的同桶 ID。检查、回收、再次检查与插入在同一 manager 锁内；等待清理后再次检查跨连接 request_id 冲突，不能被不同 gate 绕过。

桌面 Start/Reconnect 使用已有 UUIDv7 生成器，不改变配置或 connection_id 格式。移除当前记录后清理终端输入队列/渲染/选择，轮询确认记录消失不应误报整个服务崩溃；移除与读并发出现 NotFound 时刷新列表，不自动建连。

## 证据、代价和回退

验证结果见 [P09](../records/P09.md)：契约边界；隔离 Windows 服务的 64 条容量、1100 条 Start/Reconnect、旧请求/未知旧桶拒绝、运行中旧有序回执与 opaque 回执保留；并发移除/重连和跨连接同请求竞争；原生 WebView 移除全部记录后继续建连。快速循环不代替 8 小时长稳与真实设备。

结果与输出由用户移除后不可恢复。旧不透明客户端仍可能到达 1024 上限，不能在有限内存中承诺随机 ID 无限精确去重；UUIDv7 时钟回拨/大范围乱序可保守拒绝，不能自动换 ID 重发或用重连绕过。没有数据库/vault 迁移、新依赖、用户全局配置或系统服务变更。回退新增 revert；服务重启不会恢复/重放旧连接，Git 不撤销远端执行。
