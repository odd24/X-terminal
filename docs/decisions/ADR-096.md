# ADR-096 覆盖另存的写前记录与重启诊断

范围为 ADR-033 的普通本地目标覆盖。沿现有系统选择器、固定句柄和本次明确确认。新文件另存不依赖诊断存储。覆盖在校验暂存、复制 DACL 并同步完成后，在首次原文件改名前同步并发布一条私有意图。前置记录失败、冲突、损坏或容量不足时停止覆盖，保留原文件并沿已有暂存清理。记录后再次检查取消，受保护导出的原生服务提交确认仍紧接改名前。

固定应用根中的独立版本 1 命名空间复用目录 pin、排他锁、单硬链接及重解析拒绝、限长读取和按句柄不覆盖发布。每个保存编号一份有界记录。意图为第一条完整记录，包含保存 UUID、时间、转义基名和固定父目录、原文件及暂存的卷和文件索引。绝对路径、正文、确认码、授权及源指纹不入记录。最多 16 个尝试，满额仅可按受管句柄退休最旧的已记录终态且无需保全关注的元数据。未决、部分失败、未知或损坏记录不自动修复或退休，不能获得容量时明确拒绝覆盖。

只增加两个同步边界。首次改名前同步并发布不可变意图，返回库结果前同步并发布独立不可变终态。中间两次改名维持原语义，避免在备份和发布之间增加一次同步。强制退出在意图后到终态前的任一点都可能只留下意图，启动提示结果未知。可记录已观察到的发布、无发布或仍需保全。中断留下的未发布文件、损坏、未来版本、未知文件或重解析使存储不可用并提示可能存在遗留。终态记录失败独立显示，已发生的发布仍返回原完成回执。该方案只以实际进程异常退出验证同步边界。

Desktop 启动从固定应用目录取一次有界投影，沿共享非模态提示及主动查看，只显示原编号、基名、已观察阶段和时间。提示不代表文件当前状态。记录既不签发同意，也不验证外部对象。启动不打开外部路径，首包无目录选择核对、自动恢复、续存、替换、改名、删除或旧编号重放。治理只触及已验证的受管记录，用户备份与暂存均保留。
