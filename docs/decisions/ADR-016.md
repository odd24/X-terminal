# ADR-016 同一 SSH2 transport 的有界 exec 任务

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（服务任务阶段；桌面/Agent 任务体验继续）
- 关联：P09/P14/P15、R01/R11/R12/R13/R14、ADR-014/ADR-015

## 决定与候选

exec 使用已认证的 Ssh2Session 独立 SSH channel，不另外启动 SSH 连接、不向交互 shell 拼接命令。它不继承交互 shell cwd/环境/前台程序，API 和后续 UI 必须明确。使用任务模型而非同步等待 RPC：启动只登记任务并返回 task_id，状态、增量读、取消独立调用，避免长命令阻塞 Pipe 或诱发客户端自动重发。

启动必须明确 connection_id/generation/request_id、敏感 command、timeout_ms 和 max_output_bytes；command 非空、至多 64 KiB、无 NUL；执行限 1–86400000 ms、输出总限 1–1048576 字节。参数是明确定义的限制，不承诺无限执行/存储。SHA256 指纹包括命令、超时和限额，相同 request_id/相同参数返回同任务；内容或动作类型与 write/resize 冲突拒绝，不重试/重放。

任务启动进入已有 FIFO，与普通写入/resize 按派发顺序共享入口；派发后独立执行，任务完成顺序可以不同。活动任务包括等待/运行/取消中，每连接至多 4 个、全服务 16 个；保留结果至多每连接 16 个、全服务 64 个。不隐式淘汰去重证据，满额明确拒绝；长期清理/墓碑/分页策略仍待 P14/P15/P22，当前不能称为完整长会话容量。只有 active Desktop 能启动/读/取消；Observer 的 shell 只读票据不自动获得任务输出范围。

## 输出与结束语义

新增 exec_streaming，SSH2 输出在成功应答前也可增量交给服务；8 槽传输通道有背压。每任务独立 64 KiB/128 事件滚动缓冲，按序号保留 stdout/stderr 标签；读取回复明确 connection/task_id、next_cursor/available_from/truncated/completed。不同读取者游标独立。输出不能混入 shell 原始流；滚动覆盖是读取缺口，和超出任务总限额的 output_truncated 是两回事。

服务同时保留结构化结束摘要：可选 exit_status/exit_signal、是否收到请求批准（可能未知）、stdout/stderr 总计数及结束原因。Completed 可以带非零 code，例如 7；它表示收到退出结果，不等于命令成功。RemoteSignal、MissingExitStatus、TransportLost、Rejected、Timeout、Cancelled、OutputLimit、ProtocolFailure 分开，不编造 code=0。收到输出而没有批准时仍不能证明未执行。

Queued 取消为 CancelledBeforeDispatch，不调用 exec；Running 取消先变 Cancelling，再由 channel 操作结束；连接关闭/失败会结算未完任务并停止队列。已派发任务取消/连接终止只能报告远端结果可能未知，不承诺动作撤销。完成结果不会被迟到取消或子任务覆盖。所有者关闭真实 socket，子任务由连接 JoinSet 管理，不能遗留另一个 SSH 会话。

## 成本、证据和回退

为提供流式结果，暂时还保留 transport 单次 ExecOutcome 的受限 stdout/stderr 缓冲，单任务最多 1 MiB，加上滚动/传输队列有界；全服务并发受限。尚未设计任务结果持久化、输出落盘、Agent 授权/接管、长期容量或 GUI。应用实现不能将这些待办从最终 v1.0 删除。

领域用例验证标签/独立游标/输出覆盖缺口，传输用例验证批准前即可读取且取消保留部分结果；Windows 独立服务+隔离 SSH2 服务器验证一次执行、参数冲突、Observer/旧代次拒绝、shell 隔离、非零/信号/缺码/超时/限额、排队取消/并发上限。结果见 P09，不将隔离服务器当真实 UNIX 验收。

回退新增任务接口不改配置/vault 格式，不改用户 SSH 配置；已发生的远端动作不能由 Git revert 撤销。后续迁移任务存储/容量须保留明确代次和去重语义。
