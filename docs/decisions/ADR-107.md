# ADR-107 会话树连接在桌面绑定落位和焦点

会话树三个入口冻结发起窗格的实例和服务所有者。窗格恢复、关闭后重建或服务换代产生新实例。标签栏在精确启动回执到达后发布新标签，将现有显示顺序显式化后追加。现有分组之后可继续容纳新未分组标签。复制和工作区使用原有放置入口。

SSH2 读取配置后核对所选连接的参数和凭据引用，再以读回的修订启动。认证按回执中的连接代次查询和回答。主机信任等无关配置更新可以推进全局修订，原连接参数一致即可使用新读回的修订。显式记住凭据后刷新树。串口保存配置使用当前配置修订、设备清单修订和设备 ID。SSH1 保留预览开关和显式许可。

会话树认证窗口支持用户切换已有标签和窗格。发起时保留的一次焦点交接在主动切走后失效，迟到认证仍在原目标，输入沿用受管终端路由。已取消且尚未交接的准确结果仅在原服务处理。快照与回执使用不同的到达顺序，新标签由回执认领。

桌面身份可通过已认证 IPC 使用固定串口启动和查询。MCP 桥仍需要原单操作授权，回执按原发起身份和完整目标核对。沿用原服务协议和数据格式。回退到上一便携目录时可复用原数据和配置锁。候选的桌面和服务应一起运行。
