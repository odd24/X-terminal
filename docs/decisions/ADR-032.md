# ADR-032 导出产物指纹与受限验证复制

- 日期：2026-11-05（Asia/Shanghai）
- 状态：ACCEPTED（生产指纹、回执与文件库验证复制；原生保存/目标发布尚未接入）
- 关联：P11.4、R12/R13/R14、T16、ADR-030/031

## 选择与候选

用户自选保存位置需要复制已有受管理导出，而不是把任意目标路径加到日志RPC。候选是只检查文件长度后复制、保存时重新生成日志、生产时记录SHA-256并在复制前后验证。选择第三项：同长度改写不能靠长度发现；重新导出可能因源保留范围变化或已整理而不同于用户选中的产物。指纹随精确ConnectionRef/log_id/request_id的可信服务回执传递，不把用户或文件内自报哈希当作来源授权。

terminal-log直接复用仓库已锁定的sha2 =0.11.1（session-core已使用），不引入新的版本/下载或自行实现哈希。Limited写入器只对下游实际接受的字节计数与更新哈希，短写重试不会重复累计；JSONL最终flush、文件sync、无覆盖发布全部成功后才交付ExportArtifact的bytes/[u8;32]。哈希不写回JSONL，文件格式/源日志/保留范围均不迁移，也不把哈希当作秘密或数字签名。

ExportInfo仅COMPLETED携带64位小写十六进制sha256，排队/运行/失败/取消/REMOVED均为null；清理清空旧指纹，前端核对精确scope及指纹形状后才接受成功路径。旧/缺失字段的成功结果不能用于可信复制；本应用服务/桌面/schema需一起更新。现有JSONL文件不会因升级自动重新导出或改写，服务重启不恢复本次回执的限制不变。

## 文件读取与复制

Windows VerifiedExport只接受可信应用目录、非nil导出UUID及生产回执的长度/32字节指纹，固定读取terminal-log-exports/UUID/export.jsonl，无任意源文件名/路径选项。祖先、根、UUID目录逐级pin并拒绝reparse；固定文件以OPEN_REPARSE_POINT、只读且只共享读的句柄打开，拒绝目录/reparse、缺失、非正数或超256MiB长度。它不创建根/锁/文件，也不争用导出写入者exports.lock；持有源句柄时普通改写、改名和DELETE清理拒绝。

先用64KiB缓冲完整验证源长度/哈希，成功才返回句柄；copy_to重新从头读，核对实际复制字节及最终哈希，再flush下游。内存不随文件增长。每块及最终结果前检查取消；取消不能中断正在阻塞的OS I/O。目标必须是调用方提供的全新私有暂存sink；失败可留下部分甚至全部字节，不能发布。Ok只证明这次复制字节与可信回执相符，不代表目标sync、发布、覆盖授权、断电持久或远端执行撤销。

复制期间若同用户进程持有其他非常规写入方式，第二遍哈希仍检查读出的实际字节；不宣称防御同权限进程接管、硬件篡改或哈希碰撞。源后续被外部改变不追溯改变已校验复制结果；不是文件系统长期监控。目标写入/同步/改名的失败语义必须由原生保存层另行处理，不能用本接口成功冒充“另存完成”。

## 原生保存后续约束

本阶段不提供原生对话框/目标发布/打开目录按钮。后续应只接收精确导出scope，向服务确认COMPLETED及指纹；目标由用户在原生选择器中明确选定，不把任意路径放入通用RPC或模型参数，不在终端/输入通道做文件I/O。保持任务有界、原目标固定、取消/关闭/不明结果可查询，复制经私有暂存并核对/sync后再发布；已有目标覆盖必须单独绑定用户确认与当时文件身份，不自动覆盖或重试。原产物保留，结果可供审阅后再实现打开其所在目录。

Windows的保存选择器可提供覆盖提示，[Open and Save As dialog boxes](https://learn.microsoft.com/en-us/windows/win32/dlgbox/open-and-save-as-dialog-boxes)说明相关选项；[ReplaceFileW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew)列出替换失败时不同名称/内容状态。因此不能把“调用一个替换API”描述为任何失败都原样回滚，具体目标发布方案需再形成实现与真实Windows验证。

## 证据、代价与回退

真实受管理JSONL产物验证指纹/复制一致，标准abc向量与短写累计、同长度篡改/长短不符/partial-only、占用/取消/flush失败、缺失根不创建、真实自建NTFS junction拒绝及目标保持见[P11.4](../records/P11.4.md)。原生导出专项以Node crypto独立计算实际文件SHA-256比对服务回执；库/回执通过不等于用户自选保存流程已完成。

代价是复制前后的两遍有界读取，最大源256MiB，最多处理约512MiB读取；期间占用有限目录/文件句柄，清理需等其释放。后续保存层必须使用有界文件worker，不能在UI或会话锁下执行。真实长稳/低速盘/磁盘耗尽/用户覆盖与UI矩阵仍后续验收。

回退新增revert，同步生产者/回执/schema/前端；已有源与导出文件不改变，不删除用户目标、不重放导出或记录。若已实施原生保存，回退须停止暴露依赖此指纹的保存入口，不能静默改为仅按长度复制。
