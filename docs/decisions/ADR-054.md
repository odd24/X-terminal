# ADR-054 Agent Forget的独立范围与完成回执

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED（核心、SSH/串口服务与两协议GUI已有软件证据；实际结果/边界见P14，真实桥另验）。
- 关联：P14、R11/R13、T13/T14/T17、ADR-044/051/053。

## 选择

候选为放宽旧无编号Forget、复用Disconnect授权并等待清理、独立Forget范围及完成回执。选择第三项：旧Forget保持Desktop专用；ForgetStart/ForgetStatus要求完整ConnectionRef/request_id，服务认证ticket绑定owner，不接受调用者owner。Forget不推导Disconnect、Reconnect、读取或配置删除。

新操作要求精确旧代次Forget与当前lease。仅Disconnected/Failed且已有实际本地传输结束证明时移除；SSH要求Actor任务已结束且共享传输Weak强引用为0，串口要求实际worker join回报、无未结算ticket。领域状态、取消标志和丢失join通道不代替回收证明。清理未完返回InvalidState，不取消传输、不预留成功回执，可在清理结束后以原编号重试。与等待/取消Actor的旧Desktop操作区分，不承诺远端执行撤销或驱动缓冲排空。

SSH与Reconnect/旧Forget共用每连接gate；等待前捕获许可，等待后再认证、原编号查回、核对许可和精确代次。实际移除在同一生命周期/Store锁内复核并dispatch，随后退休范围/lease。退休后同owner原编号先查完成回执，不再查范围、不续期或操作新代次；ticket仍须有效，撤销/到期拒绝查询，未知Agent查询不泄露目标存在性。

独立账本最多1024项，Removed只指精确代次记录已移除，不删除Profile、日志、导出或用户文件。没有虚拟Requested：授权/清理/容量预检失败不记成功。同锁无await的remove_with先查编号/容量，删除闭包成功后才记Removed；失败不淘汰旧记录或推进水位，闭包不得在已删除后返回失败。UUIDv7只淘汰最旧完成记录且拒绝整个同毫秒退休桶，不透明UUID不淘汰。Start/Reconnect/Disconnect账本继续独立保留，不因移除重放。

## 代价、验证与回退

串口服务复用独立完成账本，ForgetStart/ForgetStatus与原输入/Disconnect白名单分别认证，旧Forget仍Desktop专用。新请求在inner→Store锁内核对原owner、独立Forget/lease、精确Serial终态、joined及空tickets，再检查Start/输入/Disconnect编号冲突并通过remove_with容量预检；同锁派发后移除，不取消worker、无await窗口。实际join回报丢失继续拒绝并无成功回执，可原编号重试；旧Disconnect账本终态保留，日志/配置/用户文件不变。准确服务/feature IPC与原生结果见P14，不代表COM或GUI批准/真实桥完成。

代价是清理未完时需查询原Disconnect并重试原Forget编号。没有新依赖/数据库/全局配置，回执不跨服务重启。核心5项测试覆盖重复闭包不执行、来源/代次冲突、失败无回执、容量不删除、成功才退休及同毫秒拒绝，结果见[P14](../records/P14.md)。服务须分别验证SSH/串口独立范围与lease、真实回收、gate等待撤权、丢应答原owner恢复、跨来源及撤销/到期拒绝、移除后新建与旧编号不重放；GUI固定目标/默认无同意及真实stdio交付独立完成。

回退新增revert关闭新入口，保留旧Desktop路径，不恢复同意或重放。完整P14、R01–R16/P01–P25及全部阶段门继续开放。Step-ID: P14 / Decision-ID: ADR-054。
