# ADR-092 MCP 固定设备 UART Connect 与原编号回执

v8 新增 `serial_connect` 和 `serial_connect_status`，保留 v7 二十二项。复用 Desktop Single 完整串口批准，其中配置版本绑定端口与初始 DTR/RTS，操作指纹绑定库存版本、设备及原编号。批准确认后仅在当前授权面板显示本次工具参数，由用户显式转交。参数不含端口、OS 路径、控制线覆写、库存列表或票据秘密。

固定版本入口只接受对应 Single 指纹和精确 ProfileRevision Connect。配置线程读取同版本快照，服务核对同库存版本和设备、配置端口及独占占用。实际打开前 worker 复核原许可、库存版本和停止状态。物理打开继续使用已有不可变设备身份校验。未派发取消不得应用初始控制线。

独立状态查询按原有效 owner、固定设备操作类别、原编号和目标查账本，不轮询 worker 或枚举设备。回执仅为创建快照。应答未知只查询，禁止重发打开。测试使用显式启用的计数内存 UART。
