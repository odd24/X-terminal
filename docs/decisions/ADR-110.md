# ADR-110 快捷指令 ZIP 清单与资源提交

ZIP v1 使用 `manifest.json` 保存有序指令、脚本相对路径及每个资源的 SHA-256。ZIP 解析使用锁定的 `zip` 8.6.0，仅启用所需的解压支持。文件名逐段校验，拒绝目录穿越、Windows 保留名称、大小写碰撞、非普通文件及未知资源。验收上限为 32 条指令、128 份资源、单个资源 8 MiB、资源总计 32 MiB。[ZIP 依赖文档](https://docs.rs/zip/8.6.0/zip/)

源包预览留存原修订及实际读取的字节。目标按资源清单摘要分配独立目录。暂存资源写完后原子移到最终目录，提交用原数据库修订一次保存。失败只清理本次新建文件，已存在且核对通过的同内容资源可复用。进程异常时未登记的资源不会成为快捷入口，完好的目标资源可在之后复用。

数据库沿用原结构。回退可用原版本读取已导入的指令和脚本路径。回退时保留受管脚本目录。ZIP 不包含 ADB 安装路径或本机布局。
