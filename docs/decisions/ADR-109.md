# ADR-109 复用 PowerShell 编辑器插入通道处理本地粘贴

Windows 实窗证据显示，把原 LF 文本直接写入 ConPTY 会让 PSReadLine 缓冲区中的管道行和过滤行交换。保留当前命令行光标需要编辑器一次接收整段文字。[P26.98](../records/P26.98.md)

扩展原有按任务分配的单用户命名管道。路径请求仍按语法位置校验，文本请求按长度和控制字符校验，并调用同一个 PSReadLine `Insert`。请求带原编辑代次及过期时间。PowerShell 正执行前台任务时，以编辑状态为零识别原任务，进入既有输入队列，写入前再次检查编辑状态。编辑状态不可核对时，需确认的粘贴保留在预览。不重放回执不明的插入。

这项变更无持久配置迁移，旧数据可直接跟随原程序版本使用。回退使用先前的成套便携目录或新增 revert，本地数据和原配置锁沿用现有规则。
