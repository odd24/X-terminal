# ADR-053 SSH重连的双范围与旧代次回执

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED（P14服务子步，实际结果见P14）。
- 关联：R01/R11/R13、T01/T13/T14/T17、ADR-022/044/049/051/052。

## 选择与派发边界

候选为仅凭Profile Connect替换任何结束连接、直接复用Disconnect批准、独立旧代次Reconnect加固定配置Connect。选择第三项。新增Connection上的独立Reconnect动作，精确旧ConnectionRef及当前lease；只允许Disconnected/Failed，不关闭正在工作的连接。用户须在旧传输结束退休后重新批准旧代次；不恢复已退休的读写范围或租约。Profile Connect单独批准指定Profile/revision，两份范围须属于同一真实ticket；重连不接受旧ID-only Profile范围作为固定配置批准。

新操作先认证并查同owner/同旧代次/同尺寸的原Start账本，再检查Reconnect/lease，才读取旧记录关联的Profile ID并捕获Connect许可。原1024条Start/Reconnect账本与UUIDv7水位仍有界，owner随原记录回收；跨来源UUID拒绝，不新增永久映射或调用者owner字段。保留的原编号只返回创建时ConnectionInfo，旧记录/配置删除、范围退休、lease释放后也不重建或续期；ticket撤销/到期仍拒绝。返回Started不是当前在线状态。

每连接restart gate串行化重连/移除；等待gate之后、配置线程核对revision返回不可变快照之后、旧Actor join与传输引用释放之后，均复核原两份Permit。释放再取lease不能复活在途许可。配置错误不先取消旧Actor；清理已开始后撤销只能阻止新generation，不能撤回本地清理。无Store/manager锁跨await。

推进generation前在Store锁内dispatch旧Reconnect许可并退休旧范围/lease；该派发边界只批准替换旧记录。新Actor另携带同一Connect Permit，DNS/TCP future首次poll前仍与撤销同锁核对；退休旧代次不应取消独立Profile范围。新generation不继承Read/Write/Exec/Control/Disconnect/lease、输出、队列或任务，不重发旧命令。配置读取后的编辑不替换本次不可变快照，后续新操作受全库revision约束。主机信任、密码及交互认证仍仅Desktop。

## 边界、验证与回退

旧无编号Forget仍Desktop专用，Agent移除将独立采用编号/回执，不从重连推导。GUI目前只解析/显示新动作的管理回执，不提供重连批准组合入口；真实stdio桥仍P15，不能把服务IPC当GUI或Codex交付。串口不借SSH接口重连，SSH1未隐式降级。

核心测试扩展动作独立及精确lease；确定性服务测试在真实配置消息等待后撤销/接管/释放重取/到期，检查generation不变且本地监听无接受；新Actor首次poll前撤销同样不得连接。真实Windows IPC验证双范围、无lease拒绝、固定revision变更拒绝、同owner原编号恢复、跨来源/退休/删除后不重放及新代次无隐式能力，保留Desktop重连/移除/容量回归。准确命令结果见[P14](../records/P14.md)，合成SSH不等真实网络、长稳或完整R01–R16验收。

无依赖/数据库迁移，IPC v1同构建新增动作枚举，schema与管理投影同步。代价是两份批准/旧代次新lease及终态后审批；保守拒绝优于复活原范围。回退新增revert关闭Agent Reconnect，保留原回执和Desktop路径，不恢复同意、不重放或撤回远端动作。完整P14及所有阶段门继续开放。Step-ID: P14 / Decision-ID: ADR-053。
