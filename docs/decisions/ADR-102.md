# ADR-102 会话配置删除的服务内修订检查

现有树入口通过打开管理窗口处理删除，删除前在桌面重读目标。重读和按编号删除之间，其他客户端可能修改配置。同一确认也可能在管理窗口内出现，两处需要一致的删除约束和失答语义。

桌面两入口使用原配置 UUID 和显示该配置时的配置修订，调用新增的 `delete_profile_if_revision`。配置服务串行检查修订并复用原删除实现。原按编号的 `delete_profile` 保留给现有客户端，新桌面遇到不支持条件删除的旧服务时不会改用原请求。记录、连接与凭据的所有权保持原边界。

删除确认冻结配置快照。只有该次请求的有效更新应答可显示删除成功。回执不明使用普通配置分页读取原 UUID，报告核对时的存在状态，无自动补发或存储迁移。试用回退使用原版桌面和会话服务配套程序及原数据锁。
