# ADR-084 审计关闭安全诊断与测量错误阶段

- 日期：2026-11-10；状态：ACCEPTED；Step-ID: P22。

007380c已证明旧异常缺最后状态/首错阶段，不能追认QUEUE_FULL。监督准入诊断增强，非旧故障根因修复；不改RPC/schema/renderer权限、队列/段容量、到期或失败封闭，不重跑吞吐/短时延迟或旧根。

采用现有service stderr追加固定前缀`audit_close_diagnostic `及version=1白名单JSON；仅固定outcome/state、accepted/synced/rejected/incomplete和首次failure.kind/stage。u64计数为十进制字符串，避免调用方整数精度丢失；不可取得状态时明确null，不伪造0。正常关闭也输出快照，失败继续原错误退出；owner任务join/close失败与状态水位不满足分别报告。不含正文/路径/token/底层异常Display/Debug，不向已失败审计再写诊断。它是结束时采样，不自动证明所有记录已同步或磁盘绝对持久。

Writer在现有锁内新增独立first_failure，仅首次赋值。kind为固定QUEUE_FULL/CHANNEL_DISCONNECTED/SEQUENCE_EXHAUSTED/IO_FAILURE，stage为SUBMIT/APPEND/CHECKPOINT/FLUSH_BARRIER/CLOSE_BARRIER。APPEND涵盖编码/换段/文件追加，不能当单一OS write；原文件没有独立BufWriter.flush，显式Sink.flush实际是同步屏障，按真实语义标注。现有state转移与失败行为保持，后续失败不能覆盖first_failure。现有公开Status/RPC不新增字段。

测量调用方在每个普通Err分支也保留最先可知阶段、原错误安全类别；Shutdown请求/ACK、真实exit code、实际强退尝试/结果作为清理次错独立保存，不用强退尝试替代正常退出或覆盖load首错。未知变更不重放。诊断只输出允许的固定字段，动态底层错误字符串不进入新增报告。

先用有界可控队列/追加/同步/flush屏障/close屏障验证首错粘滞、白名单和不泄漏合成秘密；再独立测试服务构建验证正常与在途关闭、故障错误退出和权限拒绝。故障钩子独立Cargo feature，另需显式测试参数/Temp直属中文自建根；普通构建拒绝测试参数。固定arm/release标记只控制自己的有限测试，不新增RPC或任意路径能力，不打开旧根。生产源实际Desktop构建与影响专项、fixture finally普通实际恢复。

替代：只加泛化异常字符串不能补证且可能泄密；仅在同一audit写诊断会受原故障影响；新增renderer/Agent读取入口超出范围。回退关闭新增测试feature或revert诊断提交，无数据迁移，不削减原安全失败语义。
