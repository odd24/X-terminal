# ADR-017 显式重连与连接代次隔离

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（P09 服务重连阶段；桌面/长期容量继续）
- 关联：P09/P14/P15、R01/R11/R13、ADR-007/ADR-014/ADR-015/ADR-016

## 决定

公开 Reconnect 只接受当前明确 connection_id/generation、request_id 和尺寸；仅 active Desktop，可从 Disconnected/Failed 启动，活动连接先由用户显式 Close，不在 Connected 状态隐式打断执行。保留 connection_id，使用领域 begin_connect 递增 generation、重置原始输出/序号；不把新 UUID 连接伪装成同一会话重连，不提供自动重连/自动重放选项。

每次重连读取当时的 Profile 快照，必须仍为 SSH2；配置不存在/不支持时拒绝且不递增代次。使用新的 Cancellation、挑战/认证状态、输入 FIFO/回执、exec 表和输出缓冲。沿用持久主机信任作只读评估，但新端点/变化密钥仍需当前握手确认；认证仍发新挑战，不沿用旧回答或临时密码。受保护凭据在主机批准后核对新快照取用。

原 Start 和 Reconnect 的服务内请求账本区分动作、重连来源代次、尺寸等。相同 request_id/参数返回最初 Started 结果，不再次递增；参数/动作冲突拒绝。对来源代次已有 write/exec request_id 的复用也拒绝。重试响应是原始结果，客户端需另查当前状态，不能把旧 Started.state 当现在仍在连接。账本原 1024 项上限保留，不为了重连清空去重证据。

## 并发、清理与授权

每连接有一个跨代次复用的异步重连锁；不同连接独立，等待时不持会话或配置锁。同源代次并发同 request_id 只有一次迁移并返回同结果；不同 request_id 竞争只允许一个迁移，另一个因旧代次拒绝。迁移前取消旧 token，至多等待旧连接任务两秒，超时 abort 并等待释放。已派发远端动作不能撤销；这些清理不能解释为远端尚未执行。

旧连接 actor 的状态、挑战、输入完成和清理回写均核对 Entry.reference；旧原始输出仍由 Sessions 校验代次。旧 exec 子任务只可能命中旧 task_id，不能覆写新任务。新代次不会继承队列或任务、输入回执、旧屏幕输出或挑战；旧状态查询返回 StaleGeneration。旧授权票据仍只包含原精确代次，不能读新输出；这不是宣称撤销所有旧票据，也不缩小 Desktop 的管理权限。P14 的 Agent 写授权/接管仍未实现。

## 代价、证据与回退

当前服务表只持当前代次，旧任务/原始输出不迁移；历史导出、审计和持久任务记录留 P11/P15。旧代次请求明确拒绝，不能静默映射到新代次。长期输入/任务/重连容量仍留 P14/P22，不能用重连清账来宣称解决所有长期容量问题。GUI 重连与实际网络环境验收继续。

独立 Windows 服务+隔离真实 SSH2 包用例验证 ID 保留/代次递增、同请求并发去重/不同请求竞争、旧写入/任务/挑战/票据拒绝、缓冲从 seq=1 重建且无旧字节、Profile 更新到新端点需新指纹和凭据、Profile 删除后不迁移。背压用例验证 64 KiB 只已发送 32 KiB 时关闭/重连，不重发部分前缀或未发送队列。结果见 P09，不替代实机/桌面/长期压力。

回退只撤去重连接口，不变更配置/vault；保留已经可能发生的远程动作与审计要求，不将 Git revert 当作网络回滚。
