# ADR-083 T18仅测试构建的原生只读观察者

- 日期：2026-11-10；状态：ACCEPTED（测试集成范围，非产品能力）；Step-ID: P22。

用户恢复持续执行，监督明确准入独立观测。旧两轮WebView/CDP全源批读deadline失败保留，不将不同配置的结果覆盖旧结果。UI继续原可见窗格poll/真实键盘；不改源速率、生产容量、主通道调度或日志/审计语义。

采用默认关闭的Cargo feature `load-observer-test`，另需启动参数和Temp直属中文自建根。默认构建收到该参数直接拒绝；没有新增renderer命令。测试启动者通过根内固定、有限16KiB计划文件提供service_id/20精确ref/8或120秒；原生核对同一服务全部20个连接均Connected SSH2且server_host为127.0.0.1。拒绝重复/额外/旧代次/其他协议/其他服务和任意文件路径。这个测试二进制只给受信任本机测试启动者，不面向用户部署，也不把临时路径前缀视为跨用户安全凭据。

原有已认证Desktop Client通过现有IssueRead签发固定范围、有界期限Observer票据；仅原生私有持有，沿现有Client验证服务PID/Welcome服务ID及Observer身份。bootstrap不保留/导出，不借Agent批准，不新增生产签票API。预先用独立短票据核对别源/错误代次/未知ID拒绝、写入拒绝、到期及撤销后旧连接拒绝；全部在合成连接且负载前完成，不重放未知变更。测试票据最终原Desktop撤销并实际验证旧Observer被拒；异常时仍尝试撤销并分别报告，服务退出亦清空票据但不能冒称主动撤销成功。

到期记录原服务返回expires_at_ms（服务自身单调轴）、100ms期限和原生独立单调观察时长；先实际读取成功，再等待并实际取得PermissionDenied，不把不同单调轴直接相减或仅凭sleep判定过期。别源用真实存在的第二连接，未知ID独立核对；错误代次使用第一连接的不同generation。主观测工作线程退出并join、runtime/Client释放之后，由不持能力的有限finisher发布最终摘要；旧root/plan只处理一次，每轮新唯一根，迟到不改投新轮。

首次无负载预检发现测试端混用了Agent的Welcome.client_id约定。现有server只为Agent返回ticket_id；Observer返回pipe_id。测试端按真实协议核对同service_id/Observer/非空pipe_id，Client仍核对原服务PID与协议版本；不改协议让Observer冒充Agent，也不把pipe_id用于撤销。票据绑定由私有IssueRead token握手及实际限定范围/到期/原ticket_id撤销验证共同证明，原失败保留。

专用原生线程/独立Tokio runtime使用Observer NamedPipe每100ms顺序轮询20源、每次64KiB，直接核对序号/固定1024字节/内容/累计SHA及源Gap/退休/精确ref。保留每源≤一个响应加不足一帧尾部及20份有界计数/哈希，不向WebView搬正文。不宣称无开销：同一服务状态锁/原审计/CPU仍有竞争；记录调用次数/max耗时及整体轮询时长。固定路径只写ready/最终有限摘要，测量期间不逐响应写磁盘；停止文件/绝对截止/失败关闭。Node只读有限摘要、保留真实输入两时钟指标与资源观察；不同配置单独命名报告。

测试构建从实际Tauri构建产生并复制到隔离目录（含普通服务）；随即恢复普通Desktop实际构建并验证测试参数拒绝，再使用隔离测试exe。结束普通服务实际build/fixture=false/测试API拒绝及自有进程退出核对。代码级保护与真实IPC定向验证先完成，再一次8秒校准，通过才一次固定120秒；失败先定位，不无限换参。正式样本nearest-rank第114/120、100ms阈值与远端通知保守上界分别报告，不提供8小时/开日志/实机或完整P22通过结论。

替代方案：继续让WebView额外搬20流保留为已失败配置；单独服务不能观察同一UI会话；暴露bootstrap/普通renderer签票/复用Agent均拒绝。代价是维护独立测试编译与启动集成、显式摘要/退出验证；回退为关闭feature并保留所有失败证据，无schema/用户数据迁移。
