# ADR-087 P15 串口字节与显式控制 stdio 包

- 日期：2026-11-10；状态：ACCEPTED；Step-ID: P15。

监督仅准入serial_write/serial_control，目录由v2十二扩v3十四，保留前十二逐字段schema及公开结果。write只收1..16384个u8整数数组，不编码/加换行/HEX解析；control只收DTR/RTS/BREAK固定line及显式asserted布尔，不提供脉冲/默认动作。沿原Agent WRITE/CONTROL、lease/FIFO、原编号/owner/代次及Single完整规范参数校验，不扩大库存/配置/打开关闭/日志/认证权限。配对不执行控制；Unknown只terminal_input_status查原编号，不重发动作，旧ID换动作/正文拒绝。

现有服务InputReceipt只含request_id/state/driver_accepted/failure。按监督取舍不扩服务协议：新工具typed回复{connection,receipt}中的connection是native冻结的原请求绑定，不能称服务独立回传或证明了connection；native核对服务receipt.request_id和Client真实wire response id。授权事实仍来自原服务owner/精确代次检查。旧send/status结果结构不变，但SERIAL路径同样先核对返回request_id；不匹配或错回复类型拒绝。protected票据现行输出路径保持，不允许新工具请求raw。

验证先协议边界/typed负向，再已有服务Single/权限契约，实际desktop:build与仅合成内存UART真实stdio。新增显式默认关闭serial-mcp-fixture编译/参数，仅Temp直接中文自建根及固定内存端口，普通构建拒参数。计数在Port::write_once/control真实调用点，有限write次数/字节数及≤64条固定line/值序列，不保留正文/秘密；不以请求/ACK计数代替控制器副作用，不增MCP或生产renderer快照工具。只读固定快照文件可能遇部分写，有限重读观察，不重试实际操作。

覆盖无lease、WRITE/CONTROL不互授、跨owner/代次/撤销接管、Single参数/编号不符、00/FF/控制字节精确回显与控制器计数，真实写/控首应答调用方丢弃后只查询、旧ID改动作拒绝、迟到/失联。新原生回复绑定反例/普通参数拒绝和finally实际普通build/runtime必验；原12及14工具安全矩阵按影响检查，复制品14tools/list按包独立命名。无真实COM89或控制线，无T18/T19/长稳或模型；完整MCP/P15/实机不收口。
