# ADR-103 WebView2 原生上下文菜单过滤

原生网页菜单来自每个 WebView2。保留文本编辑的本机可用状态、密码框限制和输入法行为，采用宿主的原生菜单请求事件，并通过 Tauri 对每个已创建 WebView 注册相同策略。应用消费的会话树、终端及标签事件仍由现有代码处理。[Microsoft 的 WebView2 菜单说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/how-to/context-menus)

在处理请求时先阻止默认菜单，只对可编辑目标保留撤销、重做、剪切、复制、粘贴、删除和全选等原生命令。过滤使用不随语言变化的命令名。宿主先关闭原生菜单，完成回调注册后开放过滤后的菜单。旧运行时若不提供原生过滤接口，原生菜单保持关闭，应用菜单和原显式键盘操作仍可用。

新增显式依赖与原 Tauri 传递依赖使用同一 webview2-com 版本。数据及权限契约无需迁移。回退时仍按原 Windows 配套程序与数据锁运行。
