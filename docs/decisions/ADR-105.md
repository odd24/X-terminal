# ADR-105 保存串口配置使用设备清单

配置表单与快速连接共用服务串口清单、设备查找及端口下拉。Windows 驱动若提供友好名称，服务在已有 PnP 枚举中读取有界字符串并随清单返回。缺少名称或读取失败时显示 COM 号。名称只用于展示。[SetupDiGetDeviceRegistryPropertyW](https://learn.microsoft.com/en-us/windows/win32/api/setupapi/nf-setupapi-setupdigetdeviceregistrypropertyw)

服务每次刷新发放新清单修订。同一服务上连续检测到相同 COM、PnP 实例和服务内部接口路径时沿用临时设备编号。发现缺失或同号替换时，后续编号独立。保存配置仍只存 COM 和通信参数。接口路径留在服务内，设备编号不持久化。

保存并连接继续进入原快速连接确认窗口。它重读配置和清单，按设备编号和 COM 核对先前选择，再由服务检查最新修订、目标配置和打开前的 PnP 身份。保留离线旧端口只用于保存配置。找不到原设备时要求显式选择，既有连接与正在处理的原请求保持原有回执语义。

可选名称随同一候选的配套服务交付，旧清单缺失名称时仍可显示。回退时整套使用上一候选，旧配置无需迁移。
