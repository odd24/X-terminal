# ADR-088 MCP 断开与原编号回执

P15 v4 保留 v3 的十四项工具及结果，增加 `sessions_disconnect` 和 `sessions_disconnect_status`。两项均绑定协议、完整连接代次及调用者固定的请求编号。发起沿 ADR-051 的 Agent Disconnect 权限、租约和 Single 完整参数检查，查询沿原票据所有者与回执保留规则。两个工具分别使用现有协议的 Disconnect 和 DisconnectStatus 请求。

原生桥只接受对应协议的 Disconnect 回执，同时核对服务回传的连接代次和编号。REQUESTED 表示已请求取消。TRANSPORT_ENDED 表示服务已观察到 SSH 传输资源释放或 UART worker 已 join。应答不明时只用原有效票据查询原编号。配对、批准和状态查询本身都不执行断开。

验证限于合成 SSH 和显式开启的计数内存 UART。分别观察 SSH 对端释放、UART 在途停留及 worker 完成，覆盖原编号恢复和权限隔离，验证后恢复普通构建。本包范围为两项断开工具。
