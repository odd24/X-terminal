# ADR-007 会话领域与本地 IPC v1

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（类型/领域与帧边界；原生安全由 P07.2 验证）
- 关联：P07.1/P07.2/P07.3、R11/R12/R13、CR-001

## 决定与候选

协议中立领域放在 session-core，序列化/帧放在 session-protocol。UI Rust 外壳和 MCP 桥后续使用同一协议访问独立服务；不在 renderer 引入设备 API。传输仍采用架构基线的 Windows Named Pipe；本步没有实现或声称通过 ACL。

IPC 选择 u32 小端长度 + UTF-8 JSON，每帧最多 512 KiB。相比换行分隔可在分配主体缓冲前拒绝恶意长度，不会混淆原始控制字符；相比二进制自定义编码便于排错、生成 schema 和后续版本演进，代价是字节数组的 JSON 膨胀。64 KiB 原始输出最坏 JSON 大小仍在帧限额内。部分头/主体是协议错误，正常 EOF 单独表示；不接受零长度帧。

Hello 首帧携带版本、客户端显示名称和 capability。身份/角色由服务端查票据决定，调用方不能填 role 自升权。字段拒绝未知项，连接 ID 用 UUID、代次精确匹配；不兼容版本拒绝。schema 从 Rust 类型生成到 contracts/ipc/v1.schema.json。

## 生命周期与输出

新连接 generation=0，仅作配置生命周期；begin_connect 增为 1，重连递增并清空旧输出。SSH 必须经过 AUTHENTICATING，串口/fixture 可跳过；活动连接不可直接删除。失败/断开不会重放输入，输入调度和 request_id 去重仍留 P14。

当前最多 64 个领域连接，每连接原始输出 256 KiB/128 事件，每事件最多 4096 字节，每次 append 最多 64 KiB；读取预算 4096–65536 字节。cursor 是下一事件序号，从 1 开始，独立消费者各自持有游标；覆盖旧事件时 available_from/truncated 显式返回，绝不拿旧代次游标读新流。事件保留原始字节和采样时间戳，解码/屏幕/审计不会混为同一数据结构。限额可在 P11 版本化为配置，尚非 P22 性能结论。

## 最小身份与票据

bootstrap 为 256 位随机 token，计划经父子进程匿名管道传给服务；不放 argv/env、不交给 renderer。服务只保存 SHA256 token 索引及内存权限，重启不恢复。桌面身份可以签发显式 connection_id/generation 的只读票据，最多 128 个、最长 30 分钟，过期/撤销逐请求校验；观察者不能签发或撤销。P14 才引入写入/exec/租约等生产策略。

敏感 token 的 Debug 固定脱敏，包装及帧主体用 zeroize 在释放时擦除；这是内存管理措施，不承诺抵御同账户恶意进程或消除所有临时副本。当前用户 ACL、拒绝远程、服务 PID 校验和真实 OS 负向测试必须由 P07.2 补齐；纯 Rust 身份测试不能替代它们。

## 试验接口与回退

IPC 中 fixture 操作只用于明确启用的合成服务测试，不打开 SSH/串口，不作为生产写命令入口。正式适配器必须经过后续统一调度器，未实现的协议不假成功。

P07.1 采用 serde/schemars/uuid 的已锁版本与现有 Tokio；无新增外部运行时。若 JSON 成本无法满足 P22，可在版本握手下另增编码，保持有界帧与明确游标语义。回退 P07.1 提交可移除领域/协议，不会回退设备动作或修改全局配置。

关联：Step-ID: P07.1 / Decision-ID: ADR-007；前置 867eb08。

## 2026-11-04 P07.2 原生证据补充

session-service 已实现当前用户受保护 DACL、远程拒绝、首实例、不可继承 Pipe 句柄；Rust 客户端在发送 token 前校验预期服务器 PID。用 Win32 实际查询 DACL，并以真实 restricted token 的 CreateFileW 验证 OS 拒绝；另有 6 项跨进程测试，见 [P07.2](../records/P07.2.md)。这些证据补齐原生实施，不覆盖其他真实账户/远程网络/Windows 10。

服务限制 32 个客户端，5 秒握手/发送、30 秒空闲截止；每次接收后先建新监听句柄，再分发已连接实例，保证没有无实例窗口。默认 fixture 禁用，测试必须显式参数启用；生产设备/输入调度仍待后续步骤。服务独立于 IPC 客户端生命周期，UI 客户端断开不会丢领域连接；完整桌面生命周期在 P07.3 验证。

客户端遇到超时/错误即关闭该 IPC 连接，避免迟到响应错配；不会自行重试动作。服务终止后状态与票据丢失，重启不会继承授权。当前用户 full-access DACL 本身不防同用户创建其他实例，PID 校验和高熵票据是额外边界；不宣称防同用户内存读取/进程篡改。

来源：[Microsoft Named Pipe 安全](https://learn.microsoft.com/en-us/windows/win32/ipc/named-pipe-security-and-access-rights)、[Tokio ServerOptions](https://docs.rs/tokio/1.54.1/tokio/net/windows/named_pipe/struct.ServerOptions.html)。本次直接核对所锁源码并通过实际 Windows 调用。

补充关联：Step-ID: P07.2；前置 f7846e5。

## 2026-11-04 P07.3 桌面持有策略

桌面 Rust 外壳持有私有 bootstrap、已验证 PID 的客户端和子服务；renderer 只可调用显式的 status/list/read 与测试 fixture 命令，不提供通用 root RPC/票据接口。服务 exe 从外壳相邻固定文件名启动，不从 PATH 或 renderer 路径取值；打包分发由 P25 完成。每个外壳使用随机 instance，不复用未知进程。

选择匿名非继承 Windows Job + KILL_ON_JOB_CLOSE，外壳进程结束即结束所属服务；普通关闭先请求 shutdown。相比只用 Child Drop，Job 覆盖外壳被强杀；相比系统服务不需要权限提升或安装。代价是当前不能在外壳退出后保持后台连接；P12 的后台模式必须保持原生外壳/托盘进程存活，而不是遗留失去配对密钥的孤儿。普通退出语义在界面明确显示。

服务获得 bootstrap 前先分配到 Job。启动极窄窗口如外壳提前死亡，子进程匿名 stdin EOF/5 秒截止自行终止。原生 IPC 每 10 秒心跳，页面暂停不会触发 30 秒空闲断开；客户端错误锁定失效，不自动重新启动或重放业务请求。

实际 WebView 脚本暂停 31 秒再重载，服务/连接身份和原始事件不变；正常退出、服务崩溃与外壳强杀均有真实 PID/界面验证，见 [P07.3](../records/P07.3.md)。这只证明合成会话，不证明传输接入/设备验收。

来源：[Microsoft Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)。补充关联：Step-ID: P07.3；前置 782bb6b。
