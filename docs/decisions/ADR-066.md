# ADR-066 当前连接常用命令库与显式准备

- 日期：2026-11-08（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P19；依据CR-006 S3与用户持续推进。

P19整体仍依赖P12/P14/P18。当前独立子包只对活动连接准备文本，复用P12基础撰写和P14输入安全，不使用广播集合；其前置P12/P14已具备。选定多目标发送待P18后接入，完整P19/R08/R09不因本包完成。先补真实缺项，不另建并行审批或重做主窗口。

用“更多工具→常用命令”共享弹窗管理命令，Ctrl+Shift+K仅打开，不发送。分组标签由命令的group字段汇总，最多16组/64条，名称和分组1–64 UTF-16单位且拒绝控制/bidi/首尾空白；同组同名拒绝。每条ID/名称/组/模板/末尾换行，模板最多8192 UTF-16单位，库序列化总预算256KiB。模板是用户明确保存的非秘密文本，随配置备份；变量值、解析结果、当前草稿、执行历史、身份/授权/发送同意不保存，不自动从终端或剪贴板采集。

占位符为{{name}}（ASCII字母或下划线开头，后续字母数字下划线，最长32字符），最多16个不同变量；填写后只做一次字面替换，不递归、不作shell转义或插值，${HOME}/反引号保持原样。空值不准备。界面说明模板随配置保存、变量值只在本窗口、不要将密码/令牌写入模板。所有发送仍经原Compose预览和输入队列，UART不当shell或独立exec。

准备前重读同命令/配置revision，冻结当前service_id/窗格epoch/精确连接/协议及草稿版本；await后再核对，切换/关闭/重载或来源变更不写草稿、不发送。已有草稿须独立明确勾选替换且版本仍匹配。准备后进入原撰写、末尾换行保持，用户另行预览/确认；快捷键、选中命令、保存/读取或准备本身都不发送。不以快速命令单击绕过多行/控制字符预览、接管/去重或未知结果不重试。

schema7新增quick_commands，沿原配置线程/全库revision/事务/升级前备份/完整读回和ConfigImage摘要/安全副本恢复；旧schema2–6只读空命令库，不改旧源。当前坏字段/缺表/超预算拒绝不默认。新库不能由旧程序读写，恢复内容不降版本。便携Profile JSON仍只连接配置，不含命令库；原生备份预览显示命令数并纳入恢复确认。命令类型Debug隐藏名称/组/模板，审计只RPC类型/配置版本，Agent拒绝命令库读写，不把保存模板当Agent授权。
