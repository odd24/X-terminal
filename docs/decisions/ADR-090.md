# ADR-090 MCP SSH2 重连与原编号只读回执

P15 v6 加入 `ssh_reconnect` 与 `ssh_reconnect_status`，保留 v5 十八项工具。沿 ADR-053 使用已结束旧代次上的独立 Reconnect 和租约，以及同票据固定 Profile/revision Connect。Start 继续使用既有 SSH Reconnect 请求与 Single 指纹。主机信任、保存凭据与交互认证仍由 Desktop 处理。

现有 Desktop StartStatus 按编号查询 Desktop 创建记录，无法为 Agent 查询原重连。新增 SSH ReconnectStatus，只在当前有效票据的原创建账本核对 owner、重连类型、旧代次及编号。查询不读配置、不推进代次、不派发或恢复权限。返回原创建快照，不代表当前在线。原编号应答不明只查询。

新增查询回执由服务回传旧代次、编号和创建快照。既有 Start 回复保持 Started；原生核对 wire ID 与下一代次、协议及创建状态，再附加请求中冻结的旧代次和编号。查询则另校验服务实际回传的旧代次与编号。异常回复按应答不明处理。
