# ADR-086 P15 SSH exec 与本人任务 stdio 闭环

- 日期：2026-11-10；状态：ACCEPTED；Step-ID: P15。

监督准入仅ssh_exec/tasks_get/tasks_cancel，目录由初版9扩为v2固定12项，保留初版历史契约；不扩连接/认证/串口控制/日志导出或模型自签授权。独立Agent代理、OS配对、原票据、Exec独立scope/lease、Single完整参数和TimedTask边界保持。任务属于同ticket/精确connection+generation；任务UUID相同不授别的owner读取。

ssh_exec要求调用者事先固定RFC9562 UUIDv7，使用服务同一ordered_timestamp条件（版本7及RFC4122 variant），派发前拒其他UUID。command最多16KiB UTF-8、timeout_ms 1..120000、max_output_bytes 1..1048576；不补换行或新shell状态。task_id必须等于原request_id，原生typed回复重验连接/任务编号，首答不明也已知应查编号。Start绝不自动重放；NotFound/REQUEST_EXPIRED/服务重启/流失效不证明未执行，不换grant继承原owner。流失效后仅能显式恢复原桥/同票据再查，票据失效则保持未知。

tasks_get固定connection/task_id，view严格status或output。output显式cursor/max_bytes（16..64KiB）/through_cursor可空；普通票据through_cursor只能空，映射本人ExecRead有界页。受保护票据空水位先映射ExecReadProtected Info取得固定水位，再用非空水位映射Text（必须合法cursor≤through），不调用未保护输出或回退raw。两种返回有明确typed区别，不拼接双流或混淆源游标。状态/取消/Start回执的exit_signal仍由既有服务策略保护，原生只投影明确TaskStatus/输出，不能带bearer/规则或未保护副本。

tasks_cancel仅原owner既有任务的停止请求；可能已执行或仍在取消，不能宣称远端回滚/退出。get/cancel不引入第二种授权或新任务列表，不另签模型授权，不以未知/超时为理由重发Start。

完整包先协议/模型及既有服务契约定向验证，再实际desktop:build与真实stdio+合成SSH：UUID/预算/未知字段/路径/身份拒绝；同owner一次执行、首答丢失按已知ID查、跨owner/代次/接管/撤销；保护双流与信号/取消/迟到及流失效；原9影响/固定12清单和安全矩阵。仅自建中文根，finally实际普通服务恢复与本机普通预览；不跑真实业务/COM/秘密或T18/T19长稳。盘点证据随本实质产物归档，P15完整/MCP模型自治/实机不因此收口。
