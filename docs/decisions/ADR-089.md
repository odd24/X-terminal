# ADR-089 MCP 编号移除与原回执

P15 v5 在 v4 的十六项工具上增加 `sessions_forget` 和 `sessions_forget_status`。两项接收协议、完整连接代次和调用者固定的原编号。桥只转发 ADR-054 的 ForgetStart 和 ForgetStatus。服务核对独立 Forget 范围、当前租约、精确代次、Single 完整参数与本地回收。Removed 表示已移除会话记录，配置、日志、导出及文件继续保留。

服务明确返回 InvalidState 时，清理完成且权限有效后可显式重试原编号。应答不明时只用原有效票据查询原编号。原生只接受对应协议的 Forget 回执并核对服务回传代次及编号。回执不匹配使桥请求失效并报告 UNKNOWN_DELIVERY，避免将投影异常当成服务明确拒绝。原票据可在范围和租约退休后查询原回执。

验证限合成 SSH 和内存 UART，分别观察实际回收与未完成拒绝，核对原回执、权限及保存数据，再恢复普通构建。
