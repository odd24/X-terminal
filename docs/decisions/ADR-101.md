# ADR-101 快捷指令描述的受保护存储

0.1.37 的桌面和桥严格解码现有快捷指令设置与回执。把描述直接写入设置条目会令旧桌面无法读取整组快捷指令。把描述和设置分开提交则可能让修订或回执指向未保存的文字。

**决定**　在已有 DPAPI 库增加一条按快捷指令 UUID 索引的描述记录。设置与描述在同一快照读取。保存按原集合修订核对，设置、描述以及适用的 MCP 回执在同一事务提交。v3 使用独立的描述查看和管理批准，v3 写入使用独立回执日志，各版本的请求编号仍互斥。v3 仅查询已有回执，旧授权与旧桥继续看到原投影。

**容量及回退**　描述使用独立记录，保留原设置记录的容量。最多 32 条描述，每条最多 500 个 Unicode 标量，描述记录能容纳全部条目的最大有效 UTF-8 文字。旧桌面照常读取设置并按原修订保存。新版按仍存在的 UUID 合并描述，丢弃已移除条目的描述。旧桥的创建和更新不会清除已有描述。回退到旧程序时保留库和描述记录，仍使用相同的数据锁和配置修订。
