# ADR-104 本地终端文件拖入与 PowerShell 行编辑

Windows WebView2 接收 OLE 文件事件。主窗口把窗口物理坐标换算为 WebView CSS 坐标，命中可见的本地终端正文后冻结行编辑目标。内部标签保留原有的指针拖放。窗格选择、布局、服务任务与 PowerShell 行编辑代次变化时撤销高亮和目标。

轻量命令行复用现有光标编辑，按 Windows 参数规则处理双引号和路径末尾的反斜杠。PowerShell 会话保留原有编辑器和用户配置。启动时对 PSReadLine 的行读取入口做进程内包装。行编辑期间用随机任务标识发布可用代次，拖入请求在原本地输入队列中等待编辑器回执。命名内存映射与命名管道限定当前用户。PSReadLine 在所属 PowerShell 运行空间验证原代次、时限与实际光标语法，确认候选行的路径仍是独立字面量后插入。撤销时关闭管道。拖入的路径不会经 ConPTY 键盘流传给前台应用。

有界请求仅在内存中存在。超时、失答、行编辑器不可用或光标位于引号、注释等无法形成独立参数的位置时，拒绝或终止原请求。应用不代按回车、不写剪贴板、不自动重试。回退使用上一候选或回退对应提交，无配置迁移。
