# ADR-014 SSH2 服务接入的传输契约

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（传输阶段；服务/桌面整合继续，最终依赖选择保留 ADR-002 的实机条件）
- 关联：P09、R01/R11/R13、CR-001

## 决定

保留 P03 Ssh2Probe 回归，新增 Ssh2Session 作为仅服务使用的正式原语，继续锁定 russh 0.65.0。直接使用原型会丢弃等待 PTY/exec 应答时早到的数据，且同步交互回调不能等待实际 GUI 决定。系统 ssh 子进程需要另建 PTY/凭据桥，不能自动共享当前会话；暂不替换已验证候选。真实 UNIX/独立 OpenSSH、算法/证书与发布依赖审计继续保留，不能把本阶段编译当成兼容验收。

每次实际握手的主机公钥先通过有界 Challenge 通道交给服务，由服务按 endpoint/connection_id/generation 和当前信任库决定。传输不读 known_hosts、不默认接受首次密钥、不在批准前发送凭据，也不接受主机证书绕过 CA 策略。接入时包括 rekey；服务必须在挑战中绑定连接代次，旧确认不能跨代使用。当前只实现传输等待机制，尚无用户主机确认界面。

密码/密钥/交互认证分别调用。交互挑战最多 8 轮、每轮 16 提示、文字合计 8 KiB，回答数必须匹配且总长至多 8 KiB。可区分拒绝、部分认证和成功；错误/中断认证关闭连接，避免下一轮消费错位回复。SecretText 使用 Zeroizing 和脱敏 Debug；russh 内部复制与 OS 转储不由本包装器承诺擦除。

私钥解析在 blocking worker，最多同时两项；OpenSSH bcrypt 至多 64 轮，PKCS8 PBKDF2 至多 100 万轮，scrypt 内存上界 64 MiB、N*r*p 至多 8388608，先检查再解密。超过限额明确失败，不静默降级认证。不支持 PuTTY PPK 导入（原文件格式不在现有导入范围）；PKCS/RSA/EC/OpenSSH 保留库支持。已超时的 blocking CPU 工作不能强杀，但持有并发 permit 直到结束，不能无界创建解密任务。

## 生命周期、输出与 exec

TCP socket 保留共享 OS 句柄；所有者 Drop、连接取消或握手失败关闭实际 socket，避免 russh 内部分离 task 在上层放弃后继续连接。默认连接/控制 15 秒、用户决定 120 秒、保活 30 秒/3 次，均可受限配置；不自动重连、不重放。生产协商仅 compression none，避免启用未独立核实的大块解压资源边界。

PTY/shell 等待成功时保留早到 stdout/stderr/退出事件，缓存最多 64 KiB/256 事件，单事件最多 64 KiB，超限明确失败。读写 half 分离，写入成功仅表示进入 SSH pipeline，不代表远程执行；错误可能发生在部分发送后。resize 检查 2–500 列、1–200 行。流控通知属于非输出控制事件，不导致丢掉后续数据。

exec 是同一 SSH transport 的独立 channel，不继承交互 shell 的 cwd/环境；默认 600 秒、输出合计 1 MiB，可受限配置，绝不自动重试。返回部分 stdout/stderr、可选退出码/信号、是否收到请求批准、截断和明确结束类别。超时、取消、断线、没有退出码不能伪造 code=0；收到非零 code 是明确远端结果。未收到批准不证明未执行，关闭 channel 不承诺远程动作撤销。任务持久化/请求去重/调度和 GUI 仍待后续 P09/P14/P15 接入。

## 证据与回退

隔离回环真实 SSH2 包测试覆盖批准前无认证、拒绝/超时/取消、实际 socket 关闭、早到输出、错误密码/加密密钥/异步交互、同 transport shell+exec/resize/保活，以及非零退出/信号/缺退出码/断线/部分超时/取消/输出限额。KDF 测试直接构造超成本头部，拒绝前不执行昂贵派生。具体结果见 P09 记录；没有设备或 GUI 接入证据。

回退新增传输模块不改变 SQLite/vault 格式，不改用户机器 SSH 配置，不涉及真实远端动作。保留原型，服务整合完成前不删除回归；若实机证据要求换库，另写 ADR，保留公开服务语义。
