# ADR-093 MCP 显式 SSH2 终端尺寸控制

v9 增加 `ssh_resize`，保留 v8 二十四项工具。调用固定精确连接代次、原编号、列数 2–500 与行数 1–200。原生只转发现有 ADR-048 SSH2 Resize，服务复用 Control、当前租约、Single 指纹及 FIFO。读、写和 exec 权限不能用于调整尺寸。Desktop 的视口逻辑保持原样。

原生核对 wire ID、SSH 输入回执类型及原编号，结果使用既有 SSH 输入回执形状。应答未知时仅以原参数中的连接和编号调用 `terminal_input_status`，协议为 SSH2。PIPELINE_QUEUED 表示管线接纳，合成对端实收单独核对。权限失效阻止尚未派发的尺寸操作。
