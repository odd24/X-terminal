# ADR-051 Disconnect原编号恢复与本地传输结束证据

- 日期：2026-11-06（Asia/Shanghai）；状态：ACCEPTED（核心与SSH服务分步实施，真实结果见P14；串口/GUI继续）。
- 关联：P14、R11/R13、T13/T14/T17、ADR-020/044/049/050。

## 选择

旧Close没有request_id；SSH立即改变领域状态，串口则异步取消并join。不能把Accepted或Disconnected当作本地socket/worker已完成回收。候选为直接放宽旧Close、由MCP保存去重、服务持有独立有界Disconnect回执。选择第三项，SSH/串口复用同一核心模型，各管理器持有账本，不公开owner，不增加依赖或数据库。

每项绑定认证ticket owner（Desktop为None）、request_id与完整ConnectionRef。新操作必须独立Disconnect范围及当前lease；服务在同一策略/生命周期锁内检查、预留回执、派发取消并退休能力。容量失败不能先关闭传输。保留同owner/同目标编号只查询，不需要已被关闭退休的范围/lease，不续租或再次关闭；票据本身仍须有效。跨owner和目标/代次冲突拒绝。查询未知编号不得执行关闭，不换编号自动重试。

Requested仅表示本地取消已派发；TransportEnded须实际观察精确代次Actor任务或OS worker回收完成后设置，不能仅凭领域Disconnected、取消标志、超时或移除记录。不表示远端动作撤销、驱动缓冲排空或对端处理退出。无法证明回收时保持Requested；服务接入须在移除记录前保存可证明的终态。

最多1024项，只淘汰已TransportEnded的UUIDv7记录；水位拒绝旧编号及同毫秒其他编号。Requested和不透明UUID不能淘汰，容量不足显式失败。候选编号落入拟退休桶时先拒绝且保持原记录。Forget/Reconnect不删除独立账本，重启不恢复回执或同意。

## 验证与回退

SSH服务增量使用严格Disconnect/DisconnectStatus（均必填完整connection/request_id）与Disconnect回执，不放宽旧Close。新请求在原inner→Store锁内取得并派发独立许可、预留原编号后取消FIFO/exec/challenge并退休；保留原Desktop领域状态语义。查询不披露未拥有编号或任意目标的生命周期，原同来源编号在Forget后仍可查，ticket撤销/过期仍拒绝。无异步窗口的关闭派发不跨await持锁。

SSH回收证明同时检查原Actor JoinHandle已结束和内部Weak<Ssh2Session>无强引用；exec JoinSet异步abort期间不能仅凭Actor结束报完成。Reconnect/Forget在旧Actor join（超时abort后也join）后另等传输引用释放，再记录旧代次回执完成并替换/移除；等待上限2秒，失败保留原记录，不虚报物理断开。内部Weak不进入RPC；SocketGuard最终释放执行本地shutdown，远端是否观察仍须合成对端独立验证。串口Disconnect需按OS worker实际join另接，不从SSH证据推导完成。

核心测试覆盖来源/精确代次、单调完成、重复只取原结果、pending/opaque容量、完成记录退休及同毫秒拒绝。服务须另以真实Windows IPC验证独立范围/lease、跨身份、关闭后原编号恢复、撤销/过期、队列和任务取消、实际SSH/内存串口结束，以及Forget/新代次不重派发。核心通过不代表服务/GUI/真实桥/COM完成，结果见[P14](../records/P14.md)。

回退新增revert关闭新Agent入口，保留旧Desktop Close与去重证据，不重放或恢复授权。GUI独立动作批准、时间范围/授权形式/脱敏/完整审计、P15–P25及整个方案继续。Step-ID: P14 / Decision-ID: ADR-051。
