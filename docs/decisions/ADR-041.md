# ADR-041 固定连接代次的基础撰写与共享输入队列

- 日期：2026-11-05（Asia/Shanghai）；状态：ACCEPTED（P12软件子步）。
- 关联：R09/R13/R15/R16、P12/P19、T10/T13/T22/T23、ADR-020/026/037/040。

## 选择

候选为在撰写面板直接调用传输、把草稿跟随Profile、复用主终端的文本接收与有界输入队列。选择第三项：草稿按connection_id/generation/protocol绑定，同Profile实例各自独立；当前活动连接与实际终端绑定一致后才启用预览，确认时再次在发送适配器核对完整目标。SSH2/串口均进入原receiveInput→submit→InputQueue/服务request_id回执，不能另开SSH shell或旁路连接。

基础撰写为单批文本，正文不作shell变量/命令模板展开，末尾显式选择不追加/CR/LF/CRLF；不自动添加回车，不解释ANSI/控制内容，不等同独立exec。HTML textarea使用平台文本编辑换行规则；预览显示JSON转义、CR/LF计数和固定目标，所显示UTF-8字节仅为本地预算，最终编码/拒绝由服务冻结编码裁决。每次预览均需明确确认，不自动采用剪贴板括号粘贴模式；后者继续原受控粘贴入口。

窗口内最多64份草稿，每份最多65536 UTF-16单元，确认payload按SSH2 196608/串口65536 UTF-8预算包含追加换行；不完整Unicode拒绝。达到草稿数量上限拒绝新增，不静默挤掉旧草稿。关闭面板保留草稿，明确清空全部可移除；重载清空正文和同意，不持久化或写审计正文。旧代次草稿不能被新代次读取/发送；可显式清空，不继承重连授权。

## 预览与输入语义

草稿编辑/换行选项、切换目标、代次/连接状态变化、键盘或粘贴接管、关闭面板均使预览失效；切走再回来不能恢复同意。预览对象及目标冻结，consume只有同一对象/完整scope/当前草稿一致时成功一次，双击不重复入队。输入适配器返回接受后清空该草稿并说明结果见主终端状态；队列拒绝/服务失败/应答未知不自动重发，已执行动作不能撤销。基于已有队列，切换会丢弃尚未发送项，在途动作仍绑定原目标；后续P14租约/接管不能由此推断完成。

首轮真实桌面探测发现标签更新先于终端绑定，旧保护会拒绝过早输入；现以完成保留输出读取后的实际绑定启用撰写，发送前仍双重核对。键盘接管使面板预览立即撤下。活动标签在尺寸变化后重新滚入可见区，所有标签隐藏时完整列表显示明确空选择，避免视图选择含混。显示层仍沿用共享Panel/Field/tokens。

## 验证、代价与回退

独立草稿状态测试验证多实例/代次/协议隔离、64份容量、原样控制字符/显式末尾、冻结/一次性/切走再回、字节预算和Unicode拒绝；真实WebView用双SSH合成连接核对精确echo/跨目标保持、键盘接管、真实write_text应答丢失命中且不重试、重开/重载，串口专项验证同一路径精确文本/LF/CRLF。最终实际结果见[P12](../records/P12.md)，不以库测试推断GUI/真实设备通过。

本子步不提供P19选区发送/快速命令/变量/历史/节奏等完整功能，不替代P14授权、P12受管理偏好/习惯选项/Alpha说明与完整UI矩阵。新增revert可撤下撰写入口、共享文本适配及测试，保留服务连接、配置、日志和用户文件；不重发草稿、撤销已执行输入或恢复旧同意。Step-ID: P12 / Decision-ID: ADR-041。
