# ADR-002 SSH2 后端试验选择

- 日期：2026-11-03（Asia/Shanghai）
- 状态：PROPOSED（本地协议原型已验证，生产决策待真实端点）
- 关联：P03、R01/R13；前置 P01/P02

## 候选与证据

| 候选 | 证据/能力 | 许可/代价 |
|---|---|---|
| russh 0.65.0 | 本机 MSVC 构建、真实 SSH2 回环集成测试；异步 Rust API、密码/密钥/交互认证 | Apache-2.0；ring/rsa/flate2 特性，避免 AWS-LC 构建要求 |
| libssh | 官方描述含密码/公钥/交互认证及更多兼容能力；未做本机原型 | LGPL-2.1；C 依赖/FFI 与分发义务待核查 |
| libssh2 + ssh2 0.9.6 | 官方描述支持密码/公钥/交互认证；未做本机原型 | libssh2 BSD-3-Clause、ssh2 MIT/Apache；阻塞 API 需要隔离工作线程 |

## 暂定方向

优先 russh，与 Tokio 服务方向一致，不引入另一个本地命令行 SSH 会话。P03 原型在 transport-ssh2 内独立验证，尚未接入桌面或统一服务。P07 之后仅由服务访问它。

所有连接要求外部显式提供 SHA256 主机密钥 pin；空 pin、变更 pin 拒绝，不能先认证再确认。主机证书暂拒绝，CA 策略尚未实现。首次用户确认与主机存储属于 P08/P09。

锁定 russh 0.65.0、Tokio 1.54.1、ring 0.17.14，传递版本见 Cargo.lock。依赖包含 ssh-key 0.7.0-rc.11、rsa 0.10.0-rc.18、pkcs1 0.8.0-rc.4 等预发布版本；它们是候选的实际成本，发布前必须评估稳定替代、漏洞与兼容性，不将构建成功当作安全审计。

## 已验证与未验证

[P03 矩阵](../evidence/P03-ssh2-matrix.md) 区分真实协议与合成服务器行为。回环协商到 mlkem768x25519-sha256、Ed25519、ChaCha20-Poly1305、strict-kex；其他算法仅有库能力信息，不能声称全套实测。SSH1 仍是独立 P04/P13，不存在 SSH2 失败自动降级。

每次协议操作设 5 秒截止；exec stdout+stderr 总计最多 1 MiB，单命令 64 KiB；shell 尺寸限定 2–500 列/1–200 行。协议窗口 256 KiB、包 32 KiB、channel 消息槽 32。超时/超限关闭 exec channel，不自动重试，不保证远端已执行动作撤销；失败后的真实远端结果仍可能未知。生产长任务与结构化错误在 P09/P15 设计，不能沿用此短原型限制直接宣称完整。

## 迁移与回退

真实 OpenSSH/Linux/UNIX、RSA/ECDSA/其他 KEX、不同主机算法、真实 PTY/保活失联和网络中断尚未通过；P03 保持 BLOCKED，不跨越 G0。可以继续 P04/P05/P06。若候选不能满足 R01，用 ADR 替换适配器，不删减要求。回退对应 P03 提交移除独立原型，不影响 P02 桌面。
