# ADR-056 单次操作确认与限时任务授权形式

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED（核心先行，服务/GUI待接入，实际结果见P14）。
- 关联：P14、R11/R13、T13/T14/T17、ADR-044/046/049–055；ARCHITECTURE“仅观察、单次确认、限时任务授权”。

## 选择

候选为只限制GUI批准按钮、首次派发计数一次、固定操作编号和规范参数指纹。前两种分别只能防双击、或会在异步分段/重连双许可/丢应答重试时误消费或允许同编号换参数；选择第三种作为单次变更确认。限时范围保留现有Scoped形式；另以TimedTask绑定任务UUID、非空有界说明、明确scopes和绝对到期。说明不是权限、任务ID不能跨票据接管，重试不续期，模式变化是不同签发。

SingleOperation绑定一个固定request_id和SHA-256参数指纹，批准时须展示完整可审查操作，批准不执行。指纹由服务对严格类型、规范序列化的完整SSH/串口变更请求计算，临时序列化字节用Zeroizing；不接调用者自报摘要代替正文核对。只允许已接入的变更请求，不接受任意RPC/路径/认证秘密或主机批准。单操作只授该操作需要的scope，Reconnect可包含独立旧代次Reconnect+固定Profile/revision Connect双许可；不顺带给Read，观察仍独立批准。Profile建连须固定revision/参数，串口仍固定库存/device_id/初始线，不将ID范围冒充固定配置。

服务收到真正操作时重算编号/参数指纹，在认证身份内附不可序列化的进程内绑定证明；配对核心在admit/实际dispatch检查同票据、同grant_id、同操作编号/指纹及独立scope/lease。异步首poll、队列、worker分片复用原Permit，不将每个片段计成新操作；释放重取lease不能复活旧Permit。认证票据本身不含此临时证明，不能拿一个原始Single票据直接绕过参数核对。客户端重发相同操作仍由既有owner/精确代次/FIFO或Start/Disconnect/Forget有界回执只查/去重；退休水位/opaque不淘汰及服务重启清授权继续阻止回执淘汰后重放。不声称核心单独执行了传输去重。

证明在Identity中以只读Arc携带，Permit只保存绑定已验证标记，保持轻量Copy；实际dispatch核对标记、操作编号和同一不可变grant_id所绑定的指纹，不每片段复制/重新序列化正文。授权不能原地更换形式/参数；新授权有新grant_id，旧证明/Permit均失效。未绑定的原始认证身份不能admit Single操作，证明不进入协议或可自填角色字段。

TimedTask允许明确任务范围内的多个操作，仍每项独立scope和lease，不自动恢复/延长/迁移权限。任务编号与ticket共同标识授权任务，任务说明仅在内存管理视图展示，不作为命令或授权来源，不写终端正文/审计正文。任务取消复用准确原签发撤销及原任务取消语义，不能承诺撤回已执行动作。

## 接入顺序与验收

1. 核心Form/操作指纹/不可序列化身份证明及Permit复核，保留Scoped行为；核心通过不能作为服务/GUI已开放。
2. 管理服务增加独立限时任务及固定单操作签发，幂等回执必须绑定形式/任务/指纹，不跨形式恢复。固定操作来源/完整参数预览与Profile版本复核，真正SSH/串口请求统一重新绑定，查询回执不要求再次执行。原生投影持续剥离token，正文/同意不持久化。
3. GUI复用共享Panel/Field/tokens和现有Profile/输入预览，完整操作/期限/范围、默认无同意、编辑/切换/重载失效；真实Windows IPC、合成SSH/内存worker验证改参数/换编号/跨来源/接管/释放重取/到期/撤销及丢应答恢复。单次支持现有Connect/写入/exec/控制/Disconnect/Reconnect/Forget，不以单一写命令子步宣称完整形式交付。真实stdio桥独立继续。

无新依赖/数据库或全局配置。指纹/任务说明不当持久完整审计，服务脱敏/全部拒绝RPC与持久审计仍待独立实现。回退新增revert撤下新形式入口，不扩大既有票据或重放操作。父P14、R01–R16/P01–P25与实机/全局UI验收保持开放。Step-ID: P14 / Decision-ID: ADR-056。
