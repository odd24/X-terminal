# ADR-023 串口设备身份与专用接口打开

- 日期：2026-11-04（Asia/Shanghai）
- 状态：ACCEPTED（软件选择；驱动/设备验收待补）
- 关联：P05/P10、R03、T04/T05、ADR-006、CR-001

## 决定与替代

P05 按 COM 名称打开，单纯在打开前比较 USB VID/PID/序列号或再次枚举 COM 名称仍可能在检查后打开一个被重用的别名；无序列号/多接口设备也不能只用 VID/PID 识别。采用 Windows GUID_DEVINTERFACE_COMPORT 的 SetupAPI 只读枚举，保存端口名、设备实例 ID 和专用接口路径的完整选择。路径由 OS 提供，字段私有、不从 RPC/配置任意构造；设备 Debug 隐去实例/路径。

实际打开前重新枚举并核对完整选择；移除、COM 改号、实例改变或接口改变均拒绝，要求重新选择。打开使用所选接口路径，绝不再次把 COM 别名解析成目标；设备在检查后消失则由驱动打开失败，不回退别名。一个实例可有不同接口的多个端口，必须按完整接口区分；同名别名或重复接口的歧义项不能选择。

枚举最多 256 个接口和 256 个兼容名称，实例 UTF-16 上限 1024 单元，接口详情缓冲 8192 字节、端口名 256 单元。原生结构按 ABI 设置 cbSize/对齐，返回长度限制读取，UTF-16/NUL/控制字符无效则拒绝。设备信息集合和注册表键用 RAII 关闭。单个接口元数据失败计数显式返回；兼容枚举中没有唯一接口的名称列入 unidentified_ports，不隐藏也不静默按 COM 打开。整表或数量超限明确失败。

继续使用已锁定 serialport 4.10.1：本地源码核对其 Windows builder 对反斜杠开头路径直接调用 CreateFile，不追加 COM 前缀，独占句柄；串口参数与 DTR/RTS 显式设置沿用 P05。没有修改上游或新增不必要设备打开。Windows-sys 0.61.2 复用已有锁定版本，增加直接依赖边和所需 SetupAPI/Registry/Ioctl 特性。

## 边界、证据与回退

设备实例/接口身份是 OS 身份，不是物理硬件证明；没有唯一序列号的相同型号设备在相同物理位置替换时，OS 可能无法区分。不得承诺识别硬件克隆。没有接口注册的旧驱动仍需后续明确兼容路径/设备证据，不能把本决定当作删除 SERIAL 或全驱动支持声明。原 P05 按 COM 的低层入口保留为原型，正式服务必须用 open_selected；不向 UI/Codex 暴露任意路径。

实际结果见 [P10](../records/P10.md)。逻辑测试证明验证失败不调用 opener、验证成功传入专用接口而非 COM 别名、歧义/界限/元数据失败显式，以及 Debug 脱敏；内存 opener 不冒充真实 COM 打开。原生只读扫描只记录数量，不提交设备实例 ID、序列号、接口路径或真实设备日志。工作线程、统一服务/队列、GUI 和驱动实际收发仍待接入/验收，P05/P10 不据此标完整 DONE。

回退新增 revert；无配置/vault 格式变更、全局设置、驱动安装或系统服务。打开期间的 DTR/RTS 瞬态仍是 ADR-006 的设备验证项，不能由接口身份解决。
