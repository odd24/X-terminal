# ADR-055 Agent读取时间窗与独立范围重建

- 日期：2026-11-07（Asia/Shanghai）；状态：ACCEPTED（实施中，真实结果见P14）。
- 关联：P14、R11/R13、T12–T14/T17、ADR-044/047、CODEX_INTEGRATION输入与上下文规则。

## 选择与边界

候选为仅GUI过滤、过滤已有派生文本/屏幕、服务独立时间窗范围并从原始事件重建。前两项会被其他调用绕过，且增量解码器/屏幕可能携带窗外前缀或正文；选择第三项。新增只允许Read的OutputWindow目标，绑定完整ConnectionRef及Unix毫秒半开区间[from_ms,until_ms)。旧Connection Read仍表示用户明确批准的该代次有界缓冲区及授权有效期内后续输出，不把旧范围冒充时间窗。授权到期仍服务单调时间，与输出Unix时间不同；显示/输入采用Asia/Shanghai并明确UTC+08。

新增Context请求分别提供Info/Raw/Text/Screen，时间窗票据不能调用旧Read/ReadText/Screen绕过边界。请求窗口必须包含于本票据一项获准窗口，或已有明确完整Read；不拼接不同票据/窗口扩大单项批准。List仅显示有观察范围的精确代次，时间窗不授lease/Write等能力。接管保留Read，退休精确代次撤下窗口，原签发编号恢复不续期/复活。新Grant仍先查原编号、配置await后同锁核对完整代次。

Info只返回当前保留起点、原始exclusive source_cursor及重建参数，无窗外正文。Raw/Text/Screen请求必填through_cursor（固定原始exclusive水位），分页使用原始事件seq，不用重建后重新编号；未来水位/游标拒绝，保留覆盖显式source_truncated。每次查询只遍历既有有界原始缓冲，不创建无界持久快照。分页固定水位，后续新输出不会改变已完成解码；若旧字节被覆盖，报告缺口，不假装可恢复。

先过滤原始事件，再以该代次固定编码和当前视口尺寸从空状态重建。UTF-8/旧编码首尾缺片明确替换/错误，不借用窗外解码前缀或ANSI状态。遇被排除的源事件/原始缺口断开上下文，保留所选文本事件，屏幕只表示最后连续获准片段的重建；窗外时间回拨也不能重新拼接。回执明确TIME_WINDOW_REPLAY、window、through水位、上下文重置和源结束状态；重建completed仅表示固定水位快照完成，不代表连接结束或真实当前终端完整屏幕。旧完整读取不变，范围屏幕不宣称历史resize轨迹或真实当前屏幕。

## 代价、验证与回退

不新增依赖/数据库/全局配置。代价为每次重放最多当前256KiB/128个原始事件（沿用既有限额），返回页沿用64KiB上限与独立原始游标；源已覆盖时不能重建更早完整上下文。范围内文本/屏幕仍可能包含用户选择范围内的敏感内容，后续服务脱敏策略独立实施，不把时间过滤当脱敏。

验证覆盖前/中/后事件、边界时间、窗外分片/ANSI不泄露、编码尾片、原始缺口/时间回拨断开、固定水位分页与覆盖/未来游标、跨连接/代次/到期/撤销/接管/退休、不能旧端点绕过、原编号恢复；服务真实Windows IPC及GUI固定范围/默认无同意/丢应答和重载逐层验证，准确结果见[P14](../records/P14.md)。不由合成通过推导真实stdio桥/COM或全局矩阵。

回退新增revert关闭Context与窗口批准入口，保留旧明确完整Read及现有回执；不扩大旧票据、不恢复同意或重放输入。父P14及完整R01–R16/P01–P25继续。Step-ID: P14 / Decision-ID: ADR-055。
