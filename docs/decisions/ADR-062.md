# ADR-062 窗口内标签分组先行，工作区持久化独立接续

- 日期：2026-11-08（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P17；依据CR-006 S3顺序及用户持续推进。

S1/S2软件已完成，真实COM因无设备待办；S3先复用现成导航、单终端、配置和基础撰写，补最小独立“标签分组”。不重写已有连接/调度/日志，不借此全局改版或同时做广播/触发器。完整P17的分屏、布局持久化/恢复仍接续，不能把本子包当P17或R06全部通过。

候选：①立即把单终端重构为多渲染器并新建持久工作区schema；②先实现本窗口内仅整理标签的分组，再独立规划受管理布局持久化；③借localStorage偷存工作区/连接正文。选择②，③违反受管理配置与不恢复正文/秘密要求，①扩大单包风险和界面范围。分组无网络请求、不改变配置和授权；没有新增依赖/schema。

TabGroups仅保留当前service_id、权威连接ID/代次/协议与最多16组/64字符名称。组内标签继承现有排序，未分组在前；同Profile/地址多实例分别归属。重连保留原逻辑标签分组，但一次拖动只认原服务/当时精确代次/协议，旧拖动不得移动新代次；移除记录回收归属，换服务清空全部。窗口重载也清空，不冒称可跨重启恢复。

默认无分组时复用原标签外观与键盘行为，SSH标签仍只显示地址。管理放“更多工具→标签分组”共享弹窗，可命名/重命名、调整组顺序、指定归属或解散组；解散只回到未分组。组标题是HTML5标签拖放目标，所有标签保持可见；左右移动仅组内，避免无意跨组。键盘箭头按实际可见顺序选择目标，不发送。隐藏的已结束标签可从管理窗口显示，但不重新建连；关闭标签继续无确认且绑定原代次，程序退出确认保持。

名称作为纯文本渲染，拒绝C0/C1、DEL和方向嵌入/隔离字符，不创建私有配色/字体；组标记使用现有tokens。分组不是广播集合、Agent授权或自动连接来源。后续持久工作区需明确保存内容、配置迁移/版本/失败安全、跨服务身份与显式恢复，不从当前内存分组推导自动建连/认证/发送。

验证按影响使用纯状态边界测试、实际desktop:build和WebView分组专项及受影响原导航；HTML5 DataTransfer测试与真实鼠标/DPI矩阵分别记载。无串口产品变化不再跑串口整套。回退新增revert与台账，不改历史或删除用户数据。
