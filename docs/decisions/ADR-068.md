# ADR-068 基础撰写选区预览与草稿保留

- 日期：2026-11-08（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P19。

按CR-006 S3/R09补齐当前单目标基础撰写选中发送，不新增全局编辑器、持久历史、广播集或服务协议。复用原ComposePanel/共享Field、目标/一次预览/原输入队列，在原正文明确选区后点“预览选区发送”，另确认；没有选区不默认发送整篇，全文原入口保留。变量/控制字符均字面保持，显式末尾换行只追加到所选片段，不把邻接未选正文一起发送。

ComposeProposal冻结精确target、完整源文本、草稿revision、UTF-16半开range和实际payload，禁止空/反向/越界/非整数范围及切断Unicode代理对。预算针对发送选区加末尾换行；完整草稿仍65536单元且窗口64份。编辑、改选区/末尾、切目标或关闭撤同意，consume仅一次。原输入队列拒绝不改草稿；队列接受后同步只移除已确认选区，其余原样保留，若调用期间revision/源变化则不覆盖新编辑。移除不等于远端执行，后续未知不自动回填/重放；取消预览不改变源。

不直接发送DOM选中内容或跳过原预览，不从终端/剪贴板/常用命令继承同意。沿原服务FIFO、精确代次、请求去重和未知停止；不更改schema7/Agent或多目标授权。模型验证Unicode边界/选区预算/源revision/单次/保留草稿/拒绝和晚finish；真实WebView合成SSH+内存UART验证转义预览、精确选区/CRLF/CR、取消不发、改选区和切标签撤同意、原fetch丢应答不重放，finally实际恢复普通服务。产品先实际构建，原全文撰写/常用命令按影响复验。完整历史/节奏/选定连接执行及实机/R09仍另列。
