# ADR-077 独立键盘区的有界连续同步

- 日期：2026-11-09（Asia/Shanghai）；状态：ACCEPTED；Step-ID: P18。

R07/T09与P14/P17软件前置已满足，ADR-067显式文本批次继续复用。候选重定向活动终端全部输入会混入认证、粘贴与焦点切换；服务新增长期广播任务需要独立恢复/权限协议。选独立共享弹窗中的专用键盘区，只从该区的xterm onData取得键盘文本/控制序列，不订阅普通终端、认证表单、输出或剪贴板。启用本身不发送，不做本地假回显；屏幕光标不是远端回执。不改服务协议、数据库schema7或Agent授权入口。

默认无目标/同意/键盘区，选2–8个SSH2/SERIAL的完整代次后读取真实host/UART port、编码、CONNECTED和无认证挑战状态，再只读检查原管理通道的Agent输入租约。占用或核对失败拒启用，需先明确停止/人工接管再重预览。预览和每次派发均复查原owner/代次/协议/地址/编码/租约；这是非原子预检，不能保证读与写间没有新租约。单独未默认勾选的确认明确同意固定范围的持续人工输入及原Desktop接管，最终仍由原服务在派发处撤下相应Agent写/控制与未开始动作，不新增旁路或隐式权限。

窗口只一个ContinuousInput协调器，复用原InputQueue 16项（含在途）和未发尾合并规则：同类可打印/相同退格、每段最多4096 UTF-8字节，控制序列为屏障；满或非法Unicode立即停整模式并丢弃未发尾，不静默丢字后继续。每段复用BroadcastRun固定顺序推进原服务输入FIFO，每目标独立request_id/回执。上一段全部结束后才开始下一段；任一目标预检失败、已知拒绝或UNKNOWN都停止全部未开始目标与队列尾，不像一次文本批次的已知拒绝继续。已经接受的其他目标前缀如实保留，没有跨目标事务/撤回。切标签/新增连接不扩大集合，不替换同地址或新代次。

仅专用区保持焦点时可键入；停止按钮、Esc（不群发该键）、离开输入区/窗口失焦/隐藏、关闭、服务/所选代次失效、重载均停未开始尾部，在途原编号可继续取得回执。Ctrl+V/Shift+Insert/粘贴事件先拦截并停模式，正文需另走原多目标文本预览，不直接群发剪贴板；拖放同样停止。重新输入须重新选择/预览/确认，无自动恢复旧许可。Enter CR、退格/方向/Ctrl等按xterm序列，由每连接原编码处理；远端密码提示无法自动识别，界面明确不能用于密码。实际支持以合成逐字节证据限定，不承诺全部终端键/操作系统IME组合兼容。

仅窗口内保留最多8个固定目标、逐目标累计可信接受段数/字节和末段回执，队列正文仅有界内存且停止丢弃，不写历史/日志/存储。ACK含义仍SSH管线/UART驱动，不等远端执行。未知仅查询原编号，确认接受后计数只补一次，绝不恢复队列；旧查询不能污染新启用。重载清结果，不据此重发。回退移除独立入口和模型，不迁移用户数据。

验证模型冻结/边界/合并与控制屏障、预检与在途停止、拒绝/未知失败封闭、原查询一次计数/旧查询隔离、owner变化；实际desktop:build后新第42入口仅中文自建根/合成SSH/内存UART，真实MCP测试租约阻止启用、Chromium组合输入未提交不发/提交精确、键序列与字节、焦点/粘贴/关闭/迟到/目标退休/GBK拒绝。普通批次、命令准备、输入性能/双窗格及逐行节奏按影响回归，feature finally实际恢复普通服务。真实COM/现场SSH/Windows IME/全局DPI/长稳/SSH1和完整P18/R07仍独立留验。
