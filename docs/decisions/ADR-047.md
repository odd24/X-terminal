# ADR-047 桌面授权管理的无令牌投影与固定编号交互

- 日期：2026-11-06（Asia/Shanghai）；状态：ACCEPTED（P14分阶段接入，实际结果见P14）。
- 关联：P14、R11/R13/R15/R16、T13/T14/T17/T22/T23、ADR-044/046。

## 选择与边界

候选为将公共Agent协议完整交给WebView、把token显示/复制到聊天或配置、由原生提供独立管理投影。选择第三项。新增agent_management_request仅接签发/原编号查询/摘要清单/原编号撤销、租约查询、人工接管及有界审计；没有Acquire/Release、调用者身份/角色/token或路径字段。沿用服务真实Desktop身份和原配置通道，配置查询不占终端输入Pipe；不增加客户端或依赖。

原生回复使用独立类型，Grant/GrantStatus/GrantRevoke仅将receipt投影给WebView，协议token立即随临时回复释放，不缓存、不进入JS/剪贴板/磁盘/argv/env/全局配置。服务保留ADR-046的内存回执恢复能力。此管理入口使用户能批准和撤销，但不是Agent连接交付：P15还须实现受控原生交付给真实stdio桥，绝不能将Desktop bootstrap交给桥或把token拷到命令行。本子步不以隐藏token宣称真实Codex已经接入。

## 界面与恢复约定

后续GUI复用Panel/Field/tokens，明确完整ConnectionRef、独立动作与期限，默认不勾选；预览冻结目标/范围/期限，批准只消费一次，切换/编辑/关闭使确认失效。当前可用传输动作与尚未开放动作明确区分，不以签发成功推导已实现Connect/Disconnect/SSH Resize或广播。

签发前保留service_id/request_id，最多一个窗口恢复槽，仅持久化这两个编号；不保存范围、期限、正文、同意、token或路径。未知应答与重载后只显式查询原编号，不自动签发/换ID/重试；查询NotFound/RequestExpired不说明原授权从未发生。签发时可由服务按原编号去重，但GUI恢复不把它当自动重试授权的许可。关闭迟到应答不重新打开面板或恢复批准。

管理清单只代表本服务最多128项保留回执；ACTIVE是ticket有效，当前能力必须以effective_scopes显示。Read表示当前代次服务保留的原始/派生文本/屏幕读取范围，不包含持久日志/导出、其他连接或认证秘密。人工接管撤下固定连接全部非Read自动化范围/租约；撤销按原签发编号，不能撤回已派发动作。租约只查看、不能由Desktop冒充Agent抢占。

期限expires_at_ms是服务单调相对时间，界面不可误作Unix日期或以本地时间伪造精确倒计时；显式刷新获取当前状态。审计只有512条元数据环，分页最多128，gap必须可见，不显示为完整持久审计或无限历史。

## 验证、代价与回退

原生单元验证拒绝身份/秘密/路径/租约写操作、参数上限与token剥离，实际WebView→Tauri→NamedPipe验证原编号恢复/未知应答命中、接管后有效范围、幂等撤销/过期/重启。GUI随后独立实测明确批准、冻结/迟到/重载及共享布局；通道通过不能冒充用户入口。结果见[P14](../records/P14.md)。完整审计/Agent交付/其他动作和P13/P15–P25持续。

代价为维护独立无秘密投影与管理交互；无数据库迁移或依赖变更。回退以新增revert撤入口/调用者，不恢复旧同意或已撤能力、不重放动作，服务退出清空内存授权。Step-ID: P14 / Decision-ID: ADR-047。
