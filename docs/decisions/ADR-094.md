# ADR-094 有界终端字面等待

v10 增加 `terminal_wait`，保留 v9 二十五项工具。等待仅对精确代次的完整 Read 范围开放。时间窗专用票据明确拒绝。原生沿现有 Context 或 ProtectedContext 返回相应的文本投影，每次短读取都由服务核对当前权限。受保护等待只匹配已保护文本。

stdio 每次读取只占用一轮既有管道。等待使用独立单槽，轮询休眠时释放管道。取消或总时限结束即停止等待，已发出的一帧有界收完且不向调用者返回。管道损坏时不重试，不另建连接。普通工具仍沿原入口。

同一固定水位、投影及连续源序号才允许跨页匹配。水位变化从原 cursor 重读，避免拼接不同保护投影。覆盖、源缺口、解码错误和投影变化不作干净超时。查询最长 30 秒，字面最多 256 UTF-8 字节，每次 128 页及 2 MiB 文本，证据仅匹配文本和源序号。
