# 验证与验收计划

当前所有产品用例均为计划，未执行；文档检查不能替代功能测试。执行结果进入对应 docs/records/Pxx.md 或其引用的脱敏证据。

## 测试层次

- 单元：状态机、权限、输入队列、request_id 去重、编码边界、缓冲游标、触发冷却、配置迁移。
- 契约：IPC/MCP JSON Schema、版本不兼容、缺失/超限参数、错误类别、取消/超时。
- 集成：本地测试 SSH 服务器、隔离 SSH1、虚拟串口对、临时数据库和日志。
- 实机：用户授权的服务器/UNIX/串口设备、真实 Codex CLI 与桌面。
- 桌面：标签与焦点、复制/粘贴、多行输入、分屏、分辨率/DPI、中文输入法与键盘。
- 发布：干净 Windows 安装、WebView2 前提、升级/卸载、数据迁移、长期运行。

## 证据格式

每次记录：测试 ID、执行者、时间与时区、构建 commit、命令/操作、服务器/驱动/客户端版本、机器配置、输入、预期、实际、PASS/FAIL/BLOCKED、脱敏日志或产物路径。生成的私有日志放入被忽略目录，只提交脱敏摘要/必要样本及校验值。

性能报告记录采样方式、队列深度、吞吐、P95、内存曲线、丢失计数；不以总体平均值代替尾延迟。测试阈值修改须 CR，保留修改前失败数据。

## 阶段门与缺陷

[CR-001](changes/CR-001.md) 将用户设备验收安排在后续，软件/协议/模拟结果必须单独标记。P03/P04/P05 未执行的真实端点、完整 SSH1/控制线项目仍开放，随 P09/P10/P13/P16/P23 补充；不降低 T01–T21 条件。P07 等独立软件可先验证状态机/ACL/IPC，不能因此将 G0 或实际协议/设备行填 PASS。

- G0：后端候选已验证，风险与许可记录，实际设备缺口单列。
- G1：基础 SSH2/串口可工作，日志与配置可恢复；Alpha 限制明示。
- G2：SSH1 与 Codex 实际闭环通过，权限负向测试通过。
- G3：效率工具全部有验收结果，Xshell 导入支持范围明确。
- G4：需求矩阵全部有证据，安装/恢复与长稳通过；无 S0/S1。

严重度：S0 凭据泄露、越权执行、不可恢复数据损坏；S1 连接/数据丢失或主流程不可用；S2 局部功能缺陷有替代方案；S3 外观/文案。S0/S1 阻断完整发布；S2 必须有范围说明和处理决定。记录缺陷 ID、复现、对应 commit、修复 commit、回归结果。

P09 exec 桌面补证覆盖独立输出/非零码/信号/缺码/超时/取消/滚动缺口与总限额、任务 ID 查询不重跑、页面重载后查询及取消。实际 Windows 服务回归额外验证捕获上限后 shell 仍可结束；合成服务器按窗口发送、关闭即停止。所有仍属隔离软件证据，未执行实机/长期压力，不将 T01/T02 或阶段门据此标完整通过。

P09 重协商补证通过低阈值真实 SSH2 包，在并发 shell/resize/exec 下核对 512 KiB 原始字节及多次主机信任回调；拒绝重协商无伪造退出码。跨进程服务在信任记录被删除或并发改变后重新展示 Unknown/Changed，确认期间新输入拒绝且 Ping 可用，批准恢复、拒绝失败。原未修改依赖上两项 transport 用例真实 FAIL，补丁见 [ADR-019](decisions/ADR-019.md)。这是信任库变化后的重评估，没有冒充服务器实际换钥或真实 OpenSSH 兼容验收。

输入回执退休窗口见 [ADR-020](decisions/ADR-020.md)：一万次核心请求仍有界，跨进程 SSH2 的 2200 次写入/1099 次 resize 和旧 ID 转动作拒绝，补 T14 的长期容量软件证据。原生 WebView 另跨过 1024 条回执后验证真实键盘可用。具体结果见 P09；不能据此填写 T18/T19 的 8 小时/30 分钟压力通过。

exec 结果窗口见 [ADR-021](decisions/ADR-021.md)：服务回归跨五条连接验证局部/全局结果回收、旧请求/任务查询和换动作均拒绝重跑，运行任务/opaque 结果/取消尚未出队记录保留。原生 WebView 连续任务跨 16 项服务与 64 项页面上限，并查过期任务不增加远端执行数；实际结果详见 P09。结果退休不等于任务成功，不能伪造退出码或用快速循环代替长期压力。

连接历史窗口见 [ADR-022](decisions/ADR-022.md)：契约/Windows 服务验证仅 Desktop 可移除结束连接、64 名额释放、1100 条建连请求跨 1024 回执容量、保留中的活动/opaque 回执、旧 Start/Reconnect 与未知旧桶不重放、清理/重连并发和跨连接重复 ID 冲突。原生桌面清空记录、空终端与重新手动建连作为 GUI 验证；结果记录 P09，不代替 T18/T19 或真实设备。
