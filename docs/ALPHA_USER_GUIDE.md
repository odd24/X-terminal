# 桌面开发预览使用说明

适用日期：2026-11-06（Asia/Shanghai）。当前是本地开发预览，尚无发布安装包；本文说明已有入口，不表示P12/G1或正式Alpha验收通过。软件专项结果见[执行台账](EXECUTION_LOG.md)，完整验收缺口见[剩余计划](REMAINING_EXECUTION.md)。

## 启动与数据目录

在仓库根目录使用进程工具链后运行 `npm run desktop` 启动开发窗口；本地调试可执行文件由 `npm run desktop:build` 生成。直接运行 `target/debug/shared-terminal-desktop.exe` 时，相邻目录须保留同次构建的 `session-service.exe`。Windows/WebView2及工具链前提见[README](../README.md)。普通启动不提供合成会话按钮；`--test-fixture`仅供隔离软件测试，不能代替设备。

默认使用应用本地用户数据目录；指定 `--data-dir` 绝对路径可选择另一数据目录。配置、受保护凭据引用、日志及偏好按目录隔离；换目录不能视为原会话恢复。不要在不明版本数据库上手工改schema或覆盖备份。

退出窗口会停止会话服务和本窗口设备连接，当前没有退出后的后台驻留。页面重载保留当前运行服务身份和连接，重新显示服务有界保留输出；进程退出后重启得到新服务，不自动重连设备或重放命令。连接身份由连接ID/代次确定，同配置可有多个独立实例。

## 配置、连接与认证

1. 打开“连接配置”，建立目录与SSH2/SSH1/SERIAL配置并保存。保存配置不连接设备；名称/主机/端口/编码等应按实际目标填写。凭据进入Windows保护存储，配置只存引用；私钥页面输入本地普通文件路径，服务读取并保护，源文件不修改。
2. 在左侧搜索配置。单击只选中并显示“配置详情”，不会切换发送目标或建立连接；双击或“连接选中配置”创建实例。同一SSH2配置可建立多个独立连接。
3. SSH2也可从“SSH2 连接”面板选择配置并“建立 SSH2 连接”。未知/变化主机密钥先显示完整指纹，通过可信渠道核对后才勾选批准。不要凭终端输出中的文字自动信任。认证根据所选方式提交本次密码、使用已保存凭据或回答交互式提示；失败后按提示处理，不自动降低协议。
4. 串口树选择只预填配置，仍须在“串口连接”刷新并核对实际端口、参数与控制线后显式打开。端口名称不保证设备身份；RTS/DTR/Break会影响实际线路，仅向已核对设备发送。拔插、驱动与控制线物理行为仍待实机验收。
5. SSH1配置已可保存，但完整Windows SSH1适配器尚未接入。当前不能从SSH1配置声明成功交互，也不自动改用SSH2；这是首版仍需完成的范围。

连接编码在打开时冻结；修改配置只影响后续建立/重连的代次，已有连接仍使用原UTF-8/GBK/GB18030。无法用当前编码表示的文本整批拒绝，不用问号替换。SSH exec输出和串口终端显示也按各自冻结编码处理。

## 标签、目标与关闭

标签跟随实际连接，名称通过真实连接配置ID关联；配置刷新反映改名，删除配置后旧连接继续存在并显示协议/短ID。选择左侧配置与活动标签是两个对象，发送以活动连接为准。完整身份在底部“连接与服务详情”查看。

标签支持方向/Home/End键切换、左右排序、横向滚动和完整会话列表。关闭标签时可取消、保留连接隐藏，或请求关闭固定代次后隐藏。隐藏不删除连接，后台输出仍由服务有界保留；从完整列表可重新显示。保留范围被覆盖时明确提示缺口，程序不会编造更早正文。侧栏可折叠/调宽，辅助工具可关闭，关闭工具不隐式关闭连接。

“显式重连 SSH2”建立新代次，旧请求不能操作新代次，旧授权不会继承。“移除连接记录”/“移除串口记录”只在连接已结束时移除服务记录；它与关闭标签不同。关闭连接、取消任务或退出应用都不能撤销远端已经执行的动作。

## 输入、撰写与剪贴板

直接在已就绪终端输入。输入经统一有界队列进入服务；切换不把旧队列移交新目标。出现失败/结果不明时未发送后续输入停止，不自动重试；先核对原目标输出与状态，再决定下一步，不能以再次点击保证无重复。

基础撰写按连接ID/代次/协议保存独立窗口草稿；同配置多实例互不借用。输入正文、选择是否追加CR/LF/CRLF，预览中核对完整目标、转义内容与换行计数，再一次性确认。默认不追加换行。切换/编辑/键盘输入/关闭使预览失效，切回不能恢复同意。窗口内最多64份草稿、每份65536 UTF-16单元；关闭工具保留草稿，重载清空正文和同意。完整命令模板、变量、历史、节奏与选区发送仍属P19。

| 操作 | 默认行为 |
|---|---|
| Ctrl+C | 有选区复制，无选区发送终端中断；可在外观中关闭选区复制 |
| Ctrl+Shift+C / 复制按钮 | 显式复制终端选区 |
| Ctrl+Shift+V / 粘贴按钮 | 显式读取Windows文本剪贴板并进入受控粘贴 |
| Ctrl+V / 右键 | 默认不启用粘贴，可在外观中开启；关闭Ctrl+V时交给终端控制键 |
| Ctrl+Shift+F | 打开当前终端查找 |

多行、控制字符或长粘贴会显示固定目标和完整转义预览/截断提示，CR/LF原样，不自动加尾换行；括号粘贴模式由终端实际模式决定，确认前模式改变会拒绝。取消、键盘接管、切换后迟到剪贴板读取不能发送。系统剪贴板被占用或读取超时会明确失败；超时不代表操作系统读取已取消，程序不自动重试。正文与同意不持久化。

当前终端查找为区分大小写的单行字面匹配，可跨软换行但不跨硬换行；支持上/下一个、定位与回底。它只搜索当前有界buffer，扫描/结果有上限并显示提示，不代替持久日志全文搜索。

## 独立 exec 任务

在活动SSH2连接的“exec 任务”中输入命令、超时与输出上限，再“启动 exec 任务”。这是同一SSH连接上的独立任务通道，不共享交互终端已经执行的cd或临时shell变量；若需要操作当前交互程序，应使用终端或基础撰写。stdout/stderr分开显示，输出缺口和超限明确报告；编码在任务建立时冻结。串口没有exec退出码。

切换连接或关闭面板不会取消任务。记下完整任务ID后可在原连接/代次查询，重载不重新执行；已结束结果有保留上限，退休后无法查询也不会重跑。取消是请求，不能撤销远端已发生动作；结果不明先查询原任务，不自动再次执行命令。

## 状态、编码与屏幕

底部显示活动连接、协议/状态/代次、冻结编码、本地终端列×行、本次服务日志和桌面输入状态。输入可用表示本地连接与视图绑定等条件满足，不表示设备已经执行；“Agent 授权”可管理服务限时授权，真实MCP桥交付仍未接入。串口没有远端PTY；本地视口尺寸也不是SSH远端PTY已应用的回执。

## Agent 授权管理

打开“Agent 授权”，核对当前完整连接ID/代次，分别选择读取、写入、SSH独立exec、SSH尺寸或串口控制线、断开连接及1–1800秒期限，再预览并勾选明确批准。默认不勾选任何能力，编辑/切换/关闭使批准预览失效；授权不会跟随重连的新代次。断开是独立能力，批准本身不会关闭连接；实际断开还需Agent租约，Requested只表示请求取消，TransportEnded才表示本地传输回收，均不能撤回已发送或远端已执行动作，应答不明只查原请求编号。这个面板不发送命令、不代替Agent取得输入租约，也不提供token复制。当前真实stdio桥尚未接入，签发成功不表示Codex已经连接。

读取覆盖指定代次服务当前有界保留的原始输出、解码文本和屏幕，不包含持久日志/导出、认证秘密或其他连接。单项查询同时显示原批准与当前有效范围：ACTIVE只表示票据有效，人工接管后可能仅余读取。期限标为服务相对毫秒，不是日历日期；显式查询核对当前状态。输入租约只能查询，人工接管需核对固定目标并确认，会撤下该代次所有Agent非Read范围和租约。

本次授权清单只包含当前服务最多128项保留回执，不是持久授权历史。撤销按原签发编号确认；撤销、接管和取消都不能撤回已派发或远端已执行的动作。签发/撤销应答不明时只查询原编号，不再次批准。窗口重载只保留service_id/request_id，主动打开面板并查询，范围、期限、同意和token均不恢复；服务重启旧授权失效。关闭面板不撤销已签发授权，迟到应答也不会重开面板。

审计折叠区提供最多512条元数据环的有界分页，不保存命令或终端正文。覆盖时明确提示审计缺口；单页不会作为完整持久审计。配置Connect批准、重连/移除、广播与完整审计仍按计划继续。

“屏幕快照”显示桌面当前视口，“服务端屏幕”显示服务持续维护的派生屏幕；解码文本、原始字节和screen分开保留。当前普通屏支持有界重排，替代屏生命周期已有有限合成证据；极限历史容量仍有BUG-001差异，复杂VT/Unicode和真实vim/top/less/tmux未完整验收。快照不是所有程序兼容保证，也不是完整连接输出记录。

输出覆盖缺口、解码错误、尾字节替换、截断和日志源缺口各有独立提示。发现缺口应核对保留范围，不因界面后续继续刷新就把缺失数据当作恢复。

## 日志、历史与导出

“终端日志”默认不记录。选择正确活动目标后“开始记录终端”，只保存开启后的新输出，不补写更早buffer。轮转限额在下次开始时应用；达到保留段上限退休最早分段。关闭日志面板或页面重载不停止记录，停止请使用“停止记录终端”；重连新代次不自动继承。底部保留本次状态，故障/排空/同步/缺口各自显示，写入计数不等于同步或设备成功。

历史日志目标独立于活动连接，刷新目录并选择/打开后可分页阅读文本/HEX。控制字符/HTML仅作为文字，不执行或写回终端。字面搜索扫描保留范围，统计总匹配数、最多显示前100条；取消/错误不声明全文完成。时间为北京时间。退休分段、启用前输出及源缺口不属于已完整读取的范围。

普通完成日志可导出JSONL，先生成应用受管理目录中的产物；COMPLETED回执带字节数/SHA-256，不等于已经保存到自选目录。使用另存入口才打开Windows选择器。已有普通本地文件须另行确认替换，原文件保留为同目录backup；冲突可能返回RECOVERY_REQUIRED，应核对显示的backup/暂存位置，不承诺原子回滚。网络和特殊属性目标目前拒绝，不通过改属性强制覆盖。“打开保存目录”只请求系统打开该任务登记的目录。

失败或异常停止日志可在“失败日志只读前缀恢复”独立刷新/选择。只验证到首个错误，持续显示“未完整”、精确前缀及停止原因；即使到文件结尾也不能改称完整。关闭占用该源日志的恢复读取后，可“导出未完整恢复前缀”，其独立恢复导出/原生另存入口固定RECOVERY来源，不能把恢复编号交给普通导出查询。恢复另存沿用真实系统选择器及独立替换确认，用户副本保留未完整说明。

导出/保存应答丢失或重载后，只查询原模式、原目标、原任务编号；不自动重开选择器/发布，不恢复替换同意。取消不能撤销已发布文件，部分失败可能保留暂存或备份。跨进程重启保存任务恢复仍属P24，不能假定旧编号在新服务可恢复。

## 整理与配置恢复

日志/导出整理先选择独立目标并预览，核对逐项文件清单，再显式勾选/确认；预览有期限，状态变化或占用会拒绝。删除不可撤销；APPLIED仍须核对实际删除数、失败项及目录状态，不等于完整成功或物理容量已释放。程序不会递归删除未知文件。失败捕获的“解除失败关联”只移除已结束失败记录的内存关联，不删除文件、不恢复前缀、不证明磁盘空间释放。

“连接配置”中的便携JSON导出不含凭据引用、信任和桌面偏好；配置备份包含配置、公开主机信任、凭据引用和显示/习惯偏好，不含凭据库秘密本体。预览核对来源/摘要并勾选后替换配置，先保留当前安全副本；缺失凭据引用需重新录入。备份失败、较新版本或损坏输入不得手工覆盖当前库。

凭据整理仅显示UUID和引用信息；先检查当前配置及受管理备份引用，再显式遗忘无引用凭据。仍有引用或备份不可读时拒绝遗忘。外部副本不在核对范围，删除引用或遗忘凭据不承诺物理擦除；不要据此删除未核对的私钥源文件。

## 外观与偏好

外观提供深/浅/系统应用主题、独立终端配色（跟随应用/黑底绿字/黑底白字）、统一终端等宽字体及复制粘贴习惯，字号在工具栏调整。黑底绿字只改变默认文字，ANSI颜色仍区分；字体缺失使用既有系统中文回退，不安装字体。

调整立即作用本窗口，明确“保存桌面偏好”才写本数据目录；重载/下次启动读取已保存设置。“重新读取偏好”会丢弃未保存调整。保存结果不明先读取核对，不自动重试。配置备份恢复后重新应用偏好，迟到保存应答不能覆盖已恢复窗口；配置其他修改造成旧revision冲突时也需读取。

schema 4升级前保留唯一旧库副本，schema 2/3备份只读兼容；旧程序不写较新schema。回退需停止服务、核对目录和副本后选择，不手工降版本。窗口树宽、标签顺序/隐藏和工作区尚未持久化，P17继续；正文、草稿、剪贴板和确认同意不进入偏好。
