## 原基线与变化

原 P07 要求 P02–P06 结论齐备且 G0 通过；P03/P04/P05 的真实端点/驱动验收未通过，阻止进入任何 P07 工作。现允许**不依赖真实设备结果的公共软件与隔离验证**继续：P02/P06 已通过，P03–P05 有可复查候选结论/失败缺口，接口可据此实现并保持候选可替换。

这不是 G0 通过。G0 与 G1–G4 的完整验收条件、R01–R14 和 T01–T21 均保留。P03/P04/P05 继续 BLOCKED 或 IN_PROGRESS，记录已完成软件子项与未执行设备子项。后续工作只在自己的实现/软件测试前置满足时继续，不能用本 CR 将所有 TODO 直接标 DONE。

## 边界与依赖约束

- 允许先完成 P07 状态机、IPC/配对/ACL、P08 配置与凭据及其他可隔离测试的软件工作。
- 允许将已验证 SSH2/串口候选整合到开发构建，公开缺少真实设备验收；实现未验证的功能必须禁用或明确 UNSUPPORTED，不能假成功。
- SSH1 的 Windows resize/凭据桥是软件缺口，不因用户推迟实机而豁免。P13 完整适配前仍须解决；通用服务可先实现协议中立边界，不用原版 Plink 管道冒充完整 SSH1。
- P03 真实 OpenSSH/Linux/UNIX，P04 完整 SSH1/用户设备，P05 虚拟对及控制线/设备收发分别补验。P16 实际共享会话、P23 设备矩阵、P24 相关故障注入和 P25 完整发布仍受这些证据约束。
- 不自动打开未知端口、不改用户全局 Codex 配置、不安装驱动/系统服务、不公开测试端点。需要真实参数时在后续验收登记，当前继续软件实现。
