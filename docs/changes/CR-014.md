# CR-014 终端右键基本日志操作

- 日期：2026-11-09（Asia/Shanghai）；来源：用户要求在选中窗口右键直接开始/停止日志、打开目录/文件、导出全部日志/可见屏幕；经既有顾问聊天转交，截图只作交互参考，不复用Xshell资源。Step-ID: P11.4；状态：IN_PROGRESS。

后续同日用户追加并覆盖下文“已停止才有可读文件”：开始后实时追加可读文本，所有窗口/轮次统一平铺在现行稳定应用根的logs目录，内部raw/JSONL结构保持；打开文件定位本次正在追加文件，不以临时导出快照冒充。默认文件名严格“窗口显示名_YYYY-MM-DD_HH_mm_ss.log”，北京时间、起录时冻结；如192.168.10.250_2026-11-09_14_14_47.log。非法字符/保留名仅必要规范化，同秒冲突原子create_new并最小_1、_2后缀，不默认加协议/用户名/UUID，不覆盖/等待。实时flush目标100ms、sync目标1秒（OS阻塞不承诺硬实时/每字节掉电安全），accepted/written/flushed/synced分列；失败/磁盘满/源缺口明显。新实时文本独立保留，旧内部日志不移动/删除/扫盘合并，整理内部日志不自动删除平铺用户文本，也不把内部清理计数称包含文本容量。

实时文件实现后，“全部已记录日志”也支持记录中：对本代次全部已录文件先等待操作开始前accepted记录刷新，再冻结各文件已刷新字节水位，完整流式导出这些固定前缀及范围元数据，录制不中断。不是首批预览/实时追尾，不包含起录前未记与快照后的新输出；源缺口/拒绝/失败与同步水位分列。该实现覆盖下文早期“全部导出须停止”的方案限制；独立viewport和保留显示缓冲仍不同。

SSH2/UART和两个窗格共用菜单，右键实际窗格先选中，冻结服务/协议/connection_id/generation与视图；菜单后切换、重连、关闭不改投目标。开始/停止直接走原日志服务，独立原编号/同步在途门，未知只查，不自动重新起录或导出。旧右键粘贴偏好不再触发直接发送，粘贴改为明确菜单项或原快捷键，不能一次右键同时弹菜单和发送。

六入口：开始记录日志；停止记录日志；打开本代次可信受管理日志目录；打开本代次已停止日志的完整可读UTF-8文本；导出本代次全部已停止日志的完整保留范围（多份/轮转/缺口/起录前未记录均明确）；导出右键当时可见屏幕文本，包括用户向上滚动的viewport。完整已记录导出/可读文件须源已停止且同步，不静默停止正在记录的任务；活跃或未录制时额外提供“导出当前终端保留缓冲”，清楚说明有界且不等于从连接开始的全部历史。无可读来源时禁用并说明。

复用原安全存储/指纹与系统另存/覆盖保护。原生仅接受精确身份、受管理ID或有界显示文本，不接受WebView路径/命令/URI；文件内容不解释为路径。准备后直接进入选择器，不要求再点多层准备按钮；仅覆盖原文件保留既有独立确认。结果和范围固定在简洁操作状态区，失败/未知明显，查询沿原ID，其他会话保持。真实设备日志不入Git/fixture、不为菜单验证发送远端业务命令。
