# CR-057 会话树连接的标签落位与焦点

从会话配置栏双击、右键「连接」或点击「连接选中配置」时，新标签追加到发起连接的窗格末尾。保留已有标签的手动顺序、分组和本地终端混排。复制标签继续紧邻源标签，工作区连接依现有布局规则处理。

默认选中新标签，按需先显示主机核验和登录。认证成功或串口打开后，在新连接的终端已绑定并显示时交接键盘焦点。用户在等待期间主动切换标签或窗格，连接仍在原窗格落位，保留用户当前选择及输入目标。

回执按原请求与连接代次处理。原窗格关闭或服务换代时停止交接。原服务的迟到回执只处理该回执指定的连接。服务列表公共顺序继续由服务负责。

使用隔离 Windows 桌面、回环 SSH 和内存串口验证，交付 Windows x64 便携试用候选。
