# CR-027 新建本地终端的默认目录

2026-11-22 在 0.1.16 基础上为新建 PowerShell 和轻量命令行使用当前 Windows 用户的桌面。启动时读 Windows 已知文件夹位置，支持系统管理的重定向路径。

「更多工具 → 软件设置 → 本地终端」显示默认目录，可用系统文件夹选择器修改，也可恢复使用桌面。选择和恢复立即保存，取消保留当前设置。读取旧数据目录时，缺少此设置视为使用桌面。自定义目录不可访问时提示并回退到桌面。桌面也不可访问时使用当前用户的主目录，两处都不可用时提示无法新建。

现存标签保留各自目录。ADB 结果沿用来源标签原有的继承规则，BAT 和 CMD 仍从脚本所在目录启动。按 [P26.4](../records/P26.4.md) 验证并交付 Windows x64 直接运行目录。
