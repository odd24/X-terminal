# CR-049 MCP 快捷指令管理同步

工具目录升级为 v13，沿用 33 个工具名。四个快捷指令工具用显式 `version: "v2"` 选用四类型契约。省略该字段时沿用旧 ADB 和脚本引用契约。扩展查看、扩展管理分别在 Desktop 针对当前桥批准，与会话权限独立。

扩展契约支持旧 ADB、BAT/CMD 引用、多步 Windows 本地命令和当前会话发送文本。适用条目支持成功后关闭与追加 Enter。省略补丁字段保留原值，显式 `false` 清除相应开关。脚本创建省略名称或补丁提供空字符串时使用含扩展名的文件名，沿用桌面的 64 字上限。

支持在当前置顶或普通区稳定批量移首、移尾，并兼容同区锚点。沿用集合版本检查、原请求编号及实时右栏刷新。按原编号恢复此前与新版的回执。工具权限只覆盖配置元数据。

以实际 Windows 便携版、官方客户端和原生 stdio 验收。模型调用仅管理自建配置，检查脚本文件和合成 SSH 输入保持。已有用户脚本和真实设备不参与。
