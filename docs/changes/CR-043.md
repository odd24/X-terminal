# CR-043 普通本地标签双击复制与拖动

普通 PowerShell 和空闲轻量命令行标签通过同一标签上的两次有效鼠标点击复制一次。副本在当前窗格中紧邻源标签。轻量命令行使用当前工作目录，PowerShell 使用启动目录。原终端保留草稿、历史和运行中的进程，副本启动新终端。

拖动、取消、浏览器随后生成的点击事件以及菜单和关闭操作不参与双击复制。自建或登记的 BAT/CMD、独立 ADB 结果和已知前台任务占用的轻量标签双击只选中原会话。显式右键复制沿用原入口。

Windows 便携发布验证以同一 Release 桌面文件校验值绑定本地普通鼠标双击和排序、混合 SSH 分屏、快捷指令别名及悬停预览。
