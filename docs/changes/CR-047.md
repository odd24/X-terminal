# CR-047 本地命令组末步 ADB Shell 交互

本地命令组最后一行是单独的 `adb shell` 时，以 Windows ConPTY 启动固定设备的 ADB 客户端，在本次结果标签显示真实提示符并接收输入及尺寸更新。用户原有的设备参数和快捷指令继续读取原配置。输入 `exit` 正常结束，Ctrl+C 沿命令组规则中断。

带远程命令的 `adb shell`、有本机管道的步骤及其他普通步骤使用原有标准流。明确收到设备已是 root 的回执后直接继续。确实重启 adbd 时仍等待同一设备就绪，拒绝、超时及中断停止后续步骤。

Windows x64 直接运行目录以复现的 0.1.33 行为、模拟对照和有明确授权的单台 Android 只读验证验收。ROOT 分支仅由模拟设备提供回执。
