# CR-026 本地脚本快捷指令与本地终端入口

2026-11-22 用户确认以 0.1.15 为基线，在右侧栏增加本地脚本。新建菜单及空态统一显示「本地终端（PowerShell）」，轻量入口移至更多工具。

右栏「＋」提供 ADB 命令和本地脚本。本机 Windows 选择器可多选 .bat、.cmd，每个文件生成独立指令，默认显示文件名。入口保存原路径，默认工作目录为脚本所在目录。行菜单支持改名、重新定位、排序和删除入口。

点击脚本在独立本地标签用 cmd.exe 打开，保留原 PowerShell、ADB Shell 或草稿。使用实时终端输入输出，显示脚本名及工作目录，并可从结果标签打开该目录。每次启动读取现有文件，保留正常退出状态和现有 Ctrl+C 处理。现有 ADB 配置、按钮运行与诊断继续沿用。

验收仅使用自建临时脚本，覆盖实际 Windows 选择器及交互、配置重开和可直接运行目录。记录见 [P26.3](../records/P26.3.md)。
