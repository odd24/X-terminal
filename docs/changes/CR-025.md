# CR-025 本地 PowerShell 与 ADB 设备枚举修正

2026-11-21 用户确认在 0.1.14 基础上实施。PowerShell 能进入 adb shell，桌面快捷操作提示没有设备，需要对照同机路径、环境和枚举输出。

- 枚举行支持空格和 Tab。失败提示区分无设备、状态不可用、枚举异常和格式异常。指令旁可查看实际 adb 路径、枚举参数及输出。已指定目标按原命令执行，自动选中的设备按本次序列号绑定。
- 「本地命令行」默认运行真实 Windows PowerShell。ConPTY 中直接输入输出，保留已有 xterm 显示。单条命令能力作为「轻量命令行」入口留用，也直接在正文输入。
- 真实 Shell 的前台状态和当前目录由 Shell 管理。从真实 Shell 点击快捷指令时开独立结果标签，终端直接交互，原 Shell 和草稿保留。结果标签以开原标签时记录的 Windows 目录为初始目录。
- 右侧栏开关改为与左上导航图标镜像的细线图标，保留悬停提示、可访问名称和展开状态。全局工具栏及既有配置沿用原版。
- Windows x64 交付为可运行目录。实机验证限唯一已授权 Android 设备上的 adb shell、pwd 和 exit。

实现和验收见 [P26.2](../records/P26.2.md)。
