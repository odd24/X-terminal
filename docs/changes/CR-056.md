# CR-056 新建 SSH2 配置与首次登录

左侧新建 SSH 配置的「仅保存」回到会话树并选中已保存的配置。「保存并连接」进入受管连接，并明确显示配置已保存。

首次主机核验展示实际连接目标、可复制的真实 SHA256 指纹和可信来源核对说明，用户通过「指纹一致，信任并继续」批准。焦点停在「暂不连接」。已知相同指纹由服务跳过确认，指纹变化单独展示原记录及新指纹，默认停止并要求明确更新。拒绝或取消保留已保存配置。

需要补录 SSH 密码时展示当前用户名、主机与端口，支持明确记住密码及回车提交当前认证挑战。保留原凭据同意、密钥、交互认证和手动快速连接流程。使用隔离 Windows 桌面与回环 SSH 验收，交付便携试用候选。
