# CR-031 当前窗格快捷键和本地终端查找

Ctrl+Tab 与 Ctrl+Shift+Tab 在当前窗格按标签栏顺序循环，Alt+1 至 9 和 Alt+0 直达第 1 至 10 个标签。没有对应序号时保持原标签。分组、拖动、分屏均沿用实际显示顺序。

Ctrl+Shift+T 在当前窗格新建 PowerShell，读取原默认目录设置。Ctrl+Shift+B 开合本地快捷指令栏，打开聚焦列表，方向键移动，Enter 单次运行。管理和编辑仍使用各自控件。Ctrl+Shift+F 扩展到本地 PowerShell、轻量和脚本结果的实际保留缓冲区。关闭本地查找后回到终端输入。

在发往终端前捕获专用组合键。输入法组合与 AltGr 保留其输入用途，模态及普通表单不触发窗口操作，按住组合键不重复执行。验证与交付见 [P26.8](../records/P26.8.md)。
