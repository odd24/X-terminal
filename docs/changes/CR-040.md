# CR-040 恢复普通本地终端双击复制

普通 PowerShell 和轻量命令行标签再次支持双击。一次有效双击只创建一个空白同模式标签，放在原窗格原标签旁。轻量命令行使用原标签跟踪的当前工作目录。PowerShell 使用原标签的启动目录，其内部 `cd` 或 `Set-Location` 不改变该记录。

双击不传递原草稿、命令历史、前台任务或设备选择。脚本与独立 ADB 结果标签双击只选中原标签。普通轻量标签复用执行 ADB 时，等待设备选择、正在运行和等待原请求核对的阶段禁止双击复制，空闲后恢复。其他已知轻量前台任务沿相同条件。应用不从 PowerShell 命令和屏幕内容推断设备操作。

原右键显式复制、SSH2/串口复制、标签排序、分屏和关闭继续各自处理。方案 A 样式沿用现行实现。
