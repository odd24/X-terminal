# CR-050 右栏快捷指令描述

Windows 本地命令、ADB、发送到当前会话、BAT/CMD 脚本均可添加或编辑可选描述。批量登记脚本时每项独立填写。原生按至多 500 个 Unicode 标量校验，统一换行为 LF，保留多行及非空白文字，空白描述归为空值。紧凑列表仍只显示名称。悬停、键盘预览及全部展开时在命令正文或脚本路径前显示描述。脚本预览读取中和读取失败时也显示。异步读取不能更新另一个条目、旧修订或旧窗格的预览。

描述保存在同一个受保护的本地库中。现有配置和回执的存储形状保留，旧桌面仍能读取原快捷指令。新桌面按快捷指令编号读取描述，将描述与配置变更原子提交。描述仅用于显示和配置，执行、ADB、脚本及会话输入仍使用原目标字段。

MCP 目录升级至 v14 并保持 33 个工具。四个快捷指令工具显式传 `version: "v3"` 以选用含描述的四类型契约。v3 在 Desktop 单独批准「描述查看」或「描述管理」。原省略版本和 v2 的 schema、权限、返回值和回执查询沿用各自历史行为。v3 创建可省略描述。更新时省略保留，显式空字符串、纯空白或 `null` 清除。请求修订、原编号、桥身份及失答查询依原规则核对。旧记录和后续版本间的请求编号冲突继续拒绝。

常用命令模板另行处理。候选通过隔离的 Windows 桌面、实际 stdio 桥及旧客户端复验。
