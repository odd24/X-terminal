# CR-051 右栏快捷指令编辑导航

右栏列表继续使用「快捷指令」、新增和收起入口。进入现有指令编辑时显示「编辑快捷指令」，进入新增时显示「新增快捷指令」。表单页隐藏新增按钮，在原收起位置放置「← 返回」。返回仅退出本次指令表单，保持侧栏打开。

顶部返回和底部「取消编辑」共用离开逻辑。表单值与进入时相同则直接返回。有改动时弹出「更改尚未保存」，可选择「继续编辑」或「放弃更改」。默认焦点在「继续编辑」，Esc 回到表单。现有条目保存成功或取消后恢复列表滚动位置和该条目的管理焦点。新增取消回到新增入口，新增成功定位新条目。原条目不可用时退回列表的可用入口。失败则保留描述及其它输入。
