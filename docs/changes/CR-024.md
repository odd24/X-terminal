# CR-024 本地窗格的 ADB 快捷指令侧栏

2026-11-21 用户确认在 Windows x64 0.1.13 基础上，把 ADB 快捷操作放入本地窗格右侧。

- 「快捷指令」开关位于本地标签栏末端。首次收起，记住手动选择。宽窗展开约 300 px，窄窗和分屏只覆盖当前窗格，收起归还显示空间。
- 侧栏顶部可新建和折叠。列表显示名称和省略后的等宽命令预览，点击指令行执行。「⋯」分别提供编辑、上移、下移和删除。空态可添加第一条指令，底部有「ADB 设置」。
- 在栏内编辑名称和完整命令。字段占满栏宽，命令视觉换行保留输入原文。保存使用现有受保护的 ADB 设置和版本校验，取消保留已保存值。
- 可继续使用旧按钮及 adb.exe 路径。执行沿用空闲、草稿和忙碌路由，结果焦点回到对应终端。切回后台原标签继续交互，折叠侧栏不影响任务。全局工具栏沿用 0.1.13 布局。

布局、设置重开、管理零调用和解包验收见 [P26.1](../records/P26.1.md)。
