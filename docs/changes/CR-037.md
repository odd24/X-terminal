# CR-037 应用菜单外观与键盘操作

顶部「更多工具」作为菜单视觉基准。自绘菜单复用其背景、边框、圆角、阴影、内边距、行高、字号、悬停、键盘焦点和禁用状态。分区、状态和快捷键只在有对应信息时显示。顶部工具栏菜单保留原宽度和分组，其余菜单随内容宽度放置，短动作名保持单行。菜单靠窗口边缘避让，超长时在菜单内滚动。

覆盖顶部工具和日志、标签加号、配置加号和配置树右键、会话标签右键、快捷指令加号及管理、SSH 更多会话操作、本地复制和粘贴。工具菜单里的诊断折叠继续使用原入口。系统选择器、原生下拉、普通列表、折叠表单和终端正文沿用当前控件。

方向键、首尾键、Enter 和 Escape 统一操作，关闭时将键盘焦点交回原控件。标签加号仍可悬停展开或单击直接新建 PowerShell。本地右键按已保存策略处理，键盘菜单键和 Shift+F10 显式打开菜单。打开菜单和浏览管理选项不执行指令。会话、日志范围、粘贴目标、在途任务及复制规则沿用各动作原有验证。
