# CR-023 Windows 本地命令行与 ADB 快捷操作

2026-11-21 用户确认以 Windows x64 0.1.12 为基线实施两个阶段，并完成验证、打包和交付。需求来自同日《Windows 本地命令行与 ADB 快捷操作方案》审定稿。

1. 从现有标签的「＋」打开本地命令行。每个标签独立持有 Windows 工作目录、命令历史、显示缓冲和前台任务。直接执行本机程序，支持 cd、盘符、pwd、dir 和 ls，支持双引号参数。保留交互式设备 Shell 时，可另开标签查看日志或导出文件。
2. 在本地终端管理 ADB 快捷按钮。持久化名称、单条完整 ADB 命令及排序。空闲且草稿为空时在原标签执行。忙碌、有草稿或输入法组字时，结果进入继承原 Windows 工作目录的新标签。
3. 主机查询直接运行。已识别的设备操作优先沿用显式目标或 ANDROID_SERIAL。其余在同一 adb 和服务端选项下枚举，单设备绑定序列号，多设备明确选择。取消、掉线和启动失败当次结束，保留诊断。
4. 现有顶部工具栏布局保持定稿。MCP、SSH 和 UART 授权均不授予本机进程执行权。本地标签禁用 SSH/UART 日志保存入口，文件导出由用户显式执行 adb pull。

实施与边界见 [ADR-099](../decisions/ADR-099.md)。验收按 L01–L06 和 B01–B03 分列软件、实机和体验证据，记录在 [P26](../records/P26.md)。实际设备检查限用户指定目标及已授权读取的样本。
