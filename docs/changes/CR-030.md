# CR-030 快捷指令批量管理和显示

本地终端右侧快捷指令保留单击运行。管理模式支持点选、全选、清除、置顶与取消置顶、上移和下移。拖柄和方向键在所属区域内调整顺序。批量移动保留原相对顺序。批量移除显示条数并要求确认，只移除入口。

快捷指令使用更紧凑的行。单双列可以选择，极窄窗格使用单列以保留点击和阅读空间。「全部展开」用当前窗格显示完整命令和脚本路径，可滚动和一键收起。布局和置顶随配置保存，重启继续使用。已有 ADB 和 BAT/CMD 记录沿原规则迁移。

管理操作只保存设置。修改基于原版本，冲突时保留当前显示，明确重新读取后再提交。验证和交付范围见 [P26.7](../records/P26.7.md)。
