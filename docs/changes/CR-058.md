# CR-058 修复 PowerShell 长路径拖入重复重绘

修复 Windows PowerShell 5.1 使用 PSReadLine 2.0 时，路径因软换行重复显示的问题。保留真实换行、原光标、路径字面量和单次插入。路径仅进入发起窗格的原编辑代次，拖入本身不提交命令。

使用 0.1.39 正式桌面中的原生 OLE 重现。以 PSReadLine 编辑缓冲、光标、ConPTY 输出和最终屏幕为独立验收项。对照 65 和 96 列、行尾、跨多行、行中、多路径、普通键入、取消、迟到请求和明确的前台过程。

使用隔离数据根、从启动关闭普通历史保存的 PowerShell 和合成文件。验证后交付配套 Windows x64 便携候选。
