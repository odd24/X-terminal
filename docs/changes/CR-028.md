# CR-028 本地会话标签拖动及双击复制

本地终端标签沿用 SSH 标签的主窗口拖动手势和落点预览，可在标签栏排序、在窗格间移动，或拖到终端边缘分屏。混合窗格同时容纳本地和服务会话。移动保留原本地进程、终端正文和草稿。本地终端的拖动范围是主窗口内的窗格。

双击本地标签在旁边打开独立的同类终端。轻量终端继承原目录，PowerShell 使用原进程的启动目录。脚本和 ADB 结果标签的副本打开空白终端，沿用该结果标签的目录。双击已连接的 SSH2 或串口标签进入已有复制流程，保留身份确认、认证和设备选择。

2026-11-22 修正。BAT/CMD 脚本会话标签使用与 SSH 相同的窗口内拖动入口，双击只选中原会话。标签复制要求同一标签上的两次有效点击，拖动或取消会清除点击序列。
