# CR-012 优先修复SSH快速输入与删除延迟

- 日期：2026-11-09（Asia/Shanghai）；来源：用户“快速在连接的ssh终端窗口输入或者删除时，文字显示或者删除跟不上”，现有顾问聊天转交；Step-ID: P12.1；状态：IMPLEMENTED（软件合成验证；现场服务器重登另列）。

S3新增继续暂缓，先改善基本SSH工作路径。先合成实际桌面诊断，再据证据修复，不归咎网络或凭据、不对用户业务连接发测试命令。保留统一服务/FIFO/精确代次/焦点epoch/去重和未知停止不重放，不本地假回显，不靠加大容量隐藏背压，不合并Compose/粘贴/resize或跨控制边界。主动交互刷新有界并回退空闲节奏。R01–R16、UART实机和全局验收边界保持。方案/测量限制见[ADR-072](../decisions/ADR-072.md)和[P12.1记录](../records/P12.1.md#快速键盘与删除延迟2026-11-09)。
