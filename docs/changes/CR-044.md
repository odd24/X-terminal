# CR-044 全窗格快捷指令

主窗口的 SSH、串口和本地窗格共用侧栏。打开侧栏与浏览预览属于只读操作。SSH 或串口运行本地指令时，新建并聚焦本地结果，原会话继续运行。已有本地单条 ADB 保持原空闲复用规则，启用自动关闭的条目始终走新结果。

「本地命令」原样保存至多 8192 UTF-8 字节，执行至多 16 个非空步骤，每行至多四段实际本机标准流管道。语法支持 Windows 双引号及引号前的反斜杠规则。裸 `|` 连接本机程序。参数按字面传递，支持 PATH 或绝对路径的 EXE/COM。BAT/CMD 使用独立的本地脚本入口。`grep` 走本机 PATH，可用 `Select-String power` 或 `Select-String -SimpleMatch power` 在 Windows PowerShell 中进行字面匹配。程序通过标准输入管道接收交互输入。

组内 ADB 使用一次冻结的本机程序和同一设备。支持直接的 `root`、`shell`、`logcat`、`pull`、`push`、`reboot` 以及主机侧 `devices` 和 `version`，可使用一致的显式 `-s`。每步输出序号。任何段失败、超时或 Ctrl+C 都停止尾部。ADB root 仅在退出码与已识别的成功输出都通过时继续，并有界等待原编号设备。任务总时限 30 分钟，原设备等待 12 秒。旧版单条 ADB 配置维持原契约。

「发送到当前会话」保存单段文本及可选 Enter，点击时冻结当前 SSH 或 UART 的准确代次和窗格，并使用其现有输入队列。旧 MCP 快捷管理接口继续管理原 ADB 和脚本类型。脚本及本地命令可单项启用成功后关闭独立结果，默认关闭。取消、失败、超时或持续运行保留结果，返回来源只发生在结果仍占据活动窗格时。
