# CR-041 快捷指令显示名称与只读预览

紧凑列表的 ADB 和脚本都只显示名称。全部展开显示完整命令或脚本路径。右侧单双列、置顶与普通区域、现有拖动、分组和管理方式保持。

本地脚本选择后在同一清单可选填显示名称，单选直接命名，多选逐行确认。确认时复用设置 revision 和一次保存事务。空白名称使用带扩展名的原文件名，超长默认名在原有 64 字符限制内保留扩展名。右侧单项重命名编辑已有名称，稳定 ID 和目标路径不变，脚本文件不写入。

指针停留或键盘聚焦约 400 ms 显示完整 ADB 命令或受控脚本预览。优先贴列表左侧，必要时避让或在列表下显示。可移入并滚动，按 Escape 或离开关闭。脚本正文调用只接受已登记 ID 及配置版本，最多读取 32 KiB，将脚本文字作为纯文本显示。预览、编辑、选择文件和浏览管理菜单都没有执行动作。MCP 快捷指令字段及权限沿用原契约。
