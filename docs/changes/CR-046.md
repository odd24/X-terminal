# CR-046 可更改日志保存位置

在「更多工具 → 软件设置 → 日志」显示完整保存位置，提供原生选择文件夹、保存、打开目录和恢复默认。以当前实例数据根下的 `logs` 为默认位置。保存前验证目录可写。失败时重新读取已提交设置，回执丢失时只重新读取。

每次开始录制时固定目录。既有录制继续写入已经打开的文件。当前日志目录按新设置打开，已录文本、完成通知和原可读日志按录制编号、连接代次、协议、文件名和原文件身份定位。原文件被移动或由同名文件替换时拒绝打开。

可读日志目录采用现有 Windows 本地路径及原生句柄边界。应用登记最多 64 份可读日志。同名冲突由独占新建处理，无关文件保持原样。旧数据根的默认路径照常使用，旧文件留在原处。旧版缺少可核对的文件身份时，仍可从历史界面读取保留的内部记录。

内部原始记录、审计与手动另存仍沿用各自的存放方式。交付形式为 Windows x64 便携目录，直接运行。以实际双连接录制、原生文件夹选择和打开、重启及失败场景作为验收依据。
