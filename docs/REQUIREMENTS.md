## 用户操作语义

- Profile：持久连接配置，凭据只存引用，不存明文。
- Connection：一次具体连接，具有独立 ID、协议、状态和输出游标；同一 Profile 可打开多份。
- Workspace：布局、配置引用、快速命令组和恢复偏好；恢复不重放旧输入。
- 输出读取授权不自动授予写入；写入不自动允许广播、执行触发器或新建连接。
- SSH exec 不继承交互终端的 cd、环境变量、前台程序；UI/API 必须明确标识。
- 串口没有通用退出码；等待匹配成功不等于命令成功。
- 取消任务表示停止后续调度，已发送到远端的操作不保证可撤销。
- 重连不会自动重发输入；认证、密码输入与广播模式不混用。

## 非功能目标（待 P01 建立测试机器基线）

1. 20 个活动会话，连续运行 8 小时；无崩溃、无无界队列，内存增长可解释。
2. 在记录 CPU/RAM/系统/屏幕信息的测试机上，20 会话各 20 KiB/s 合成输出下，键入到本地调度 P95 ≤100 ms；不将公网延迟计入本地指标。
3. 总 1 MiB/s 连续日志 30 分钟，以序号/校验值验证；过载应报告缺口/限流，不能无声丢数据。硬件串口以其实际线速单独测试。
4. 每连接内存缓冲和磁盘日志限额可配置；初始建议 16 MiB 内存、100 MiB × 5 日志轮转，在 P22 校准。
5. Windows 10/11 x64 为暂定范围；最低系统构建号与 WebView2 安装方式在 P01 确认。
6. 支持离线使用 SSH/串口；Codex 自身网络与账户要求不属于终端程序的离线保证。

## 未决事项与处理

| 问题 | 默认推进策略 | 最迟解决点 |
|---|---|---|
| 是否存在真实 SSH1 端点 | 用隔离测试端点做原型，不删除 R02 | P13 实机验收前 |
| 常用串口与 USB 转接芯片 | 原型可用虚拟串口对，实际参数按设备配置 | P10 实机验收前 |
| 目标 UNIX 与认证方式 | Linux/OpenSSH 先行；旧 UNIX 和额外认证列兼容矩阵 | P23 前 |
| Xshell 配置迁移 | 仅使用用户提供或授权读取的样本，不解密其密码 | P21 前 |
| Codex 客户端版本/受管策略 | 记录 CLI 与桌面版本，实际验证 MCP；CLI 成功不等于桌面成功 | P06、P16 |

缺少设备或权限时将相关验收标为 BLOCKED；可以继续无依赖步骤，不能填“已通过”。
